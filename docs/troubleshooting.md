# 문제 해결

**이 문서를 읽으면** 가장 자주 나오는 증상을 순서대로 짚어 원인을 좁힐 수 있습니다. 같은 내용이 툴 헤더의 **?** 버튼 → FAQ에도 있습니다.

## 마스크를 꽂았는데 효과가 안 보여요

순서대로 확인하세요. 대부분 1번입니다.

1. **sRGB (Color Texture)가 꺼져 있는지** 확인합니다. 켜져 있으면 감마 보정으로 값이 틀어집니다.
   → [sRGB와 임포트 설정](/concepts/srgb-and-import-settings)
2. 슬롯에 **채널 선택**(R/G/B/A)이 있다면, 마스크 데이터가 **실제로 들어 있는 채널**과 맞는지 확인합니다.
3. 이 프로퍼티를 켜는 **상위 토글**이 켜져 있는지 확인합니다 (lilToon의 Rendering Mode, MingToon의 `~ Enabled` 토글, NiloToon의 스태킹 레이어 활성화 등).
4. **UV**가 본체 텍스처와 같은 맵을 쓰는지 확인합니다.

## 효과가 반대로 적용돼요

셰이더 쪽 **반전(Invert)** 토글이 켜져 있거나, 마스크를 흑백 반대로 구운 경우입니다.

어느 한쪽만 뒤집으면 되므로, **마스크를 다시 굽기 전에 셰이더의 Invert 토글을 먼저 꺼 보세요.** MingToon은 대부분의 프로퍼티에 있고, 모든 셰이더에 있는 것은 아닙니다.

## 마스크 경계가 계단처럼 보여요

1. **dilate(아웃라인 확장)** 값을 키웁니다. UV 경계 바깥으로 색을 밀어내 심(seam)이 드러나는 것을 막습니다.
2. 그래도 안 되면 해상도를 올립니다 (512 → 1024).
3. 그래도 안 되면 **UV 심(seam) 위치**를 의심합니다. 마스크 경계가 심 위에 놓이면 어느 해상도로도 깨끗해지지 않습니다.

압축 때문일 수도 있습니다 — 특히 [패킹된 팩 텍스처](/concepts/channels-and-packing)에서 채널이 서로 번집니다.
→ [sRGB와 임포트 설정](/concepts/srgb-and-import-settings)

## 머티리얼이 여러 개인데 어디에 적용되나요

각 탭은 **Load한 렌더러의 슬롯 기준**으로 동작합니다. 대상 목록 아래의 **머티리얼 슬롯 피커**에서 원하는 슬롯을 고르세요. 고른 슬롯의 서브메쉬만 베이크·페인트·프리뷰됩니다.

→ [머티리얼 슬롯 피커](/getting-started/first-mask#머티리얼-슬롯-피커)

## 방금 구운 텍스처가 어디 저장됐는지 모르겠어요

각 베이크 탭 하단의 **최근 베이크** 목록에서 **핑(찾기)** 또는 **폴더 열기**를 누르세요.

## 프리뷰가 씬에 남아 있어요

**Stop**을 누르거나 창을 닫으면 자동으로 복원됩니다. 리컴파일·플레이모드 전환에도 복원됩니다.

프리뷰는 원본 머티리얼을 복제해 임시로 씌우는 방식이라, 원본이 변경되는 일은 없습니다.

## 씬 뷰에서 가닥이 안 잡혀요

| 증상 | 확인 |
|---|---|
| 클릭해도 아무 일이 없음 | `Ctrl`을 누르고 클릭했는지 확인하세요. 그냥 클릭은 씬 오브젝트 선택입니다 |
| 안쪽·반대편 가닥이 안 잡힘 | **뒷면 모드**를 켜세요. 앞면을 숨겨 안쪽을 직접 집을 수 있습니다 |
| 한 번에 여러 개가 토글됨 | 정상입니다. 앞/뒷면과 UV가 겹치는 미러 가닥은 자동으로 함께 토글되며, 상태줄에 개수가 표시됩니다 |
| Load 후 선택이 비어 있음 | 선택 상태는 Load 시 초기화됩니다. 모드를 바꾸거나 프리뷰를 껐다 켜는 것으로는 사라지지 않습니다 |

→ [단축키](/reference/hotkeys)

## 컴바이너가 텍스처를 빼놓았어요

자동 모드에서 제외된 텍스처는 목록에 **제외 사유**가 표시됩니다. 사유를 확인하고, 그래도 넣어야 하면 **포함**을 누르세요.

→ [컴바이너](/tabs/combiner)

## 컴바이너가 자동으로 스캔하지 않아요

참조 머티리얼이 **50개를 넘으면** 자동 스캔이 꺼집니다. **스캔** 버튼을 직접 누르세요. 대형 아바타에서 선택할 때마다 멈추는 것을 막기 위한 제한입니다.

## 내 셰이더가 컴바이너 목록에 없어요

빌트인 프로파일은 NiloToon · Poiyomi · lilToon 세 종류입니다. 다른 셰이더는 **셰이더 프로파일 JSON**으로 직접 추가하세요. **빌트인 내보내기**로 템플릿을 뽑아 편집하는 것이 가장 빠릅니다.

→ [컴바이너 — 셰이더 프로파일](/tabs/combiner#셰이더-프로파일)

## 페인트 탭에서 저장 못 하고 창을 닫았어요

다음 **Load** 시 자동 저장된 캔버스 복원을 제안합니다 — **복원 / 버리기 / 취소**.

자동 저장은 `<프로젝트>/Library/MaskMakerAutoSave/`에 있습니다. `Library`는 캐시 폴더라 지우면 함께 사라집니다.

→ [설정과 프리셋](/reference/settings-and-presets)

## 슬롯 분리를 적용했는데 되돌리고 싶어요

`Ctrl+Z`로 되돌립니다. 적용 결과는 Undo/Redo를 지원합니다.

적용 도중 취소하거나 실패하면 **전체가 롤백**됩니다. 일부만 적용된 상태로 남지 않습니다.

## 슬롯 분리 후 새 슬롯이 원본과 같은 머티리얼이에요

기본 동작입니다. 적용 후 원하는 머티리얼로 직접 바꾸세요.

새 슬롯마다 별도 머티리얼(`_SplitN.mat`)을 받고 싶으면 적용 전에 **새 슬롯에 머티리얼 복제**를 켜세요.

*릴리스: 2.0.0*


마스크 만들기 방법을 칠하기, 이미지, 그라데이션, 브릿지, 맷캡 광택 다섯 가지로 정리하고, 여러 방법을 조합해 레이어로 쌓은 뒤 마스크로 출력하는 흐름으로 바꾼 버전입니다. Unity 6(6000.0, 6000.3 LTS) 지원을 포함합니다.

## 업그레이드 시 확인할 것

:::caution[작업 방식과 일부 기능이 바뀌었습니다]
- 색 보정은 Mask Maker에서 더 이상 만들 수 없습니다. 색 보정은 MingPainter에서 합니다. 이전 색상 레이어의 결과는 그대로 남습니다.
- 스텐실, 데칼, 캐비티/AO는 새 마스크를 만드는 방법에서 빠졌습니다. 기존 데이터는 보존됩니다. → [칠하기](/tabs/paint)
- 1.x 레이어 편집 문서는 2.0에서 처음 저장할 때 새 형식으로 변환됩니다. 변환 전 원본은 `Library/StudioRaming/MaskMaker/DocumentBackups/`에 백업되며, 변환된 문서는 1.x에서 열 수 없습니다. → [레이어와 마스크 출력](/concepts/layer-stack)

:::

업데이트는 기존 `Assets/StudioRaming/MaskMaker` 폴더 위에 그대로 덮어 임포트하면 됩니다.


## 새 기능

- **쉽게 시작 / 전문가 작업 모드** — 쉽게 시작은 선택한 마스크의 효과 설정과 씬 뷰 편집에 집중하고, 전문가 작업은 레이어, 메쉬, 출력, 도구를 세밀하게 조절합니다. 모드를 바꿔도 작업은 그대로입니다. → [첫 마스크 만들기](/getting-started/first-mask)
- **마스크 만들기 다섯 가지 방법** — 칠하기, 이미지, 그라데이션, 브릿지, 맷캡 광택. → [칠하기](/tabs/paint) · [이미지](/tabs/image) · [그라데이션](/tabs/gradient) · [브릿지](/tabs/bridge-mask) · [맷캡 광택](/tabs/matcap-gloss)
- **방법 조합** — 내용이 있는 마스크에 방법을 더하면 기본으로 **범위 제한**을 씁니다. **흰 영역 추가**와 **이것만 사용**도 있습니다. → [레이어와 마스크 출력](/concepts/layer-stack#방법-조합)
- **칠하기 보정** — 생성 결과 위에 칠하면 칠한 부분만 보정으로 남고, 나머지는 설정 변경을 따라갑니다. → [칠하기](/tabs/paint#칠하기-보정)
- **펜 필압 크기와 필압 불투명도** — 각각 0~100%로 적용합니다. → [칠하기](/tabs/paint#펜-필압)
- **레이어 저장** — 레이어 하나만 따로 저장합니다. 레이어에 연결되지 않은 그림은 기존 레이어를 덮지 않고 복원합니다. → [레이어와 마스크 출력](/concepts/layer-stack#레이어-저장)
- **마스크 출력** — **출력 · 작업** 탭의 **마스크 출력**에서 출력 크기와 외곽선 (px)을 정하고, 편집 가능한 레이어 문서도 함께 저장합니다. → [레이어와 마스크 출력](/concepts/layer-stack#마스크-출력)
- **보기 세 가지** — 마스크만 보기, 적용 결과 보기, 원본 보기. 원본 보기에서도 마스크 작업은 보관됩니다.
- **열린 마스크 목록과 검색** — 빈 칸도 보기가 기본으로 켜져 있고, 이름, 머티리얼, 셰이더 속성, 텍스처로 검색합니다.
- **자동 보존과 복구 배너** — 저장하지 않은 작업은 스크립트 리로드, Play, 씬 전환, 편집 종료 때 보존되며, 비정상 종료 뒤에는 **복원** 또는 **버리기**를 고릅니다. → [레이어와 마스크 출력](/concepts/layer-stack#되돌리기와-자동-보존)
- **되돌리기 단위** — 적용 한 번, 선택 변경 한 번, 획 하나가 각각 한 단계입니다.
- **Inspector에서 채널을 바꾸면 작업이 같이 옮겨짐** — 칠해 둔 작업이 새 채널로 따라가고, 새 채널에 이미 작업이 있으면 **옮기기** / **따라가기만**을 묻고, 지워지는 작업은 없습니다. → [채널과 패킹](/concepts/channels-and-packing#channel-change)
- **빈 마스크 안내** — 아직 칠하지 않은 마스크의 미리보기에 "아직 칠한 곳이 없어요."라는 한 줄이 나옵니다.
- **MingToon 마스크 슬롯에서 열기** — MingToon 인스펙터의 마스크 슬롯에서 바로 엽니다. 이 연동에는 MingToon 최신 버전이 필요합니다. → [MingToon](/shaders/mingtoon)
- **창에서 언어 전환** — 창 오른쪽 위에서 한국어, English, 日本語를 바꿉니다. 다른 StudioRaming 툴과 언어 설정을 함께 씁니다.
- **Unity 6(6000.0, 6000.3 LTS) 지원 포함**

## 변경

- 새 마스크를 만들 때 고를 수 있는 방법은 칠하기, 이미지, 그라데이션, 브릿지, 맷캡 광택 다섯 가지입니다.
- Play 중에는 불러오기, 편집, 레이어 추가가 꺼집니다. Play 중에 바꾼 내용은 보관되지 않기 때문입니다.
- 지원 Unity는 2019.4 ~ Unity 6(6000.0, 6000.3 LTS), Built-in RP와 URP입니다.

## 수정

- Play, 씬 전환, 리로드, 창 닫기 때 레이어 스택이 사라지던 문제를 고쳤습니다. 이제 보존했다가 돌아오면 복원합니다.
- 새 캔버스를 만들 때 크래시 복구 데이터를 덮어쓰던 문제를 고쳤습니다.
- 채널을 묶은 텍스처(예: `_MaskMap`, `_RegionMask`)에 마스크를 저장하면 다른 채널이 지워지던 문제를 고쳤습니다.
- 머티리얼을 바꾸면 브릿지 레이어가 빠지던 문제를 고쳤습니다.
- 최종 출력에서 MatCap 레이어의 외곽선 값이 적용되지 않던 문제를 고쳤습니다.

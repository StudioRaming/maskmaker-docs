*릴리스: 0.1.1*

페인트 탭이 새로 들어가고, 격리 탭이 브릿지 탭에 통합되어 탭 구성이 6개로 정리된 버전입니다.

## 업그레이드 시 확인할 것

:::caution[탭 구성이 8개에서 6개로 줄었습니다]
**격리** 탭은 [브릿지 마스크](/tabs/bridge-mask) 탭의 **수동 선택** 모드가 됐고, **도움말** 탭은 헤더의 **?** 버튼으로 옮겨졌습니다.

수동 선택 모드의 출력 파일명은 **`_Isolation` 접미사를 그대로 유지**하므로, 이전에 만든 마스크와 이름이 어긋나지 않습니다.
:::

## 새 기능

- **페인트 탭** — 씬 뷰 메쉬 위에 브러시로 직접 그려 마스크/컬러 텍스처를 만드는 블렌더 스타일 텍스처 페인트. 그리기/지우기/부드럽게/채우기, 정면 각도 제한, 차폐, 대칭, 스텐실 텍스처링, 내장 스텐실 8종, 자동 저장 복원. → [문서](/tabs/paint)
- **MatCap 광택 — AO(캐비티) 서브모드** — 메쉬 오목한 부분만으로 음영 마스크를 굽습니다. 씬 뷰 각도와 무관하며 **프리뷰 베이크** 버튼으로 확인합니다. → [문서](/tabs/matcap-gloss)
- **페인트로 다듬기** — MatCap 베이크 결과를 페인트 탭으로 넘겨 손으로 이어 그립니다. → [문서](/tabs/paint)
- **그라데이션 — 기준 본** — 시작/끝점이 본을 따라가 포즈가 바뀐 아바타에서도 위치를 유지하고, 프리셋이 다른 아바타에서도 같은 이름의 본을 재검색합니다. → [문서](/tabs/gradient#기준-본)
- **브릿지 마스크 — 선택 편집** — 전체 선택 / 전체 해제 / 선택 반전 / 선택 확장, **최근 시드** 기록, 페인트 탭으로 보내기. → [문서](/tabs/bridge-mask)
- **슬롯 분리 — 안전장치** — **새로고침**, **이동 초기화**/**구조 초기화** 분리, **적용 계획** 카드, **새 슬롯에 머티리얼 복제** 옵션, 적용 후 자동 프리뷰 재시작. → [문서](/tabs/slot-split)
- **컴바이너 — 자동 최적화** — 자동 스캔, 썸네일, 그룹 간 드래그 이동, **실행 계획** 카드, 베이크 후 자동 머티리얼 배정. → [문서](/tabs/combiner)
- **컴바이너 — 셰이더 프로파일** — `MaskMakerProfiles/` 폴더의 JSON으로 스캔 대상 슬롯을 직접 정의·확장합니다. 빌트인 내보내기 / 다시 불러오기. → [문서](/tabs/combiner#셰이더-프로파일)
- **머티리얼 슬롯 피커** — 메쉬에 머티리얼 슬롯이 여러 개면 슬롯별 베이스맵 썸네일에서 하나를 골라 베이크/페인트/프리뷰합니다. 출력 파일명은 `<메쉬>_<머티리얼>`. 서브메쉬 수보다 많은 슬롯은 마지막 서브메쉬에 매핑됩니다. → [문서](/getting-started/first-mask#머티리얼-슬롯-피커)
- **도움말 (헤더 ? 버튼)** — "마스크 텍스처란?", 탭별 용도 표, lilToon/Poiyomi/MingToon/NiloToon 셰이더별 프로퍼티 연결표(이름 클릭 복사), 연결 4단계, FAQ. → [문서](/concepts/what-is-a-mask)

## 변경

- **격리 탭이 브릿지 탭에 통합**됐습니다. 탭 상단의 **랜덤 가닥 / 수동 선택** 모드 토글로 두 동작을 오갑니다. → [문서](/tabs/bridge-mask)
- **도움말이 탭에서 헤더 ? 버튼으로 이동**했습니다. **닫기** 버튼으로 탭 화면으로 돌아갑니다.
- 위 두 변경으로 탭 구성이 6개(**MatCap 광택 · 그라데이션 · 브릿지 마스크 · 슬롯 분리 · 컴바이너 · 페인트**)로 정리됐습니다.

## 개선

- 씬 뷰 선택이 **Ctrl+클릭 / Ctrl+드래그 페인트 / Ctrl+Shift+드래그 박스 선택**으로 전 탭 표준화. → [문서](/reference/hotkeys)
- 씬 뷰 편집에 **Ctrl+Z / Ctrl+Y** 실행취소/다시실행 적용.
- 저장 시 **덮어쓰기 확인** (덮어쓰기 / 새 이름 / 취소).
- Hierarchy 선택 변경 시 **자동 다시 로드** + 씬 힌트 표시.
- 각 탭에 **최근 베이크** 목록 추가.

## 지원 환경

Unity 2019.4 LTS ~ 2022.3 · Built-in RP / URP.

*릴리스: 0.1.1*

레이어 스택 프리뷰와 **최종 굽기**가 들어가고, 페인트 탭이 새로 생기고, 격리 탭이 브릿지 탭에 통합되어 탭 구성이 6개로 정리된 버전입니다.

## 업그레이드 시 확인할 것

:::caution[탭 구성이 8개에서 6개로 줄었습니다]
**격리** 탭은 [브릿지+영역마스크](/tabs/bridge-mask) 탭의 **수동 선택** 모드가 됐고, **도움말** 탭은 헤더의 **?** 버튼으로 옮겨졌습니다.

수동 선택 모드의 출력 파일명은 **`_Isolation` 접미사를 그대로 유지**하므로, 이전에 만든 마스크와 이름이 어긋나지 않습니다.
:::

## 새 기능

- **레이어 스택 프리뷰 / 최종 굽기** — 어느 탭에서든 **Load** 하면 바로 프리뷰가 켜지고, 탭을 바꿔도 앞 탭 결과가 씬에 남아 겹쳐 보입니다. 탭 바 아래에 **대상 줄**(Target · Load · 새로고침 · Preview)과 **레이어 줄**이 고정되며, 레이어마다 표시 체크박스 · 블렌드(`Max`/`Add`/`Multiply`/`Subtract`/`Replace`) · 불투명도를 조절합니다. **최종 굽기**는 보이는 그대로를 `<메쉬>_<머티리얼>_Final.png`(컬러 레이어가 있으면 `_FinalColor.png` 추가)로 저장합니다. 탭별 **Bake** 는 "이 레이어만 굽기"로 남습니다. → [문서](/concepts/layer-stack)
- **원본 셰이더 위에 겹쳐 보이는 프리뷰** — 씬 뷰 프리뷰가 전용 프리뷰 셰이더로 갈아끼우지 않고, **원본 셰이더를 그대로 쓰면서 베이스맵 위에 마스크를 겹쳐** 보여줍니다. 아바타가 평소 모습 그대로 보인 채 마스크만 얹혀 확인됩니다. → [문서](/concepts/layer-stack)
- **슬롯 분리 — 합치기 모드** — 탭 상단의 **분리** / **합치기** 토글로 분리의 역작업을 합니다. 합칠 슬롯을 카드 체크박스(베이스맵 썸네일)나 씬 뷰 `Ctrl` + 클릭으로 2개 이상 고르고 **남길 머티리얼**을 지정하면, `*_merged.asset` 새 메쉬를 저장하고 렌더러를 교체합니다. 베이스맵이 다르거나 UV가 겹치면 경고만 하고 막지는 않습니다. 원본 에셋은 그대로이고 `Ctrl+Z` 로 메쉬와 머티리얼 배열이 함께 돌아가며, 같은 메쉬를 쓰는 다른 렌더러도 함께 리바인드됩니다. 분리 모드에 미적용 변경이 있으면 잠깁니다. → [문서](/tabs/slot-split#합치기-모드)
- **액션 바** — 헤더 바로 아래에 **Load · Preview · 편집 메쉬만 · Undo · Redo · 최종 굽기 · 저장 · 다른 이름** 한 줄이 생겼습니다. 자주 쓰는 동작이 탭마다 다른 자리에 흩어져 있지 않습니다. **편집 메쉬만**은 씬 뷰에 로드된 대상만 남기는 비파괴 격리입니다. → [문서](/getting-started/first-mask)
- **툴에서 문서로 바로 가기** — 헤더의 **Docs** 버튼(현재 탭 페이지), 카드 제목 옆의 작은 **?** 버튼(그 기능 페이지, 마우스를 올리면 한 줄 설명), 헤더의 버전 라벨 **v0.1.1**(이 패치노트). 링크는 툴에서 고른 언어를 따라갑니다.
- **씬 클릭 잠금** — 프리뷰 중에는 씬 뷰의 일반 좌클릭이 다른 오브젝트를 선택하지 않습니다 (`Alt` + 드래그 씬 회전, `Ctrl` 클릭/드래그는 그대로). → [문서](/reference/hotkeys)
- **프리뷰 복구** — 프리뷰 머티리얼이 메쉬에 남았을 때 창을 다시 열면 자동으로 원복하고, 헤더의 **?** 도움말 화면 위쪽의 **프리뷰 복구** 버튼으로도 되돌립니다. → [문서](/troubleshooting)
- **페인트 탭** — 씬 뷰 메쉬 위에 브러시로 직접 그려 마스크/컬러 텍스처를 만드는 블렌더 스타일 텍스처 페인트. 그리기/지우기/부드럽게/채우기, 정면 각도 제한, 차폐, 대칭, 스텐실 텍스처링, 내장 스텐실 8종, 자동 저장 복원. → [문서](/tabs/paint)
- **MatCap 광택 — AO(캐비티) 서브모드** — 메쉬 오목한 부분만으로 음영 마스크를 굽습니다. 씬 뷰 각도와 무관하며 **프리뷰 베이크** 버튼으로 확인합니다. → [문서](/tabs/matcap-gloss)
- **페인트로 다듬기** — MatCap 베이크 결과를 페인트 탭으로 넘겨 손으로 이어 그립니다. → [문서](/tabs/paint)
- **그라데이션 — 기준 본** — 시작/끝점이 본을 따라가 포즈가 바뀐 아바타에서도 위치를 유지하고, 프리셋이 다른 아바타에서도 같은 이름의 본을 재검색합니다. → [문서](/tabs/gradient)
- **브릿지+영역마스크 — 선택 편집** — 전체 선택 / 전체 해제 / 선택 반전 / 선택 확장, **최근 시드** 기록, 페인트 탭으로 보내기. → [문서](/tabs/bridge-mask)
- **슬롯 분리 — 안전장치** — **새로고침**, **이동 초기화**/**구조 초기화** 분리, **적용 계획** 카드, **새 슬롯에 머티리얼 복제** 옵션, 적용 후 자동 프리뷰 재시작. → [문서](/tabs/slot-split)
- **컴바이너 — 자동 최적화** — 자동 스캔, 썸네일, 그룹 간 드래그 이동, **실행 계획** 카드, 베이크 후 자동 머티리얼 배정. → [문서](/tabs/combiner)
- **컴바이너 — 셰이더 프로파일** — `MaskMakerProfiles/` 폴더의 JSON으로 스캔 대상 슬롯을 직접 정의·확장합니다. 빌트인 내보내기 / 다시 불러오기. → [문서](/tabs/combiner#셰이더-프로파일)
- **머티리얼 슬롯 피커** — 메쉬에 머티리얼 슬롯이 여러 개면 슬롯별 베이스맵 썸네일에서 하나를 골라 베이크/페인트/프리뷰합니다. 출력 파일명은 `<메쉬>_<머티리얼>`. 서브메쉬 수보다 많은 슬롯은 마지막 서브메쉬에 매핑됩니다. → [문서](/getting-started/first-mask)
- **도움말 (헤더 ? 버튼)** — "마스크 텍스처란?", 탭별 용도 표, lilToon/Poiyomi/MingToon/NiloToon 셰이더별 프로퍼티 연결표(이름 클릭 복사), 연결 4단계, FAQ. → [문서](/concepts/what-is-a-mask)

## 변경

- **격리 탭이 브릿지 탭에 통합**됐습니다. 탭 상단의 **랜덤 가닥 / 수동 선택** 모드 토글로 두 동작을 오갑니다. → [문서](/tabs/bridge-mask)
- **도움말이 탭에서 헤더 ? 버튼으로 이동**했습니다. **닫기** 버튼으로 탭 화면으로 돌아갑니다.
- **브릿지 마스크 탭 이름이 브릿지+영역마스크로 바뀌었습니다.** 랜덤 가닥과 수동 선택(영역) 두 쓰임을 이름에 함께 담았습니다. 동작과 출력 파일명은 그대로입니다.
- **프리셋 줄이 한 줄로 정리**됐습니다 — `[프리셋 ▾] [저장] [삭제] [?]`.
- 위 두 변경으로 탭 구성이 6개(**MatCap 광택 · 그라데이션 · 브릿지+영역마스크 · 슬롯 분리 · 컴바이너 · 페인트**)로 정리됐습니다.
- **대상 줄이 탭 바 바로 아래로 이동**해 고정됐습니다. 스크롤 밖이라 탭이 무엇이든 같은 자리입니다.
- **Preview / Stop 버튼의 의미가 "그 탭 레이어의 표시 / 숨김"으로 바뀌었습니다.** 끄더라도 레이어는 남아 있어 다시 켜면 그대로 돌아옵니다.
- **머티리얼 연결 기능의 위치를 분명히 했습니다.** 이 툴의 본체는 마스크를 만드는 것이고, 브릿지+영역마스크의 **베이크 후 머티리얼에 자동 배정**(기본 꺼짐)과 컴바이너의 **합치기 + 재배정**(실행 전 계획 표시)은 선택 보조 기능이며 둘 다 `Ctrl+Z` 한 번으로 되돌아갑니다.

## 개선

- 씬 뷰 선택이 **Ctrl+클릭 / Ctrl+드래그 페인트 / Ctrl+Shift+드래그 박스 선택**으로 전 탭 표준화. → [문서](/reference/hotkeys)
- 씬 뷰 편집에 **Ctrl+Z / Ctrl+Y** 실행취소/다시실행 적용.
- 저장 시 **덮어쓰기 확인** (덮어쓰기 / 새 이름 / 취소).
- Hierarchy 선택 변경 시 **자동 다시 로드** + 씬 힌트 표시.
- 각 탭에 **최근 베이크** 목록 추가.

## 지원 환경

Unity 2019.4 LTS ~ 2022.3 · Built-in RP / URP.

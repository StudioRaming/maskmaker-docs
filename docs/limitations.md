# 알려진 제약

**이 문서를 읽으면** Mask Maker가 하지 않는 일과 설계상 정해진 경계를 미리 알 수 있습니다. 여기 적힌 것은 버그가 아니라 의도된 동작입니다.

## 환경

| 항목 | 범위 |
|---|---|
| Unity | 2019.4 ~ Unity 6 (6000.0, 6000.3 LTS) |
| 렌더 파이프라인 | Built-in RP · URP |
| 실행 시점 | Editor 전용. 런타임 API는 없습니다 |
| 플랫폼 | 에디터가 도는 환경 (Windows에서 개발·검증) |

## 재생 중

- **Play 중에는 불러오기, 편집, 레이어 추가가 꺼집니다.** Play 중에 바꾼 내용은 보관되지 않기 때문입니다.
- Play를 끝내면 이어서 작업할 수 있습니다.

## 메모리 복구

- 복구 파일을 쓰지 못하면 긴급 사본은 메모리에만 있습니다. 이 사본은 Unity 프로세스가 끝나거나 강제 종료되면 사라집니다.
- **저장하지 않고 종료**를 직접 고르면 메모리에만 있던 작업은 사라집니다.

## 셰이더

- 자동 연결은 **마스크를 꽂는 대상 셰이더의 프로퍼티 이름**을 기준으로 합니다. 이름이 맞지 않는 셰이더에는 직접 꽂아야 합니다.

## 전문가 도구 (컴바이너, 슬롯 분리)

- 참조 머티리얼이 **50개를 넘으면 선택이 바뀔 때 자동 재스캔이 꺼집니다.** 그때는 **다시 스캔** 버튼을 직접 눌러야 합니다.
- 이미 팩된 것으로 보이는 텍스처와 머티리얼이 **A 채널을 쓰는** 텍스처는 **자동 제외**됩니다. 제외된 항목은 사유가 표시됩니다.
- **원본 마스크 파일은 삭제하지 않습니다.** 결과를 확인한 뒤 직접 정리해야 합니다.
- lilToon 슬롯은 R 고정 샘플링이라 **한 팩에 하나만** 들어갑니다.
- 슬롯 분리는 **서브메쉬 배정만** 바꿉니다. 메쉬를 실제로 잘라 정점을 나누지 않습니다.
- 슬롯 분리의 덮어쓰기는 **Mask Maker가 만든 출력만** 대상입니다. 외부 파일, 소유 표식이 없는 파일, 원본이 다른 파일은 덮어쓰지 않습니다.

## 칠하기

- 대칭(미러) 칠하기는 **모델이 좌우 대칭일 때** 의미가 있습니다. 비대칭 UV에서는 반대쪽이 어긋납니다.
- 지원하지 않는 머티리얼은 PNG로 내보낸 뒤 직접 넣어야 합니다. 툴이 텍스처를 자동으로 대입하지 않습니다.

## 그라데이션과 브릿지

- 그라데이션의 **기준 본**을 지정하면 시작점과 끝점이 그 본을 따라 움직입니다. 본을 찾지 못하면 그라데이션은 월드 위치로 굽습니다.
- 브릿지의 **틴트 (프리뷰)**는 프리뷰에만 쓰입니다. 저장되는 마스크는 항상 흑백입니다.

## 설정

- 탭의 조정 값과 설정은 `EditorPrefs`에 **에디터 전역**으로 저장됩니다. 다른 프로젝트에서 만진 값이 넘어옵니다.
- 사용자 셰이더 프로파일은 `<프로젝트>/MaskMakerProfiles/`에 있어 프로젝트를 옮기면 따라옵니다.

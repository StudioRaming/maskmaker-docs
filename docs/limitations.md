# 알려진 제약

**이 문서를 읽으면** Mask Maker가 하지 않는 일과 설계상 정해진 경계를 미리 알 수 있습니다. 여기 적힌 것은 버그가 아니라 의도된 동작입니다.

## 환경

| 항목 | 범위 |
|---|---|
| Unity | 2019.4 LTS ~ 2022.3. 그 밖의 버전은 검증되지 않았습니다 |
| 렌더 파이프라인 | Built-in RP · URP. **HDRP는 지원 대상이 아닙니다** |
| 실행 시점 | Editor 전용. 런타임 API는 없습니다 |
| 플랫폼 | 에디터가 도는 환경 (Windows에서 개발·검증) |

## 셰이더

- 자동 배정과 자동 최적화가 **아는 셰이더는 NiloToon · Poiyomi 9.x · lilToon 세 종류**입니다. MingToon은 연결표에만 있고 빌트인 스캔 프로파일에는 포함되지 않습니다.
- 그 밖의 셰이더에도 마스크를 만들어 **직접 꽂을 수 있습니다.** 자동 스캔·재배정만 되지 않으며, [셰이더 프로파일 JSON](/tabs/combiner#셰이더-프로파일)으로 추가할 수 있습니다.
- Poiyomi 머티리얼이 **Locked In** 상태면 프로퍼티가 갱신되지 않습니다. 먼저 Unlock 하세요.

## 컴바이너

- 참조 머티리얼이 **50개를 넘으면 자동 스캔이 꺼집니다.** **스캔** 버튼을 직접 눌러야 합니다.
- 이미 패킹된 텍스처 · 비그레이스케일 텍스처 · 여러 채널로 참조되는 텍스처는 **자동 제외**됩니다. 필요하면 수동으로 포함할 수 있습니다.
- **원본 마스크 파일은 삭제하지 않습니다.** 결과를 확인한 뒤 직접 정리해야 합니다.
- lilToon 슬롯은 R 고정 샘플링이라 **한 팩에 하나만** 들어갑니다.
- 해상도가 섞이면 큰 쪽으로 리사이즈합니다. **종횡비가 섞이면 경고만 하고 진행**합니다 — 결과를 눈으로 확인하세요.

## 슬롯 분리

- **Mask Maker가 만든 출력만** GUID를 유지해 덮어씁니다. 외부 파일 · 소유 표식이 없는 파일 · 원본이 다른 파일은 덮어쓰지 않습니다.
- 새 슬롯에는 기본적으로 **원본 슬롯과 같은 머티리얼**이 배정됩니다.
- 분리는 **서브메쉬 배정만** 바꿉니다. 메쉬를 실제로 잘라 정점을 나누지 않습니다.

## 페인트

- 자동 저장은 `<프로젝트>/Library/MaskMakerAutoSave/`에 있습니다. **`Library`는 캐시 폴더**라 지우거나 프로젝트를 복사해 옮기면 사라집니다. 백업이 아닙니다.
- 대칭(미러) 페인트는 **모델이 좌우 대칭일 때** 의미가 있습니다. 비대칭 UV에서는 반대쪽이 어긋납니다.
- 차폐를 끄면 X-Ray로 관통해 칠해집니다. 의도한 동작이지만, 켜고 끄는 것을 잊으면 뒷면이 함께 칠해집니다.

## MatCap 광택

- **광택 모드**는 현재 씬 뷰 시점 기준으로 굽습니다. 각도를 바꾸면 결과가 달라집니다.
- **AO(캐비티) 모드**는 씬 뷰 각도와 무관하지만, 실시간 프리뷰가 아니라 **프리뷰 베이크** 버튼으로 확인합니다.
- Preview가 꺼져 있으면 핸들을 편집할 수 없습니다.

## 그라데이션

- 결과물은 마스크가 아니라 **컬러 텍스처(sRGB)** 입니다. 마스크 슬롯에 그대로 꽂으면 안 됩니다.
- [기준 본](/tabs/gradient#기준-본)을 지정하지 않으면 포즈가 바뀔 때 위치가 어긋납니다.
- 프리셋을 다른 아바타에 적용할 때 **같은 이름의 본이 없으면** 월드 좌표로 대체됩니다.

## 브릿지+영역마스크

- 선택 상태는 **Load 시 초기화**됩니다. 모드 전환이나 프리뷰 껐다 켜기로는 사라지지 않습니다.
- 틴트 색은 **프리뷰 전용**입니다. 저장되는 마스크는 항상 흑백입니다.
- 수동 선택 모드의 출력 파일명은 **`_Isolation` 접미사**를 유지합니다 (기존 작업 파일과의 호환).
- 자동 배정은 **NiloToon 스태킹 레이어** 슬롯을 대상으로 합니다.

## 설정

- 탭의 조정 값은 `EditorPrefs`에 **에디터 전역**으로 저장됩니다. 다른 프로젝트에서 만진 값이 넘어옵니다.
- 사용자 셰이더 프로파일은 `<프로젝트>/MaskMakerProfiles/`에 있어 프로젝트를 옮기면 따라옵니다. `EditorPrefs`는 따라오지 않습니다.

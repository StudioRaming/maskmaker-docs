# 단축키

**이 문서를 읽으면** 씬 뷰에서 쓰는 모든 키를 한 화면에서 볼 수 있습니다.

## 클릭 선택 탭 공통

[브릿지 마스크](/tabs/bridge-mask) · [슬롯 분리](/tabs/slot-split)에서 동일하게 동작합니다.

| 조작 | 결과 |
|---|---|
| `Ctrl` + 클릭 | 가닥 추가 / 해제 |
| `Ctrl` + 드래그 | 지나가는 가닥을 페인트처럼 토글 |
| `Ctrl+Shift` + 드래그 | 박스로 **추가** 선택 |
| `Ctrl+Shift+Alt` + 드래그 | 박스로 **선택 해제** |
| 그냥 클릭 | **프리뷰 중에는 다른 오브젝트가 선택되지 않습니다.** 프리뷰를 끄면 평소처럼 씬 오브젝트를 선택합니다 |
| `Ctrl+Z` / `Ctrl+Y` | 실행취소 / 다시실행 |

앞/뒷면과 미러 가닥은 자동으로 함께 토글되고, 상태줄에 몇 개가 같이 토글됐는지 표시됩니다.

:::note[프리뷰 중 씬 클릭 잠금]
프리뷰가 켜져 있는 동안 씬 뷰의 일반 좌클릭은 다른 오브젝트로 새어 나가지 않습니다 — 작업하던 대상이 클릭 한 번에 바뀌는 것을 막기 위해서입니다. `Alt` + 드래그 씬 회전은 그대로 동작하고, `Ctrl` 클릭/드래그의 의미도 바뀌지 않습니다.
:::

## 페인트 탭

씬 뷰에서 **그냥 좌클릭 드래그**하면 칠해집니다. `Ctrl`이 필요 없고, `Alt`는 평소처럼 카메라 회전입니다.

### 브러시

| 키 | 하는 일 |
|---|---|
| `[` | 반경 줄이기 |
| `]` | 반경 키우기 |
| `<` 또는 `,` | 강도 줄이기 |
| `>` 또는 `.` | 강도 키우기 |
| `F` + 드래그 | 반경 모달 조절 |
| `Shift+F` + 드래그 | 강도 모달 조절 |

`<` `>` 와 `,` `.` 는 **같은 기능**입니다. 키보드 배열에 따라 편한 쪽을 쓰세요. 값은 GUI 슬라이더에 즉시 반영됩니다.

### 도구

| 키 | 하는 일 |
|---|---|
| `S` | 스포이드 — 베이스 텍스처의 색 추출 |
| `X` | 색/값 교체 |
| `Ctrl` + 클릭 | 채우기 도구 실행 (다른 도구 중이면 임시 채우기) |
| `Ctrl+Z` / `Ctrl+Y` | **스트로크 단위** 실행취소 / 다시실행 |

### 스텐실

| 키 | 하는 일 |
|---|---|
| `T` + 드래그 | 이동 |
| `Shift+T` + 드래그 | 크기 |
| `Ctrl+T` + 드래그 | 회전 |
| `Alt+T` | 화면에 맞춤 |
| 휠 | 크기 조절 |

모서리 핸들로도 직접 조작할 수 있습니다.
→ [페인트 — 스텐실 텍스처링](/tabs/paint#스텐실)

## 핸들 조작 탭

[MatCap 광택](/tabs/matcap-gloss) · [그라데이션](/tabs/gradient)은 씬 뷰 핸들을 마우스로 끕니다. 별도 단축키는 없습니다.

| 탭 | 핸들 |
|---|---|
| MatCap 광택 | 주황 구 = 중심 이동 · 가장자리 노브 = 반경 · 회전 링 = 방향 회전 |
| 그라데이션 | 시작/끝 핸들 = 범위 · 가운데 노브 = 전체 이동 |

:::note[Preview가 꺼져 있으면 핸들을 만질 수 없습니다]
프리뷰가 꺼진 상태에서는 핸들이 흐리게 표시되고 편집되지 않습니다.
:::

## Unity 기본 동작과 겹치지 않게

프리뷰가 꺼져 있으면 Mask Maker는 **일반 좌클릭을 가져가지 않습니다.** 씬 뷰에서 평소처럼 오브젝트를 고르고 기즈모를 쓸 수 있습니다.

프리뷰가 켜져 있는 동안에는 일반 좌클릭만 잠깁니다(다른 오브젝트로 선택이 넘어가지 않음). `Alt` 회전, `F` 포커스 같은 Unity 기본 조작은 그대로 유지됩니다 — 페인트 탭의 `F`만 브러시 반경으로 쓰입니다.

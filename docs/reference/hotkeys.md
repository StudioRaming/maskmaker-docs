# 단축키

**이 문서를 읽으면** Mask Maker에서 쓰는 키를 한 화면에서 볼 수 있습니다.

## 공통

| 조작 | 결과 |
|---|---|
| `Ctrl+Z` / `Ctrl+Y` | 실행취소 / 다시실행. 한 단계는 적용 한 번, 선택 변경 한 번, 획 하나입니다 |
| `Space` (누른 채 드래그) | UV 캔버스를 옮깁니다 |
| `Tab` | 편집을 켜거나 끕니다 (글자 입력 중에는 동작하지 않습니다) |
| `Esc` | 진행 중인 드래그나 획을 취소합니다 |

## 씬 뷰 칠하기

칠하기 도구가 켜진 씬 뷰에서 쓰는 키입니다.

| 키 | 하는 일 |
|---|---|
| `1` / `2` / `3` / `4` | 칠하기 도구 선택: 그리기 / 지우기 / 부드럽게 / 채우기 |
| `X` | 칠하기 값을 바꿉니다 (흰색 1 ↔ 검정 0) |
| `S` (누르고 있는 동안) | 스포이드. 씬 뷰에서 누르면 색을 집고, 키에서 손을 떼면 해제됩니다 |
| `[` / `]` | 브러시 크기 ×0.9 / ÷0.9 |
| `,` / `.` | 브러시 강도 -0.05 / +0.05 |
| `F` | 반경 조절. 누른 채 움직여 크기를 바꿉니다 |
| `Shift+F` | 강도 조절 |

## UV 캔버스

| 조작 | 결과 |
|---|---|
| `1` / `2` / `3` / `4` | 선택 단위: 정점 / 엣지 / 면 / 섬. 브러시가 켜져 있으면 무시합니다 |
| `A` / `Alt+A` | 모두 선택 / 선택 해제 (브러시가 꺼져 있을 때) |
| `F` | 캔버스를 화면에 맞춥니다 |
| `X` | 브러시가 켜져 있으면 브러시 값을 0 / 1로 바꿉니다 |
| 클릭 | 선택을 바꿉니다 |
| `Shift` + 클릭 | 선택에 더합니다 |
| `Ctrl` + 클릭 · 드래그 | 선택을 토글하거나 선택에서 뺍니다 |

## 브릿지 (씬 뷰 가닥 고르기)

| 조작 | 결과 |
|---|---|
| `Ctrl` + 클릭 | 가닥 하나를 추가 / 해제 |
| `Ctrl` + 드래그 | 지나가는 가닥을 페인트처럼 토글 |
| `Ctrl+Shift` + 드래그 | 사각형 안 가닥을 박스로 추가 선택 |
| `Ctrl+Shift+Alt` + 드래그 | 사각형 안 가닥을 박스로 선택 해제 |
| `Alt` + 드래그 (`Ctrl` 없이) | 씬 궤도 회전 (Unity 기본) |

가닥에 마우스를 올리면 결과가 색으로 미리 보입니다.

| 하이라이트 | 뜻 |
|---|---|
| **시안** (`#33E5FF`) | 아직 고르지 않은 가닥. `Ctrl` + 클릭하면 추가됩니다 |
| **빨강** (`#FF4033`) | 이미 고른 가닥. `Ctrl` + 클릭하면 빠집니다 |

앞면과 뒷면, UV가 겹치는 미러 가닥은 함께 토글되고, 상태줄에 몇 개가 같이 토글됐는지 표시됩니다.

## 프리뷰 중 씬 클릭

프리뷰가 켜져 있는 동안 씬 뷰의 일반 좌클릭은 다른 오브젝트를 고르지 않습니다. `Alt` 회전과 `Ctrl` 클릭의 의미는 바뀌지 않습니다.

## 스텐실

전문가 쪽 스텐실 탭에서 `T`를 누른 채 드래그하면 스텐실이 움직입니다. `Ctrl`을 누르면 회전, `Shift`를 누르면 크기를 바꿉니다. 스텐실은 2.0 마스크 만들기 방법 목록에 없습니다.

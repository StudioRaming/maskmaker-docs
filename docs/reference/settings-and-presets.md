# 설정과 프리셋

**이 문서를 읽으면** Mask Maker가 무엇을 어디에 저장하는지, 무엇이 프로젝트를 옮겨도 따라오고 무엇이 안 따라오는지 알 수 있습니다.

## 저장 위치 한눈에

| 데이터 | 위치 | 프로젝트를 옮기면 | 패키지를 업데이트하면 |
|---|---|---|---|
| 조정 값과 설정 | `EditorPrefs` (에디터 전역) | 안 따라옴 | 유지 |
| 세션 임시 상태 | `SessionState` (에디터를 닫으면 사라짐) | - | - |
| 사용자 셰이더 프로파일 (컴바이너) | `<프로젝트>/MaskMakerProfiles/*.json` | **따라옴** | **유지** |
| 복구 데이터, 문서 백업, 출력 복구 사본 | `<프로젝트>/Library/StudioRaming/MaskMaker/` | 안 따라옴 (`Library`는 캐시) | 유지 |
| 출력한 텍스처와 메쉬 | 원본 텍스처 폴더 (`Assets` 안) | **따라옴** | **유지** |

## Library 아래 폴더

| 폴더 | 무엇을 담나 |
|---|---|
| `Recovery/` | 비정상 종료 뒤 복원할 작업 (복구 배너) |
| `DocumentBackups/` | 옛 형식 문서를 새 형식으로 바꾸기 전의 원본 백업 |
| `OutputRecovery/` | 출력 파일을 쓰는 도중의 복구 사본 |
| `TextureBackups/` | 씬 세션에서 PNG를 덮어쓰기 전의 원본 |
| `SlotSplitUndo/` | 슬롯 분리 작업의 실행취소 기록 |

:::danger[Library는 캐시 폴더입니다]
`Library`를 지우거나 프로젝트를 복사해 옮기면 복구 데이터는 사라집니다. **완성된 작업은 반드시 저장하세요.** 복구는 사고 대비용이지 백업이 아닙니다.
:::

## EditorPrefs

조정 값은 **에디터 전역**으로 기억됩니다. 프로젝트를 바꿔도 같은 값으로 시작합니다. 주요 항목은 다음과 같습니다.

| 항목 | 기억하는 것 |
|---|---|
| 칠하기 **차폐** 옵션 | 칠하기 패널에서 마지막으로 고른 값 (기본 켜짐) |
| 브릿지 **베이크 후 자동 배정** | 기본 꺼짐 |
| 브릿지 프리셋 목록 | 저장한 브릿지 프리셋 (랜덤 / 수동 모드별) |
| 도움말 표시 | 창의 도움말 표시 여부 |

:::note[값이 이상해졌다면]
`EditorPrefs`는 Unity 에디터 전체에 걸린 저장소입니다. 다른 프로젝트에서 만진 값이 그대로 넘어옵니다. 조정 항목을 하나씩 되돌리는 것이 가장 빠릅니다.
:::

## 셰이더 프로파일 폴더 (컴바이너)

| 항목 | 값 |
|---|---|
| 경로 | `<프로젝트>/MaskMakerProfiles/*.json` |
| `Assets` 바깥인 이유 | 패키지를 업데이트해도 지워지지 않게 하기 위해서입니다 |
| 읽는 시점 | 최초 스캔 1회, 또는 **빌트인 내보내기 / 다시 불러오기** 버튼을 눌렀을 때만 |
| 이름 충돌 | 빌트인과 같은 이름이면 그 자리에서 덮어씁니다. 경고 행으로 알려 줍니다 |

스키마와 예제는 → [컴바이너: 셰이더 프로파일](/tabs/combiner#셰이더-프로파일)

## 프리셋

**프리셋 줄**은 맷캡 광택, 그라데이션, 브릿지 탭에 있습니다. 줄의 드롭다운에서 고른 프리셋을 **저장**(덮어쓰기)하거나 **삭제**할 수 있고, `-`를 고른 채 저장하면 자동 이름으로 새 프리셋이 됩니다.

- 브릿지는 **랜덤 가닥**과 **수동 선택** 모드마다 목록이 따로 있습니다.
- 프리셋 이름만으로는 구분되지 않습니다. 모드가 다르면 다른 프리셋입니다.

## 덮어쓰기 확인

출력할 때 같은 이름의 파일이 있으면 **덮어쓰기 / 새 이름 / 취소**를 묻습니다. 실수로 덮어써지지 않습니다.

## 최근 작업

헤더의 **최근 작업**에서 이번 세션에 저장한 파일을 찾을 수 있습니다. Project 창에서 찾거나 폴더를 열 수 있습니다.

## 1.x 자동 저장 기록

1.x가 쓰던 `Library/MaskMakerAutoSave/` 아래의 자동 저장 캔버스는 **같은 프로젝트에 남아 있을 때** 2.0이 한 번 가져옵니다. 파일을 칠하기 복구 폴더(`Library/StudioRaming/MaskMaker/Recovery/Paint/` 아래)로 옮기고 이름 앞에 `legacy_`를 붙이며, 옛 EditorPrefs 키는 지웁니다. 옮기지 못하면 콘솔에 경고가 남습니다.

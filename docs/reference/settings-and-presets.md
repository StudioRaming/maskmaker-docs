# 설정과 프리셋

**이 문서를 읽으면** Mask Maker가 무엇을 어디에 저장하는지, 무엇이 프로젝트를 옮겨도 따라오고 무엇이 안 따라오는지 알 수 있습니다.

## 저장 위치 한눈에

| 데이터 | 위치 | 프로젝트를 옮기면 | 패키지를 업데이트하면 |
|---|---|---|---|
| 탭별 마지막 값 (슬라이더·토글·모드) | `EditorPrefs` (에디터 전역) | 안 따라옴 | 유지 |
| 세션 임시 상태 | `SessionState` (에디터를 닫으면 사라짐) | — | — |
| 사용자 셰이더 프로파일 | `<프로젝트>/MaskMakerProfiles/*.json` | **따라옴** | **유지** |
| 페인트 자동 저장 캔버스 | `<프로젝트>/Library/MaskMakerAutoSave/` | 안 따라옴 (`Library`는 캐시) | 유지 |
| 구운 텍스처·메쉬 | 원본 텍스처 폴더 (`Assets` 안) | **따라옴** | **유지** |

## EditorPrefs — 값 기억

각 탭의 조정 항목은 **에디터 전역**으로 기억됩니다. 프로젝트를 바꿔도 같은 값으로 시작합니다.

| 기억되는 것 | 예 |
|---|---|
| MatCap 광택 | 세기 · 대비 · 둥근정도 · dilate 픽셀 · 광택/AO 서브모드 · 캐비티 반경/샘플/세기/대비/반전 |
| 그라데이션 | 축 · 중심 · 부드러움 · 채움 방향 · 끝처리 · 프리뷰 표시 방식 |
| 브릿지+영역마스크 | 비율 · 그라데이션/엣지 페이드 · 뒷면 모드 · 베이크 후 자동 배정 · 대상 프로퍼티 |
| 슬롯 분리 | 새 슬롯에 머티리얼 복제 |
| 컴바이너 | lilToon 알파 베이크 · 저장 전 덮어쓰기 확인 |
| 페인트 | 브러시 반경 · 강도 · 폴오프 · 정면 각도 제한 · 미러 축 · 캔버스 크기 · 마스크/컬러 모드 |
| 공통 | 언어 · Hierarchy 선택 변경 시 자동 로드 |

:::note[값이 이상해졌다면]
`EditorPrefs`는 Unity 에디터 전체에 걸린 저장소입니다. 다른 프로젝트에서 만진 값이 그대로 넘어옵니다. 탭의 조정 항목을 하나씩 되돌리는 것이 가장 빠릅니다.
:::

## 프리셋

| 탭 | 프리셋에 담기는 것 |
|---|---|
| MatCap 광택 | 글로벌 방향 · 구 크기 · 세기/대비 등 세팅 전체 |
| 그라데이션 | 색상 · 축 · 범위 · **기준 본 이름** |

프리셋 줄은 카드 위에 한 줄로 있습니다 — **[프리셋 ▾]** (현재 프리셋 이름, 없으면 `-`) **[저장]** **[삭제]** **[?]**. 맨 오른쪽 **?** 를 누르면 이 페이지가 열립니다.

프리셋을 다른 메쉬나 다른 아바타에 적용하면 같은 세팅이 그대로 재현됩니다. 그라데이션 프리셋은 [기준 본](/tabs/gradient#기준-본)을 **이름으로 다시 찾습니다** — 같은 이름의 본이 없으면 월드 좌표로 대체합니다.

## 셰이더 프로파일 폴더

| 항목 | 값 |
|---|---|
| 경로 | `<프로젝트>/MaskMakerProfiles/*.json` |
| `Assets` 바깥인 이유 | 패키지를 업데이트해도 지워지지 않게 하기 위해서입니다 |
| 읽는 시점 | 최초 스캔 1회 또는 **빌트인 내보내기 / 다시 불러오기** 버튼을 눌렀을 때만 |
| 이름 충돌 | 빌트인과 같은 이름이면 **그 자리에서 덮어씁니다**(매칭 우선순위 유지). 경고 행으로 알려 줍니다 |

스키마와 예제는 → [컴바이너 — 셰이더 프로파일](/tabs/combiner#셰이더-프로파일)

## 페인트 자동 저장

| 항목 | 값 |
|---|---|
| 경로 | `<프로젝트>/Library/MaskMakerAutoSave/` |
| 저장되는 때 | 프리뷰 중단 · 리컴파일 · 플레이모드 전환 · 씬 전환 시 저장하지 않은 캔버스가 있을 때 |
| 복원 | 다음 **Load** 시 **복원 / 버리기 / 취소**를 물어봅니다 |
| 삭제 | 실제 저장에 성공하면 임시 파일이 지워집니다 |

파일 이름은 세션마다 고정된 GUID를 씁니다 — 전환할 때마다 새 파일을 만들지 않으므로 4K PNG가 쌓이지 않습니다.

:::danger[Library는 캐시 폴더입니다]
`Library`를 지우거나 프로젝트를 복사해 옮기면 자동 저장 캔버스는 사라집니다. **완성된 작업은 반드시 저장하세요.** 자동 저장은 사고 복구용이지 백업이 아닙니다.
:::

## 덮어쓰기 확인

저장 시 같은 이름의 파일이 있으면 **덮어쓰기 / 새 이름 / 취소**를 묻습니다. 실수로 덮어써지지 않습니다.

컴바이너의 수동 저장은 **저장 전 덮어쓰기 확인** 옵션으로 매번 물어보게 할 수 있습니다.

## 최근 베이크

각 베이크 탭 하단에 저장한 텍스처 목록이 남습니다. **핑(찾기)** 으로 프로젝트 창에서 강조하거나 **폴더 열기**로 탐색기를 엽니다.

## 초기화

| 되돌리고 싶은 것 | 방법 |
|---|---|
| 탭의 조정 값 | 각 항목을 직접 되돌립니다 |
| 슬롯 분리의 가닥 이동 | **이동 초기화** |
| 슬롯 분리의 슬롯 구성 | **구조 초기화** |
| 컴바이너 스캔 결과 | **다시 스캔** |
| 씬 뷰 편집 전반 | `Ctrl+Z` |

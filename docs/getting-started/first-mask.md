# 첫 마스크 만들기

**이 문서를 읽으면** Load에서 셰이더 슬롯까지 한 번에 통과하는 전체 흐름을 알 수 있습니다. 어느 탭을 쓰든 이 다섯 단계는 같습니다.

## 전체 흐름

**오브젝트 선택 → Load(프리뷰 자동 시작) → 머티리얼 슬롯 고르기 → 씬 뷰에서 조정 → Bake 또는 최종 굽기 → 셰이더에 꽂기**

<!-- SCREENSHOT: 탭 바 아래 고정된 대상 줄 + 레이어 줄 -->

## 0. 창 구성

스크롤 바깥의 위쪽 네 줄은 어느 탭에서도 같은 자리에 있습니다.

| 줄 | 내용 |
|---|---|
| 헤더 | 오른쪽에 **Docs**(현재 탭의 온라인 설명서) · **?**(내장 도움말) · 언어 · 버전(**v0.1.1**, 클릭하면 패치노트) |
| 액션 바 | **Load** · **Preview** · **편집 메쉬만** · **Undo** · **Redo** · **최종 굽기** · **저장** · **다른 이름** |
| 탭 | 여섯 개의 탭 |
| 대상 줄 · 레이어 줄 | 로드 상태 + 이 슬롯에 쌓인 레이어 |

카드 제목 옆의 작은 **?** 버튼은 마우스를 올리면 한 줄 설명이 뜨고, 누르면 그 기능의 설명서 페이지가 열립니다.

## 1. 오브젝트를 고르고 Load

Hierarchy에서 작업할 오브젝트(보통 헤어 또는 몸체)를 고르고 액션 바의 **Load**를 누릅니다. 여러 개를 함께 골라도 됩니다. **Load 하면 프리뷰가 바로 시작됩니다** — 별도로 **Preview**를 누르지 않아도 됩니다. **편집 메쉬만**을 켜면 씬 뷰에 로드된 대상만 남겨 가려짐 없이 작업합니다(비파괴, 끄면 원래대로).

Load 이후 Hierarchy 선택이 바뀌면 씬 뷰에 **"선택이 바뀜 — 다시 로드"** 힌트가 뜹니다. 프리뷰 중이 아니면 자동으로 다시 로드됩니다. **새로고침**은 Hierarchy 선택과 무관하게 지금 로드된 메쉬만 다시 읽습니다.

## 2. 머티리얼 슬롯 고르기 {#머티리얼-슬롯-피커}

메쉬에 머티리얼 슬롯이 여러 개면 대상 목록 아래에 **슬롯별 베이스맵 썸네일**이 나옵니다. **작업할 슬롯을 하나 골라야 하며**, 그 서브메쉬만 베이크·페인트·프리뷰됩니다.

<!-- SCREENSHOT: 머티리얼 슬롯 피커 썸네일 스트립, 한 슬롯이 선택된 상태 -->

| 항목 | 동작 |
|---|---|
| 나타나는 탭 | MatCap 광택/AO · 그라데이션 · 브릿지+영역마스크 · 페인트 |
| 출력 파일명 | `<메쉬>_<머티리얼>` |
| 서브메쉬보다 슬롯이 많을 때 | 남는 슬롯(lilToon/Poiyomi의 아웃라인 슬롯 등)은 **마지막 서브메쉬**에 매핑됩니다 |

:::note[슬롯이 하나면 이 단계는 보이지 않습니다]
피커는 슬롯이 둘 이상일 때만 나옵니다. 슬롯이 하나면 그 슬롯이 자동으로 대상입니다.
:::

## 3. 프리뷰와 레이어 줄

결과는 씬 뷰의 메쉬에 실시간으로 입혀집니다. 대상 줄 바로 아래의 **레이어 줄**에 이 탭의 결과가 칩 한 줄로 올라옵니다.

- **탭을 바꿔도 앞 탭의 결과는 씬에 남아 겹쳐 보입니다.** 각 탭 결과가 (렌더러 · 머티리얼 슬롯)마다 하나씩 있는 레이어 스택에 쌓이기 때문입니다.
- 액션 바의 **Preview** 는 그 탭의 레이어를 **표시 / 숨김** 하는 토글입니다. 꺼도 레이어는 남아 있으므로 다시 켜면 그대로 돌아옵니다.
- 프리뷰는 **원본 머티리얼을 건드리지 않습니다.** 복제본을 임시로 씌우고 **Stop** 하면 즉시 복원합니다.
- 창을 그냥 닫아도 복원됩니다. 리컴파일·플레이모드 전환에도 복원됩니다.
- 프리뷰가 꺼져 있으면 씬 뷰 핸들(구·그라데이션 시작/끝점)은 흐리게 표시되고 편집할 수 없습니다.

→ [레이어 스택과 최종 굽기](/concepts/layer-stack)

## 4. 씬 뷰에서 조정

탭에 따라 핸들을 끌거나, 가닥을 클릭하거나, 붓으로 칠합니다. 클릭 선택 탭(브릿지+영역마스크·슬롯 분리)은 전부 같은 규칙을 씁니다.

| 조작 | 결과 |
|---|---|
| `Ctrl` + 클릭 | 가닥 추가 / 해제 |
| `Ctrl` + 드래그 | 지나가는 가닥을 페인트처럼 토글 |
| `Ctrl+Shift` + 드래그 | 박스로 추가 선택 |
| `Ctrl+Shift+Alt` + 드래그 | 박스로 선택 해제 |
| 그냥 클릭 | 프리뷰 중에는 **다른 오브젝트가 선택되지 않습니다** (`Alt` + 드래그 씬 회전은 그대로) |
| `Ctrl+Z` / `Ctrl+Y` | 실행취소 / 다시실행 |

전체 목록은 → [단축키](/reference/hotkeys)

## 5. Bake 또는 최종 굽기

| 버튼 | 굽는 것 | 파일명 |
|---|---|---|
| **저장** (또는 탭 안의 **Bake**) | **그 탭의 레이어 한 장만** — 슬롯 분리 탭에서는 적용 | 탭별 규칙 (예: 수동 선택은 `_Isolation`) |
| **다른 이름** | 위와 같지만 파일 이름과 위치를 직접 지정 | 직접 지정 |
| **최종 굽기** | **체크된 레이어 전부를 합친 결과** | `<메쉬>_<머티리얼>_Final.png` (컬러 레이어가 있으면 `_FinalColor.png` 추가) |

**최종 굽기는 씬 뷰에 보이는 그대로를 저장합니다** — 프리뷰와 같은 합성식을 쓰기 때문입니다.

- 저장 위치는 레이어 줄의 **저장 위치** 라벨에 미리 표시됩니다.
- 같은 이름의 파일이 있으면 **덮어쓰기 / 새 이름 / 취소**를 묻습니다. 실수로 덮어써지지 않습니다.
- 저장한 파일은 탭 하단의 **최근 베이크** 목록에서 핑(찾기)이나 폴더 열기로 바로 확인합니다.

<!-- SCREENSHOT: 최근 베이크 목록 — 썸네일 + 핑/폴더 열기 버튼 -->

## 6. 셰이더에 꽂기

굽는 것과 꽂는 것은 별개입니다. 네 단계로 끝납니다.

1. 다른 탭에서 마스크를 **베이크**합니다.
2. 저장된 텍스처를 선택 → Inspector에서 **sRGB (Color Texture) 끄기** → **Apply**.
3. 머티리얼 인스펙터를 열고 해당 **프로퍼티** 슬롯에 텍스처를 드래그해 꽂습니다.
4. 그 슬롯에 **채널 선택**(R/G/B/A)이 있다면 마스크를 구울 때 쓴 채널과 맞춥니다. 컴바이너로 합친 마스크가 아니라면 보통 **R**입니다.

셰이더별 슬롯 이름과 인스펙터 경로는 → [lilToon](/shaders/liltoon) · [Poiyomi](/shaders/poiyomi) · [MingToon](/shaders/mingtoon) · [NiloToon](/shaders/nilotoon)

:::tip[3~4단계를 대신 해주는 선택 기능]
꽂는 일을 툴에 맡기고 싶다면 두 가지 보조 기능이 있습니다. 둘 다 **선택 사항**이고 `Ctrl+Z` 한 번으로 되돌아갑니다.

- 브릿지+영역마스크 탭의 **베이크 후 머티리얼에 자동 배정** — **기본은 꺼져 있습니다.** 켜 두면 저장한 마스크를 고른 슬롯에 연결합니다.
- 컴바이너의 **합치기 + 재배정** — 실행 전에 **실행 계획** 카드로 무엇을 바꿀지 먼저 보여줍니다.
:::

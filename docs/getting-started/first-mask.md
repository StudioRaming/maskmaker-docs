# 첫 마스크 만들기

**이 문서를 읽으면** 모델을 고르고, 마스크를 만들고, 출력해서 셰이더에 꽂기까지의 흐름을 알 수 있습니다.

## 네 단계

1. Hierarchy에서 모델을 고르고 **현재 선택한 대상 사용**을 누릅니다.
2. 오른쪽 패널에서 머티리얼과 고칠 마스크를 고릅니다. 이름이나 셰이더 속성으로 검색할 수 있습니다.
3. **칠하기**를 누르고 씬 뷰의 모델 위를 칠합니다. **이미지 · 그라데이션 · 브릿지 · 맷캡 광택**으로도 만들 수 있습니다.
4. **적용 결과 보기**로 확인한 뒤 **저장·적용**에서 마스크를 출력합니다.

흰색은 값 1, 검정은 0입니다. 각 값의 효과는 연결한 셰이더 기능에 따라 달라집니다.

## 화면 구성

| 영역 | 내용 |
|---|---|
| 넓은 창 | 왼쪽에 캔버스와 도구, 오른쪽에 머티리얼 선택·레이어 목록·열린 마스크 |
| 좁은 창 | 머티리얼 선택, 열린 마스크, 캔버스 순서로 위에서 아래로 이어짐 |
| 열린 마스크 | 작업할 마스크를 바꾸고, 머티리얼 그룹을 펼쳐 다른 마스크를 엽니다 |
| 빈 칸도 보기 | 기본으로 켜져 있어 꺼진 효과와 빈 마스크도 찾을 수 있습니다 |
| 쉽게 시작 | 선택한 마스크의 효과 설정과 씬 뷰 작업에 집중합니다 |
| 전문가 작업 | 레이어, 메쉬, 출력, 도구를 자세히 조절합니다 |
| 최근 작업 | 저장한 파일을 Project 창에서 찾거나 폴더를 엽니다 |

모드를 바꿔도 작업은 그대로 남습니다.

## 보기 바꾸기

**마스크만 보기 · 적용 결과 보기 · 원본 보기** 중 하나를 고릅니다.

- **마스크만 보기**와 **적용 결과 보기**는 씬 편집을 시작합니다.
- **원본 보기**는 씬 편집을 끝냅니다. 원본 보기에서도 마스크 작업은 보관됩니다.
- **적용 결과 보기**에서 마스크를 명시적으로 열면, 꺼져 있던 관련 효과를 켜고 결과를 보여 줍니다. 목록을 보거나 검색하는 것만으로는 효과가 바뀌지 않습니다.
- 아직 아무것도 칠하지 않은 마스크의 미리보기는 검게 보이고(검정은 0), "아직 칠한 곳이 없어요."라는 안내 한 줄이 함께 나옵니다.

## 여러 마스크 편집하기

한 머티리얼의 마스크를 오가며 각각 그릴 수 있습니다. 그림자 마스크를 칠한 뒤 외곽선 마스크를 편집하고 돌아오면, 각 마스크의 그림과 레이어가 그대로 남습니다. R/G/B/A 채널을 고르는 마스크도 채널마다 작업을 따로 보관합니다. Inspector에서 채널을 바꾸면 칠한 작업이 새 채널로 같이 옮겨지고, 새 채널에 이미 작업이 있으면 **옮기기** / **따라가기만**을 묻습니다. 지워지는 작업은 없습니다. → [채널과 패킹](/concepts/channels-and-packing#channel-change)

## 출력하고 셰이더에 꽂기

1. **저장·적용 → 마스크 출력**을 엽니다.
2. 출력 크기와 **외곽선 (px)**을 정합니다.
3. 저장합니다. 흑백 마스크는 sRGB를 끈 상태로 임포트됩니다. 머티리얼이 lilToon, Poiyomi, MingToon, NiloToon 가운데 하나면 선택한 머티리얼 속성에 연결되고, 그 밖의 셰이더는 PNG로 저장되어 직접 꽂아야 합니다.

기본 파일명은 머티리얼, 마스크 속성, 선택한 채널을 구분합니다. 같은 이름의 파일을 덮어쓰기 전에 저장 경로를 확인하세요. 편집 가능한 레이어 문서도 함께 저장됩니다.

셰이더별 슬롯 이름과 인스펙터 경로는 → [lilToon](/shaders/liltoon) · [Poiyomi](/shaders/poiyomi) · [MingToon](/shaders/mingtoon) · [NiloToon](/shaders/nilotoon)

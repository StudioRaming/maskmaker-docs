# 마스크 텍스처란

**이 문서를 읽으면** 셰이더가 마스크를 어떻게 읽는지, 왜 흑백인지, 왜 sRGB를 꺼야 하는지 알 수 있습니다. 툴 안에서는 헤더의 **?** 버튼으로 같은 내용을 볼 수 있습니다.

## 색이 아니라 숫자를 저장하는 그림

마스크 텍스처는 **색을 저장하는 그림이 아니라 '숫자'를 저장하는 그림**입니다. 셰이더는 이 그림의 밝기(0~1)를 픽셀마다 읽어서 **"이 부분에 효과를 얼마나 적용할지"** 를 결정합니다.

| 마스크 값 | 뜻 |
|---|---|
| 검정 (0) | 적용 안 됨 — 원본 그대로 |
| 회색 (0.5) | 절반 적용 |
| 흰색 (1) | 완전 적용 |

그래서 마스크에는 "예쁜 색"이 필요 없습니다. 필요한 것은 **어디가 얼마나 밝은가** 뿐입니다.

## 텍스처 하나에 마스크 네 장

텍스처 한 장은 **R / G / B / A 네 채널**을 갖고 있고, 마스크는 보통 그중 **한 채널만** 씁니다. 그레이스케일 이미지는 R=G=B라서 어느 채널을 읽어도 값이 같습니다.

마스크 네 장을 각각 R, G, B, A에 하나씩 담으면 **파일 한 장에 마스크 네 개**가 들어갑니다. 그 일을 하는 것이 [컴바이너](/tabs/combiner)입니다.
→ [채널과 패킹](/concepts/channels-and-packing)

## 저장할 때 반드시 확인할 것

:::danger[sRGB (Color Texture)를 반드시 꺼야 합니다]
마스크는 색이 아니라 숫자입니다. sRGB 체크가 켜져 있으면 Unity가 감마 보정을 걸어 **숫자값이 틀어집니다.** 0.5로 구운 회색이 셰이더에서 0.5로 읽히지 않습니다.

텍스처를 선택 → Inspector에서 **sRGB (Color Texture) 끄기** → **Apply**.
:::

Mask Maker는 **마스크 출력** 때 흑백 마스크를 sRGB를 끈 상태로 임포트합니다. 외부에서 가져온 마스크를 쓸 때만 직접 확인하면 됩니다.
→ [sRGB와 임포트 설정](/concepts/srgb-and-import-settings)

## 해상도

해상도는 출력 설정의 **텍스처 크기 (Texture Size)**에서 고릅니다. 마스크는 형태의 경계가 중요하므로, 경계가 계단처럼 보이면 해상도를 올리기 전에 **외곽선 (px)** 값을 먼저 확인하세요.
→ [문제 해결](/troubleshooting)

## 어느 방법으로 마스크를 만드나

| 방법 | 만드는 것 | 대표 용도 |
|---|---|---|
| [칠하기](/tabs/paint) | 브러시로 직접 그린 흑백 마스크 | 자동 생성이 안 되는 임의 모양 |
| [이미지](/tabs/image) | 고른 Texture2D | 외부에서 만든 그림 재사용 |
| [그라데이션](/tabs/gradient) | 방향이나 높이에 따라 값이 변하는 흑백 마스크 | 위치 기반 효과 |
| [브릿지](/tabs/bridge-mask) | 고른 헤어 가닥의 흑백 마스크 | 머리카락 일부에만 효과 |
| [MatCap 광택](/tabs/matcap-gloss) | 맷캡 하이라이트를 구운 흑백 마스크 | 광택과 하이라이트 |
| [컴바이너](/tabs/combiner) (전문가 도구) | 마스크 여러 장을 R/G/B/A 한 장으로 합친 것 | 파일 수 줄이기 |

## 셰이더는 마스크를 어디서 읽나

셰이더마다 마스크를 받는 슬롯(프로퍼티)이 다릅니다. 같은 "광택 마스크"라도 lilToon은 `MatCap ▸ Mask`, NiloToon은 `MatCap Additive ▸ Mask Map`에서 읽습니다.

→ [lilToon](/shaders/liltoon) · [Poiyomi](/shaders/poiyomi) · [MingToon](/shaders/mingtoon) · [NiloToon](/shaders/nilotoon)

# 레이어 스택과 최종 굽기

**이 문서를 읽으면** 탭을 옮겨 다니며 만든 결과가 어떻게 한 메쉬 위에 겹쳐 보이는지, 그리고 그 전부를 한 장으로 굽는 **최종 굽기**를 알 수 있습니다.

## 창 위쪽은 전부 고정입니다

스크롤 바깥에 네 줄이 항상 같은 자리에 남습니다 — 어느 탭을 보고 있든 같습니다.

| 줄 | 내용 |
|---|---|
| 헤더 | 제품 이름 · 오른쪽에 **Docs** · **?** · 언어 · 버전(**v0.1.1**, 클릭하면 이 버전 패치노트) |
| 액션 바 | **Load** · **Preview** · **편집 메쉬만** · **Undo** · **Redo** · **최종 굽기** · **저장** · **다른 이름** |
| 탭 | 여섯 개의 탭 |
| 대상 줄 · 레이어 줄 | 지금 무엇이 로드됐는지 + 이 슬롯에 쌓인 레이어 |

창이 좁으면 액션 바는 두 줄로 접힙니다. 탭에 없는 동작의 버튼은 흐리게 비활성됩니다.

**대상 줄**은 지금 상태를 알려주는 표시줄입니다 — `Target: N개 메쉬 로드됨` / `Target: N개 선택됨 (Load를 누르세요)` / `Target: (선택 없음)`. 슬롯 분리 탭에는 **새로고침** 버튼이 함께 있습니다.

## Load 하면 바로 프리뷰가 켜집니다

액션 바의 **Load** 를 누르면 어느 탭에서든 그 자리에서 프리뷰가 시작됩니다.

그리고 **탭을 바꿔도 앞 탭의 프리뷰는 사라지지 않습니다.** 각 탭의 결과는 (렌더러 · 머티리얼 슬롯)마다 하나씩 있는 **레이어 스택**에 쌓이고, 씬 뷰에는 그 스택을 합성한 결과가 보입니다. MatCap 광택을 잡아 두고, 브릿지에서 가닥을 고르고, 페인트로 덧그리면 세 결과가 같은 메쉬 위에 함께 보입니다.

액션 바의 **Preview** 는 그 탭의 레이어를 **표시 / 숨김** 하는 토글입니다. 꺼도 레이어 자체는 남아 있으므로 다시 켜면 그대로 돌아옵니다.

## 레이어 줄

레이어마다 한 줄(칩)이 나옵니다.

| 칩 | 어느 탭에서 올라오나 |
|---|---|
| 맷캡 광택 | [MatCap 광택](/tabs/matcap-gloss) — 광택 모드 |
| 캐비티/AO | [MatCap 광택](/tabs/matcap-gloss) — AO(캐비티) 모드 |
| 브릿지 | [브릿지+영역마스크](/tabs/bridge-mask) — 랜덤 가닥 · 수동 선택 공통 |
| 페인트 마스크 | [페인트](/tabs/paint) — 마스크 모드 |
| 그라데이션 | [그라데이션](/tabs/gradient) |
| 페인트 컬러 | [페인트](/tabs/paint) — 컬러 모드 |

| 항목 | 하는 일 |
|---|---|
| 체크박스 | 이 레이어를 씬 프리뷰와 최종 굽기에 포함할지 여부 |
| 블렌드 | 아래 레이어와 합치는 방식 — `Max` · `Add` · `Multiply` · `Subtract` · `Replace` |
| 불투명도 | 0 ~ 100 |

기본 블렌드는 마스크 계열 레이어가 `Max`, 그라데이션이 `Multiply`, 페인트 컬러가 `Replace` 입니다.

합성 순서는 레이어가 올라온 순서가 아니라 **위 표의 순서로 고정**됩니다 — 탭을 어떤 순서로 켜든 결과가 같습니다.

대상 줄 오른쪽의 **프리뷰 색**은 합성된 마스크를 씬에서 어떤 색으로 덮어 보여줄지만 정합니다. **저장 결과에는 영향이 없습니다.**

:::note[슬롯 분리 프리뷰는 스택에 들어가지 않습니다]
[슬롯 분리](/tabs/slot-split)는 마스크가 아니라 메쉬를 편집하는 탭이라, 슬롯 색 프리뷰는 레이어 위에 따로 덮여 표시됩니다.
:::

## 최종 굽기

액션 바의 **최종 굽기** 버튼은 **체크된 레이어를 전부 합쳐 한 장으로 저장**합니다.

| 저장되는 것 | 파일명 |
|---|---|
| 합성 마스크 | `<메쉬>_<머티리얼>_Final.png` |
| 컬러 (그라데이션·페인트 컬러 레이어가 있을 때만) | `<메쉬>_<머티리얼>_FinalColor.png` |

- 저장 위치는 레이어 줄의 **저장 위치** 라벨에 미리 표시됩니다 (베이스맵이 있는 폴더 → 없으면 머티리얼 폴더 → 그것도 없으면 `Assets`).
- 같은 이름의 파일이 있으면 덮어쓰기 / 새 이름 / 취소를 묻습니다.
- **씬 뷰에 보이는 그대로가 구워집니다.** 프리뷰와 최종 굽기가 같은 합성식을 쓰기 때문입니다.

액션 바의 **저장** 은 **지금 탭의 레이어 한 장만** 굽습니다(슬롯 분리 탭에서는 적용). 이름과 위치를 직접 정하려면 **다른 이름** 을 쓰세요. 탭 안의 **Bake** 버튼도 그대로 동작합니다.

## 대상이 여럿일 때

레이어 스택은 (렌더러 · 머티리얼 슬롯) 단위입니다. 스택이 둘 이상이면 레이어 줄 왼쪽에 **대상 팝업**이 뜹니다. 표시와 최종 굽기는 거기서 고른 대상에 적용됩니다.

→ [머티리얼 슬롯 피커](/getting-started/first-mask#머티리얼-슬롯-피커)

## 프리뷰 중 씬 클릭

프리뷰가 켜져 있는 동안에는 씬 뷰의 **일반 좌클릭이 다른 오브젝트를 선택하지 않습니다.** 작업 중인 메쉬 옆을 눌렀다가 대상이 바뀌는 일을 막기 위한 것입니다. `Alt` + 드래그 씬 회전과 `Ctrl` 클릭/드래그의 의미는 그대로입니다.

→ [단축키](/reference/hotkeys)

## 프리뷰 머티리얼이 씬에 남았을 때

에디터가 강제 종료되는 등으로 프리뷰 해제가 실행되지 못하면, 메쉬에 프리뷰 머티리얼이 남아 흰색으로 보일 수 있습니다.

- 창을 다시 열면 **자동으로 원복**됩니다.
- 창을 열지 않고 되돌리려면 헤더의 **?** 도움말 화면 위쪽의 **프리뷰 복구** 버튼을 누르세요.

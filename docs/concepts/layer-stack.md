# 레이어와 마스크 출력

**이 문서를 읽으면** 마스크 방법들이 레이어로 쌓이고 조합되는 방식, 그리고 마스크를 출력하는 방법을 알 수 있습니다.

## 보기 세 가지

| 보기 | 하는 일 |
|---|---|
| **마스크만 보기** | 마스크 그림만 봅니다. 씬 편집이 시작됩니다 |
| **적용 결과 보기** | 원래 셰이더를 쓰는 미리보기에 작업 마스크를 연결합니다. 씬 편집이 시작됩니다 |
| **원본 보기** | 원래 모습을 봅니다. 씬 편집이 끝나며, 마스크 작업은 보관됩니다 |

보기를 바꿔도 그림은 초기화되지 않습니다.

**적용 결과 보기**의 효과 카드에서 토글과 색상을 바꾸면 실제 머티리얼 설정이 바뀌며, Undo로 되돌릴 수 있습니다.

## 방법 조합 {#방법-조합}

이미 내용이 있는 마스크에 방법을 더하면 기본으로 **범위 제한**을 씁니다.

| 옵션 | 하는 일 |
|---|---|
| **범위 제한** | 기존 내용 안에서만 새 방법의 결과를 씁니다. 기본값입니다 |
| **흰 영역 추가** | 두 방법의 흰 부분을 합칩니다 |
| **이것만 사용** | 선택한 방법의 결과만 보여 줍니다 |

방법 버튼을 다시 누르면 기존 설정으로 돌아갑니다. 같은 작업이 계속 추가되지 않습니다.

예를 들어 브릿지로 고른 가닥 안에만 그라데이션이나 맷캡 광택을 남길 수 있습니다.

## 칠하기로 보정하기

생성 결과 위에서 [칠하기](/tabs/paint)를 하면, **칠한 부분만** 보정으로 남습니다. 칠하지 않은 부분은 이후 그라데이션, 브릿지, 맷캡 광택의 설정을 바꾸면 따라 바뀝니다. 다시 칠하기를 누르면 같은 보정 작업으로 돌아갑니다.

생성기와 입력 이미지 파일은 보관됩니다.

## 레이어 저장 {#레이어-저장}

**레이어 저장**은 고른 레이어 한 장만 따로 저장합니다.

레이어에 연결되지 않은 그림은 기존 레이어를 덮어 쓰지 않고 독립 캔버스로 복원됩니다. 먼저 **레이어 저장**으로 그림을 남긴 뒤 편집할 레이어를 고르세요. 이 경우 씬 편집은 자동으로 켜지지 않으며, 복원 전 Undo 기록은 이어지지 않습니다.

## 마스크 출력 {#마스크-출력}

**저장·적용 → 마스크 출력**은 현재 마스크의 레이어를 합쳐 저장하고 머티리얼에 연결합니다.

| 항목 | 설명 |
|---|---|
| 출력 크기 | 저장할 해상도를 고릅니다 |
| 외곽선 (px) | UV 경계 바깥으로 색을 얼마나 넓힐지 정합니다. 저장할 때 더해집니다 |
| 레이어 문서 | 편집 가능한 레이어 문서가 출력 파일과 함께 저장됩니다 |

기존 PNG나 문서를 다시 열어 같은 마스크를 계속 편집할 수 있습니다. 파일을 덮어쓸 때는 선택한 저장 경로를 확인하세요.

2.0은 레이어 편집 문서를 새 형식으로 저장합니다. 이전 형식의 문서는 처음 저장할 때 원본이 `Library/StudioRaming/MaskMaker/DocumentBackups/`에 백업되며, 2.0 형식의 문서는 1.x에서 열 수 없습니다.

## 이전 버전의 레이어 데이터

스텐실, 데칼, 캐비티/AO, 컬러 레이어의 데이터는 보존됩니다. 새 마스크를 만드는 목록에는 [칠하기, 이미지, 그라데이션, 브릿지, 맷캡 광택](/tabs/paint) 다섯 가지 방법만 표시됩니다.

이전 버전의 스텐실, 데칼, 캐비티/AO 레이어는 보존됨으로 표시되어 남습니다.

## 되돌리기와 자동 보존 {#되돌리기와-자동-보존}

- **되돌리기 단위**: 적용 한 번, 선택 변경 한 번, 획 하나가 각각 한 단계입니다 (`Ctrl+Z` · `Ctrl+Y`).
- **자동 보존**: 저장하지 않은 작업은 스크립트 리로드, Play, 씬 전환, 편집 종료 때 보존되고, 돌아오면 복원됩니다.
- **비정상 종료 후**: 창 위의 복구 배너에서 **복원** 또는 **버리기**를 고릅니다.

복구 파일을 쓰지 못하면(디스크 공간이나 권한 문제) 메모리에 긴급 사본을 둡니다. 메모리 사본은 Unity 프로세스가 끝나면 사라지므로, 종료 안내에서 **작업 열기** 또는 **취소**를 골라 먼저 저장하세요.

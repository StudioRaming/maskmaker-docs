# Mask Maker

**아바타 텍스처 마스크를 Unity 안에서 만드는 에디터 툴**입니다. 2.0부터 작업 화면은 **쉽게 시작**과 **전문가 작업** 두 모드로 나뉩니다.

:::info[1.x 구매자는 무료로 업데이트할 수 있습니다]
새 `.unitypackage`를 기존 `Assets/StudioRaming/MaskMaker` 폴더 위에 그대로 덮어 임포트하면 됩니다. 1.x에서 저장한 마스크는 그대로 동작합니다. → [1.x에서 업데이트](/getting-started/installation#update-from-1x)
:::

마스크는 셰이더의 여러 기능이 입력으로 쓰는 흑백 그림입니다. 어느 부위에 광택을 넣을지, 어디를 다른 색으로 덧칠할지, 아웃라인을 어디서 얇게 할지를 정합니다. Mask Maker는 씬 뷰에서 모델 위에 직접 그리거나 방법을 골라 마스크를 만들고, 그 자리에서 출력합니다.

메뉴 **StudioRaming → Mask Maker** 로 엽니다.

## 무엇이 들어 있나

마스크를 만드는 방법은 다섯 가지입니다. 하나만 고를 수도 있고, 여러 방법을 조합할 수도 있습니다.

| 방법 | 만드는 것 | 대표 용도 |
|---|---|---|
| [칠하기](/tabs/paint) | 씬 뷰 메쉬 위에 브러시로 직접 그린 마스크 | 자동으로 만들기 어려운 임의 모양 |
| [이미지](/tabs/image) | 고른 Texture2D를 마스크 내용으로 사용 | 외부에서 만든 그림 재사용 |
| [그라데이션](/tabs/gradient) | 방향이나 높이에 따라 값이 변하는 흑백 마스크 | 위치에 따라 달라지는 효과 |
| [브릿지](/tabs/bridge-mask) | 헤어 가닥을 골라 만든 흑백 마스크 | 머리카락 일부에만 효과 |
| [맷캡 광택](/tabs/matcap-gloss) | 맷캡 하이라이트를 구운 흑백 마스크 | 광택과 하이라이트 위치 |

색 보정(색 보정 레이어, 커브, 그라데이션 맵, 아티스틱 조정)은 Mask Maker에서 더 이상 만들지 않습니다. 색 보정은 MingPainter에서 작업합니다.

## 여러 방법을 함께 쓰기

이미 내용이 있는 마스크에 방법을 더하면 기본으로 **범위 제한**을 씁니다. 예를 들어 브릿지로 고른 가닥 안에만 그라데이션이나 맷캡 광택을 남길 수 있습니다. **흰 영역 추가**와 **이것만 사용**도 고를 수 있습니다.
→ [레이어와 마스크 출력](/concepts/layer-stack)

## 작업 방식

- **씬 뷰가 작업 화면입니다.** 기본 조작은 씬 뷰에서 합니다.
- **여러 마스크를 오갑니다.** 한 머티리얼의 마스크를 바꿔 가며 편집해도 각 마스크의 그림과 레이어가 남습니다.
- **출력은 한 곳에서 합니다.** **출력 · 작업** 탭의 **마스크 출력**에서 크기와 외곽선 (px)을 정하고 저장합니다. 편집 가능한 레이어 문서도 함께 저장됩니다.
- **원본 보기와 미리보기를 바꿀 수 있습니다.** **마스크만 보기 · 적용 결과 보기 · 원본 보기**로 전환합니다.

## 지원 환경

| 항목 | 값 |
|---|---|
| Unity | 2019.4 ~ Unity 6 (6000.0, 6000.3 LTS) |
| 렌더 파이프라인 | Built-in RP · URP |
| 언어 | 한국어 · English · 日本語 (창 오른쪽 위에서 전환) |
| 설치 위치 | `Assets/StudioRaming/MaskMaker` 한 폴더 |


셰이더 연결 표는 lilToon · Poiyomi · MingToon · NiloToon을 다룹니다. 그 밖의 셰이더에도 마스크를 만들어 직접 꽂을 수 있습니다.

# Mask Maker

**아바타 텍스처 마스크를 Unity 안에서 끝내는 에디터 툴**입니다.

마스크는 셰이더의 거의 모든 기능이 요구하는 입력입니다 — 어느 부위에 광택을 넣을지, 어디를 다른 색으로 덧칠할지, 아웃라인을 어디서 얇게 할지. 그런데 그걸 만들려면 보통 Unity를 나가 외부 페인팅 툴에서 UV를 펼치고, 다시 임포트하고, 임포트 설정을 고치고, 슬롯에 꽂아 보고, 틀리면 처음부터 반복해야 합니다.

Mask Maker는 그 왕복을 없앱니다. 씬 뷰에서 보면서 만들고, 그 자리에서 굽습니다. 만든 마스크를 셰이더 슬롯에 꽂는 일까지 도와주는 보조 기능도 있지만, 그건 선택이고 **이 툴의 본체는 마스크를 만드는 것**입니다.

메뉴 **StudioRaming → Mask Maker** 로 엽니다.

## 무엇이 들어 있나

**여섯 개의 탭이 각각 다른 방식으로 같은 결과물(마스크 텍스처)을 만듭니다.** 어떤 마스크는 계산으로 만드는 게 정확하고, 어떤 마스크는 손으로 그리는 게 빠릅니다. 그래서 방식을 하나로 강요하지 않습니다.

| 탭 | 만드는 것 | 대표 용도 |
|---|---|---|
| [MatCap 광택](/tabs/matcap-gloss) | 맷캡 하이라이트(광택 모드) 또는 메쉬 오목한 부분(AO/캐비티 모드)의 흑백 마스크 | 광택·스페큘러·림 마스크, 금속 부위 지정, AO |
| [그라데이션](/tabs/gradient) | 월드 방향 그라데이션 컬러 텍스처 | 높이 기반 색 틴트(옴브레 염색) |
| [브릿지+영역마스크](/tabs/bridge-mask) | 랜덤으로 고른 가닥, 또는 클릭한 가닥만 흰색인 마스크 | 브릿지(하이라이트) 염색 레이어, 특정 부위 격리 |
| [슬롯 분리](/tabs/slot-split) | 마스크가 아니라 **메쉬 자체**를 다른 머티리얼 슬롯으로 분리하거나, 나눠 둔 슬롯을 다시 합치기 | 완전히 다른 셰이더를 줄 부위 분리 |
| [컴바이너](/tabs/combiner) | 마스크 여러 장을 R/G/B/A 한 장으로 합치기 · 분리 | 텍스처 개수 줄이기, 자동 최적화 |
| [페인트](/tabs/paint) | 씬 뷰 메쉬 위에 브러시로 직접 그린 마스크/컬러 | 자동 생성이 안 되는 임의 모양 전부 |

## 다른 마스크 도구와 무엇이 다른가

**탭 결과가 한 메쉬 위에 겹쳐 쌓입니다.**
탭마다 따로 굽고 나중에 합치는 방식이 아닙니다. 어느 탭에서든 **Load** 하면 바로 프리뷰가 켜지고, 탭을 옮겨도 앞 탭의 결과가 씬에 그대로 남아 겹쳐 보입니다. 상단의 **최종 굽기**는 그 겹친 화면을 **보이는 그대로** 한 장의 마스크로 저장합니다.
→ [레이어 스택과 최종 굽기](/concepts/layer-stack)

**꽂는 일은 도와주지만, 강요하지 않습니다.**
마스크를 만드는 것이 이 툴의 본체이고, 셰이더 슬롯에 연결하는 기능은 **선택 보조**입니다. 브릿지+영역마스크의 **베이크 후 머티리얼에 자동 배정**은 기본이 꺼져 있고, 컴바이너의 **합치기 + 재배정**은 실행 전에 항상 계획을 보여주며 둘 다 `Ctrl+Z` 한 번으로 되돌아갑니다.
→ [컴바이너](/tabs/combiner)

**씬 뷰가 작업 화면입니다.**
목록에서 고르는 방식이 아닙니다. 가닥에 마우스를 올리면 시안/빨강으로 미리 보이고, Ctrl+클릭으로 넣고 뺍니다. 드래그하면 지나가는 가닥이 페인트처럼 토글되고, 박스로도 잡습니다. 안쪽·반대편 가닥은 뒷면 모드로 카메라를 돌리지 않고 집습니다.
→ [단축키](/reference/hotkeys)

**Undo가 전 영역에서 동작합니다.**
씬 뷰의 가닥 선택, 슬롯 분리 적용, 페인트 스트로크 모두 `Ctrl+Z` / `Ctrl+Y`로 되돌아갑니다.

**원본을 건드리지 않습니다.**
프리뷰는 머티리얼을 복제해 보여주고 **Stop** 하면 즉시 복원됩니다. 창을 그냥 닫아도 복원됩니다. 에디터가 강제 종료돼 복원이 실행되지 못했더라도 창을 다시 열면 자동으로 되돌리고, 메뉴 **StudioRaming → Mask Maker → Recover Preview Materials** 로도 되돌릴 수 있습니다. 저장할 때 같은 이름의 파일이 있으면 덮어쓰기/새 이름/취소를 묻습니다.

**네 개 셰이더의 연결 지점을 알고 있습니다.**
lilToon · Poiyomi · MingToon · NiloToon의 마스크 프로퍼티와 인스펙터 경로가 툴 안에 표로 들어 있고, 컴바이너는 셰이더별 프로파일로 스캔합니다. 목록에 없는 셰이더는 JSON 프로파일로 직접 추가합니다.
→ [셰이더 연결](/shaders/liltoon)

**가이드가 툴 안에 있습니다.**
각 탭 상단의 **가이드** 접이식 패널과 헤더의 **?** 버튼이 이 문서와 같은 내용을 담고 있습니다. 이 사이트는 그것을 검색·링크 가능한 형태로 옮긴 것입니다.

툴에서 이 사이트로 바로 올 수도 있습니다. 헤더의 **Docs** 버튼은 지금 보고 있는 탭의 페이지를, 카드 제목 옆의 작은 **?** 버튼은 그 기능의 페이지를, 헤더의 버전 라벨(**v0.1.1**)은 그 버전의 패치노트를 엽니다. 링크는 툴에서 고른 언어를 따라갑니다.

## 지원 환경

| 항목 | 값 |
|---|---|
| Unity | 2019.4 LTS ~ 2022.3 |
| 렌더 파이프라인 | Built-in RP · URP |
| 언어 | 한국어 · English · 日本語 (창 오른쪽 위에서 전환) |
| 설치 위치 | `Assets/StudioRaming/MaskMaker` 한 폴더 |

셰이더 연결표는 lilToon · Poiyomi 9.x · MingToon · NiloToon을 다룹니다. 그 밖의 셰이더에도 마스크를 만들어 꽂을 수 있으며, 자동 배정만 지원되지 않습니다.

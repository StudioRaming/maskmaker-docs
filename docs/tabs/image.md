# 이미지

**이 문서를 읽으면** 가지고 있는 Texture2D를 마스크의 내용으로 쓰는 법을 알 수 있습니다.

**만드는 것:** 고른 Texture2D를 내용으로 한 흑백 마스크. 입력 이미지 파일은 원본 그대로 보존됩니다.

## 절차

1. 오른쪽 패널에서 마스크를 고르거나 빈 칸을 엽니다.
2. 방법에서 **이미지**를 고릅니다.
3. Texture2D를 고릅니다.
4. **적용 결과 보기**로 확인합니다.
5. **저장·적용 → 마스크 출력**에서 저장합니다.

에셋 파일로 임포트되지 않은 Texture2D(임포터가 없는 텍스처)는 **Read/Write Enabled**가 켜져 있어야 합니다. 꺼져 있으면 툴이 거부합니다.

## 다른 방법과 함께 쓰기

이미 내용이 있는 마스크에 이미지를 더하면 기본으로 **범위 제한**을 씁니다. **흰 영역 추가**와 **이것만 사용**도 고를 수 있습니다.

→ [레이어와 마스크 출력](/concepts/layer-stack)

## 저장

출력 파일은 흑백이며 sRGB를 끈 상태로 임포트됩니다.

→ [sRGB와 임포트 설정](/concepts/srgb-and-import-settings)

# 브릿지

**이 문서를 읽으면** 헤어 가닥을 랜덤으로 또는 클릭으로 골라 흑백 마스크를 만드는 법을 알 수 있습니다.

**만드는 것:** 고른 헤어 가닥만 흰색인 흑백 마스크

## 절차

1. 헤어 모델을 고르고 **현재 선택한 대상 사용**을 누릅니다.
2. 오른쪽 패널에서 마스크를 고르거나 빈 칸을 열고 방법에서 **브릿지**를 고릅니다.
3. 가닥을 **랜덤 가닥** 모드로 고르거나, **수동 선택** 모드에서 씬 뷰를 클릭해 고릅니다.
4. **적용 결과 보기**로 확인합니다.
5. **저장·적용 → 마스크 출력**에서 저장합니다.

메쉬의 **Read/Write Enabled**가 꺼져 있으면 브릿지가 켜도 되는지 묻고, 허용하면 켭니다.

## 랜덤 가닥 모드 설정

| 항목 | 뜻 |
|---|---|
| **가닥 비율 (%)** | 전체 가닥 중 랜덤으로 고를 비율. 브릿지 밀도를 정합니다 |
| **가닥 두께 (%)** | 가닥 안에서 쓸 face 비율. 낮추면 가운데 선만 남습니다 |
| **크기 필터 (%)** | 표면적이 작은 쪽부터 N% 가닥만 후보로 씁니다. 큰 시트를 빼려면 낮춥니다 |
| **앞쪽 가닥만** | 메쉬 뒤쪽(Z 기준) 가닥을 후보에서 뺍니다 |
| **시드** / **랜덤 시드** | 같은 시드는 항상 같은 결과입니다. **최근 시드**에서 이전 시드로 돌아갈 수 있습니다 |
| **확장** | 넣지 않음 / 근처 가닥 (5mm) / 정점 공유. 고른 가닥 옆의 가닥도 함께 넣습니다 |
| **범위** | 선택 영역 또는 메쉬 전체 |
| **매끄럽게 (블러)** | face 경계를 가우시안 블러로 부드럽게 합니다. 0은 끔, 1~3 권장 |
| **엣지 페이드** | 가장자리를 점점 옅게 만듭니다 (페이드 픽셀, 페이드 곡선) |
| **틴트 (프리뷰)** | 프리뷰에만 덮어 보이는 색입니다. 저장되는 마스크는 항상 흑백입니다 |

**선택 반전**과 **선택 확장**으로 고른 가닥을 뒤집거나 인접 가닥을 더할 수 있습니다.

## 씬 뷰에서 고르기

가닥에 마우스를 올리면 결과가 색으로 미리 표시됩니다.

| 하이라이트 | 뜻 |
|---|---|
| **시안** (`#33E5FF`) | 아직 고르지 않은 가닥. `Ctrl` + 클릭하면 추가됩니다 |
| **빨강** (`#FF4033`) | 이미 고른 가닥. `Ctrl` + 클릭하면 빠집니다 |

| 조작 | 결과 |
|---|---|
| `Ctrl` + 클릭 | 가닥 추가 / 해제 |
| `Ctrl` + 드래그 | 지나가는 가닥을 페인트처럼 토글 |
| `Ctrl+Shift` + 드래그 | 박스로 추가 선택 |
| `Ctrl+Shift+Alt` + 드래그 | 박스로 선택 해제 |
| `Ctrl+Z` / `Ctrl+Y` | 실행취소 / 다시실행 |

앞면과 뒷면, UV가 겹치는 미러 가닥은 함께 토글됩니다. 전체 키는 [단축키](/reference/hotkeys)에 있습니다.

## 다른 방법과 함께 쓰기

브릿지 결과를 기준으로 [그라데이션](/tabs/gradient)이나 [MatCap 광택](/tabs/matcap-gloss)을 **범위 제한**으로 더하면, 고른 가닥 안에만 효과가 남습니다.

→ [레이어와 마스크 출력](/concepts/layer-stack)

## 베이크 후 자동 배정

**베이크 후 자동 배정**을 켜면 저장된 마스크를 머티리얼의 배정 가능한 슬롯에 자동으로 연결합니다. NiloToon, lilToon, Poiyomi 머티리얼만 지원하며, 기본은 꺼짐이고 Undo로 되돌릴 수 있습니다.

## 칠하기로 다듬기

브릿지 결과 위에서 [칠하기](/tabs/paint)를 하면, 칠한 부분만 보정으로 남습니다.

## 저장

출력 파일은 흑백이며 sRGB를 끈 상태로 임포트됩니다. **수동 선택** 모드로 저장한 파일 이름은 `_Isolation`으로 끝나고, 랜덤 가닥 모드는 `_BridgeMask`로 끝납니다.

→ [sRGB와 임포트 설정](/concepts/srgb-and-import-settings)

# 브릿지 마스크

**이 문서를 읽으면** 헤어 가닥을 랜덤으로 고르거나 직접 클릭해 마스크를 만드는 법을 알 수 있습니다. 저장한 마스크를 셰이더 슬롯에 연결해 주는 선택 기능도 함께 다룹니다.

**만드는 것:** 흑백 마스크 PNG — NiloToon 스태킹 레이어 / 격리 마스크용

<!-- SCREENSHOT: 브릿지 마스크 탭 — 랜덤 가닥/수동 선택 모드 토글, 비율 슬라이더, 최근 시드 칩 -->

## 두 가지 모드

탭 상단의 토글로 오갑니다. **두 모드는 클릭으로 켜고 끈 가닥을 서로 공유합니다** — 랜덤으로 뽑아 놓고 수동으로 다듬다가 다시 랜덤으로 돌아가도 손댄 내용이 남습니다.

| 모드 | 동작 | 대표 용도 |
|---|---|---|
| **랜덤 가닥** | 비율·시드로 가닥을 자동 선택하고 클릭으로 다듬음 | 브릿지(하이라이트) 염색 — 머리카락 일부만 다른 색 |
| **수동 선택** | 자동 선택 없음. 클릭한 가닥만 흰색 | 특정 부위 격리 |

:::note[수동 선택 모드는 구 "격리" 탭입니다]
v0.1.1에서 격리 탭이 브릿지 탭에 통합됐습니다. 동작은 같고, 출력 파일명의 `_Isolation` 접미사도 그대로 유지됩니다 — 기존 작업 파일과 이름이 어긋나지 않습니다.
:::

## 절차

1. 상단에서 **랜덤 가닥** / **수동 선택** 모드를 고릅니다
2. 헤어 오브젝트 선택 → **Load** — 프리뷰가 바로 시작됩니다
3. (랜덤 가닥) 가닥 **비율 / 두께 / 크기 필터**를 조절하고 마음에 들 때까지 **랜덤 시드**를 누릅니다
4. 씬 뷰에서 가닥에 마우스를 올려 미리 보고, `Ctrl` + 클릭으로 넣고 뺍니다
5. 패널 버튼으로 다듬습니다
6. **Bake** — 이 탭의 레이어 한 장을 흑백 마스크 PNG로 저장합니다 (머티리얼은 변경하지 않습니다). 다른 탭 결과까지 합친 한 장이 필요하면 위쪽의 **최종 굽기**를 쓰세요 → [레이어 스택과 최종 굽기](/concepts/layer-stack)

메쉬에 머티리얼이 여러 개면 위쪽 썸네일에서 작업할(활성) 슬롯을 고르세요.
→ [머티리얼 슬롯 피커](/getting-started/first-mask#머티리얼-슬롯-피커)

## 씬 뷰 조작

가닥에 마우스를 올리면 결과가 색으로 미리 표시됩니다.

| 하이라이트 | 뜻 |
|---|---|
| **시안** (`#33CCFF`) | `Ctrl` + 클릭하면 **선택됨** |
| **빨강** (`#FF5544`) | `Ctrl` + 클릭하면 **해제됨** |

| 조작 | 결과 |
|---|---|
| `Ctrl` + 클릭 | 가닥 추가 / 해제 |
| `Ctrl` + 드래그 | 지나가는 가닥을 페인트처럼 토글 |
| `Ctrl+Shift` + 드래그 | 박스로 추가 선택 |
| `Ctrl+Shift+Alt` + 드래그 | 박스로 선택 해제 |
| 그냥 클릭 | 프리뷰 중에는 **다른 오브젝트가 선택되지 않습니다** (`Alt` + 드래그 씬 회전은 그대로) |
| `Ctrl+Z` / `Ctrl+Y` | 실행취소 / 다시실행 |

앞/뒷면과 미러 가닥은 **자동으로 함께 토글**되고, 상태줄에 몇 개가 같이 토글됐는지 표시됩니다.

## 선택 다듬기

| 버튼 | 하는 일 |
|---|---|
| 전체 선택 | 모든 가닥 선택 |
| 전체 해제 | 선택 비우기 |
| 선택 반전 | 선택/비선택을 뒤집기 |
| 선택 확장 | 지금 선택된 가닥에 인접한 가닥까지 넓히기 |

| 옵션 | 하는 일 |
|---|---|
| **뒷면 모드** | 앞면을 숨기고 뒷면만 보이게 해 안쪽·반대편 가닥을 카메라를 돌리지 않고 집습니다. **저장되는 마스크에는 영향 없습니다** |
| **UV 겹침 가닥 함께 선택** | 양면 시트·미러 가닥을 한 번에 토글합니다 |

선택 상태는 **모드를 바꾸거나 프리뷰를 껐다 켜도 유지**되며, **Load 시 초기화**됩니다.

## 랜덤 시드와 최근 시드

**랜덤 시드** 버튼을 누를 때마다 다른 조합이 나옵니다. 마음에 드는 조합을 지나쳤다면 옆의 **최근 시드** 칩을 클릭해 그 시드로 되돌아갑니다.

<!-- SCREENSHOT: 랜덤 시드 버튼과 최근 시드 칩 목록 -->

| 필터 | 하는 일 |
|---|---|
| 가닥 비율 | 전체 가닥 중 몇 %를 고를지 |
| 두께 필터 | 얇은/두꺼운 가닥만 대상으로 |
| 크기 필터 | 작은/큰 가닥만 대상으로 |

## 후처리

| 옵션 | 하는 일 |
|---|---|
| 그라데이션 | 뿌리→끝 방향으로 마스크 값을 흐리게 |
| 엣지 페이드 | 가닥 가장자리를 부드럽게 (픽셀 단위 + 부드러움) |
| 틴트 색 | **프리뷰 전용**입니다. 저장되는 마스크는 항상 흑백입니다 |

## 베이크 후 머티리얼에 자동 배정 (선택)

이 탭이 만드는 것은 마스크 PNG이고, **머티리얼 연결은 선택 기능입니다.**

**베이크 후 머티리얼에 자동 배정** 체크박스는 **기본이 꺼져 있습니다.** 켜 두면 저장한 마스크를 아래에서 고른 슬롯(NiloToon 스태킹 레이어 등)에 연결합니다. 배정 결과는 상태줄에 몇 개가 배정되고 몇 개가 건너뛰어졌는지로 표시되며, `Ctrl+Z` 한 번으로 되돌아갑니다.

끄고 쓰면 마스크만 저장되고 머티리얼은 그대로 남습니다 — 연결은 [첫 마스크 만들기](/getting-started/first-mask)의 3~4단계처럼 직접 하면 됩니다.

## 페인트 탭으로 보내기

**페인트 탭으로 보내기** 버튼으로 지금 선택 마스크를 [페인트 탭](/tabs/paint)에 넘겨 손으로 이어 그릴 수 있습니다. 두 모드 모두에서 동작합니다.

## 어디에 꽂나

| 셰이더 | 슬롯 |
|---|---|
| NiloToon | `Base Map ▸ Stacking Layer 1..10 ▸ Mask Tex` — 자동 배정을 켰을 때의 기본 대상 |
| lilToon | `Main Color ▸ 2nd ▸ Mask` · `Main Color ▸ 3rd ▸ Mask` |
| Poiyomi | `RGBA Color Masking ▸ Masks` (컴바이너로 4장 묶은 뒤) |
| MingToon | `Region ▸ Region Mask` (컴바이너로 4부위 묶은 뒤) |

# 슬롯 분리


**이 문서를 읽으면** 클릭한 가닥을 다른 머티리얼 슬롯으로 옮긴 새 메쉬를 만들어 씬에서 교체하는 법을 알 수 있습니다.

**만드는 것:** 마스크가 아니라 **메쉬 에셋**입니다. 완전히 다른 셰이더를 줄 부위를 분리할 때 씁니다.

탭 상단의 **분리** / **합치기** 토글로 두 방향을 오갑니다. **분리**는 가닥을 다른 슬롯으로 내보내고, **합치기**는 슬롯 여러 개를 서브메쉬 하나로 되돌립니다.

<!-- SCREENSHOT: 슬롯 분리 탭 — 메쉬 카드와 슬롯 목록, 씬 뷰 범례 -->

## 마스크로 안 되는 경우에 씁니다

마스크는 **한 머티리얼 안에서** 효과의 세기를 조절합니다. 하지만 "이 부분만 투명 셰이더", "이 부분만 이미션 전용 머티리얼"처럼 **셰이더 자체가 달라야** 하면 마스크로는 불가능합니다. 그때 메쉬를 서브메쉬 단위로 나눕니다.

## 절차

1. 오브젝트 선택 → **불러오기** — 즉시 슬롯별로 다른 색이 입혀져 현재 배치가 보입니다 (씬 뷰 왼쪽 위 범례 참고)
2. **대상 슬롯**을 씬 뷰 범례나 메쉬 카드에서 행을 클릭해 지정합니다
3. 씬 뷰에서 옮길 가닥을 `Ctrl` + 클릭합니다 — 선택된 가닥은 대상 슬롯 색으로 표시됩니다
4. 잘못 옮겼다면 **이동 초기화** 또는 **구조 초기화**로 되돌립니다
5. **적용 계획** 카드에서 메쉬별 저장 경로와 배지를 확인합니다
6. **적용** — 확인창 후 새 메쉬 에셋을 저장하고 씬의 SkinnedMeshRenderer를 교체합니다

적용 후 프리뷰가 자동으로 다시 시작됩니다.

## 슬롯 추가와 삭제

| 버튼 | 하는 일 |
|---|---|
| **+ 슬롯 추가** | 새 슬롯을 만들고 자동으로 대상 슬롯으로 지정합니다 |
| **×** | 슬롯을 삭제하고 **바로 위 슬롯에 병합**합니다 |

구조가 바뀌면 `[구조 변경됨]` 배지가 표시됩니다.

## 새로고침

**새로고침**은 Hierarchy 선택과 **무관하게** 지금 로드된 메쉬만 다시 읽습니다. 다른 오브젝트를 씬에서 클릭했다가 돌아와도 작업 대상이 바뀌지 않습니다.

## 두 가지 초기화

| 버튼 | 되돌리는 범위 |
|---|---|
| **이동 초기화** | 가닥 이동만 취소. 추가/삭제한 슬롯 구성은 유지 |
| **구조 초기화** | 추가/삭제한 슬롯까지 **불러오기 시점으로** 복원 |

## 적용 계획 {#적용-계획}

**적용** 버튼 위의 카드가 실행 전에 무슨 일이 일어날지 보여줍니다.

<!-- SCREENSHOT: 적용 계획 카드 — 메쉬별 배지와 저장 경로 -->

| 배지 | 뜻 |
|---|---|
| 새로 만들기 | 새 메쉬 에셋 파일을 만듭니다 |
| 고유 경로 | 같은 이름이 있어 다른 이름으로 만듭니다 |
| 덮어쓰기 | 이전에 Mask Maker가 만든 출력을 **GUID를 유지한 채** 갱신합니다 |

:::danger[덮어쓰기는 Mask Maker가 만든 파일에만 일어납니다]
Mask Maker 소유 표식과 원본 GUID/local ID가 **모두 맞는** 출력만 GUID를 유지해 갱신합니다. 외부 파일 · 표식 없는 파일 · 원본이 다른 파일은 **절대 덮어쓰지 않습니다**.

GUID를 유지하기 때문에 프리팹·애니메이션의 참조가 끊기지 않습니다.
:::

취소하거나 실패하면 **전체가 롤백**됩니다. 일부만 적용된 상태로 남지 않습니다.

## 새 슬롯에 머티리얼 복제

기본값으로 새 슬롯에는 **원본 슬롯과 같은 머티리얼**이 배정됩니다 — 적용 후 원하는 머티리얼로 직접 바꿔야 합니다.

**새 슬롯에 머티리얼 복제**를 켜면 새 슬롯마다 별도 머티리얼(`_SplitN.mat`)을 받습니다. 곧바로 값을 다르게 만질 수 있습니다.

## 보존되는 것

| 데이터 | 상태 |
|---|---|
| 블렌드쉐입 | 보존 |
| 본 웨이트 | 보존 |
| UV (전 채널) | 보존 |
| 노멀 · 탄젠트 | 보존 |
| 서브메쉬 배정 | **이것만 바뀝니다** |
| GUID | 소유 출력을 갱신할 때 유지 |
| Undo/Redo | 지원 |

## 합치기 모드 {#합치기-모드}

**분리의 역작업입니다.** 슬롯 여러 개를 서브메쉬 하나로 되돌립니다 — 나눠 놓고 보니 굳이 나눌 필요가 없었을 때, 또는 드로우콜을 줄이고 싶을 때 씁니다.

<!-- SCREENSHOT: 합치기 모드 - 슬롯 카드 체크박스와 "남길 머티리얼" 선택 -->

### 절차

1. 탭 상단에서 **합치기**를 고릅니다
2. 오브젝트 선택 → **불러오기**
3. 합칠 슬롯을 **2개 이상** 고릅니다 — 슬롯 카드의 **체크박스**(베이스맵 썸네일이 함께 보입니다) 또는 씬 뷰에서 `Ctrl` + 클릭
4. **남길 머티리얼**을 고릅니다. 합친 서브메쉬는 이 머티리얼을 쓰고, 나머지는 **렌더러에서만 빠집니다** (머티리얼 에셋은 지워지지 않습니다). 기본값은 처음 고른 슬롯입니다
5. **합치기** — 확인창의 요약(`슬롯 N→M, 삼각형 T`)을 보고 실행합니다

선택 개수는 `{선택} / {전체} 슬롯 선택 (2개 이상 필요)`로 표시됩니다.

### 경고는 막지 않습니다

두 경우에 경고가 뜨지만 **실행은 막히지 않습니다.** 의도적으로 합치는 경우가 있기 때문입니다.

| 경고 | 뜻 |
|---|---|
| 베이스맵이 다릅니다 | 합치면 **남긴 머티리얼의 텍스처만** 쓰입니다 |
| 선택 슬롯의 UV 영역이 겹칩니다 | 한 텍스처로 합치면 **같은 자리를 공유**하게 됩니다 |

### 저장되는 것과 되돌리기

| 항목 | 동작 |
|---|---|
| 새 메쉬 | 원본 에셋 옆에 `*_merged.asset`으로 저장됩니다 (씬 전용 메쉬는 저장 위치를 직접 지정) |
| 원본 에셋 | **바뀌지 않습니다** |
| 렌더러 | 새 메쉬로 교체되고, 머티리얼 배열에서 합쳐진 슬롯이 빠집니다 |
| 같은 메쉬를 쓰는 다른 렌더러 | 함께 리바인드됩니다 — 한쪽만 갱신되어 화면이 안 바뀌는 일이 없습니다 |
| `Ctrl+Z` | **메쉬와 머티리얼 배열이 함께** 원래대로 돌아갑니다 |

적용 도중 취소하거나 실패하면 분리와 마찬가지로 **전체가 롤백**됩니다.

:::caution[분리 모드에 미적용 변경이 있으면 잠깁니다]
분리 모드에서 옮긴 가닥이나 추가/삭제한 슬롯을 아직 **적용**하지 않았다면 합치기를 쓸 수 없습니다. 먼저 **적용**하거나 **이동 초기화** / **구조 초기화**로 정리하세요.
:::

### 씬 뷰 조작 (합치기 모드)

| 조작 | 결과 |
|---|---|
| `Ctrl` + 클릭 | 그 슬롯을 선택 / 해제 |
| `Ctrl+Z` / `Ctrl+Y` | 실행취소 / 다시실행 |

남길 머티리얼은 씬 뷰가 아니라 패널에서 고릅니다. 선택된 슬롯 카드에는 **남김** 배지가 붙습니다.

## 씬 뷰 조작 (분리 모드)

| 조작 | 결과 |
|---|---|
| `Ctrl` + 클릭 | 가닥을 대상 슬롯으로 이동 / 취소 |
| `Ctrl` + 드래그 | 지나가는 가닥을 토글 |
| `Ctrl+Shift` + 드래그 | 박스로 추가 선택 |
| `Ctrl+Shift+Alt` + 드래그 | 박스로 선택 해제 |
| 그냥 클릭 | 프리뷰 중에는 **다른 오브젝트가 선택되지 않습니다** |
| `Ctrl+Z` / `Ctrl+Y` | 실행취소 / 다시실행 |

안쪽·반대편 가닥은 **양면 작업**를 켜면 편합니다.

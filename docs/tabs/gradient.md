# 그라데이션

**이 문서를 읽으면** 월드 방향 그라데이션을 컬러 텍스처로 굽는 법과, 포즈가 바뀌어도 위치가 유지되게 만드는 기준 본 설정을 알 수 있습니다.

**만드는 것:** 컬러 UV 텍스처 (sRGB) — 옴브레·페이드 염색용

<!-- SCREENSHOT: 그라데이션 탭 — 그라데이션 편집기, 방향 버튼, 끝처리 옵션 -->

## 절차

1. 오브젝트 선택 → **Load** → **Preview** ON
2. 그라데이션 색상을 편집하거나 프리셋(흰→검 등)을 씁니다
3. 방향 버튼(↑ ↓ ← → 앞 뒤)으로 방향을 잡거나, 씬 뷰에서 시작/끝 핸들을 직접 드래그합니다 (가운데 노브 = 전체 이동)
4. 끝처리(늘림 / 반복 / 미러)와 프리뷰 표시 방식을 확인합니다
5. **Bake** — 컬러 텍스처(sRGB)로 저장됩니다

메쉬에 머티리얼이 여러 개면 체크박스 아래 썸네일에서 작업할 슬롯을 고르세요.
→ [머티리얼 슬롯 피커](/getting-started/first-mask#머티리얼-슬롯-피커)

## 월드 위치 기준입니다

그라데이션은 **월드 좌표**를 읽어 만듭니다. 카메라를 어떻게 돌려도 결과가 같습니다. 같은 위치에 선 아바타라면 프리셋을 적용하는 것만으로 동일한 방향·범위가 재현됩니다.

Preview가 꺼져 있으면 씬 뷰 핸들은 흐리게 표시되고 편집할 수 없습니다.

## 기준 본 {#기준-본}

**포즈가 바뀌면 월드 좌표는 어긋납니다.** 아바타가 팔을 들면 소매의 그라데이션이 몸통 기준 위치에 그대로 남습니다.

**기준 본**을 지정하면 시작/끝점이 그 본을 따라 움직입니다.

| 상황 | 기준 본 없음 | 기준 본 지정 |
|---|---|---|
| 아바타가 T포즈 → A포즈 | 위치가 어긋남 | 유지 |
| 프리셋을 다른 아바타에 적용 | 월드 좌표 그대로 | **같은 이름의 본을 다시 찾아** 재현 |
| 그 이름의 본이 없는 아바타 | — | 월드 좌표로 자동 대체 |

<!-- SCREENSHOT: 기준 본 필드와 그에 따라 움직이는 씬 뷰 시작/끝 핸들 -->

:::tip[헤어에는 Head, 소매에는 팔 본]
움직이는 부위에 그라데이션을 넣을 때는 그 부위를 실제로 움직이는 본을 고르세요. 그래야 포즈를 바꿔가며 확인해도 그림이 흔들리지 않습니다.
:::

## 끝처리 (Wrap)

그라데이션 범위 바깥을 어떻게 채울지 정합니다.

| 값 | 동작 |
|---|---|
| 늘림 (Clamp) | 양 끝 색을 그대로 연장 |
| 반복 (Repeat) | 그라데이션을 반복 |
| 미러 (Mirror) | 반복하되 방향을 번갈아 뒤집음 |

## 저장

- 그라데이션은 **컬러**이므로 sRGB를 **켠 채로** 저장됩니다. 마스크와 반대입니다.
  → [sRGB와 임포트 설정](/concepts/srgb-and-import-settings)
- 같은 이름의 파일이 있으면 덮어쓰기 / 새 이름 / 취소를 묻습니다.
- 탭 하단 **최근 베이크** 목록에서 핑 · 폴더 열기로 확인합니다.
- Hierarchy 선택이 바뀌면 **"선택이 바뀜 — 다시 로드"** 줄이 뜹니다.

## 어디에 꽂나

그라데이션 결과물은 마스크가 아니라 **색**입니다. 마스크 슬롯이 아니라 컬러 레이어 슬롯에 들어갑니다.

| 셰이더 | 예 |
|---|---|
| lilToon | `Main Color ▸ 2nd ▸ Color Texture` |
| Poiyomi | 데칼 · 두 번째 메인 텍스처 계열 |
| NiloToon | `Base Map ▸ Stacking Layer ▸ Color Tex` |

"어느 부위에 이 색을 입힐지"를 함께 지정하려면 [브릿지 마스크](/tabs/bridge-mask)나 [페인트](/tabs/paint)로 마스크를 따로 만들어 같은 레이어의 마스크 슬롯에 꽂습니다.

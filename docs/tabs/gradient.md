# 그라데이션

**이 문서를 읽으면** 시작점과 끝점 사이에서 흑백 값이 변하는 마스크를 만드는 법을 알 수 있습니다.

**만드는 것:** 시작점과 끝점 사이에서 흑백 값이 달라지는 마스크

## 절차

1. 오른쪽 패널에서 마스크를 고르거나 빈 칸을 엽니다.
2. 방법에서 **그라데이션**을 고릅니다.
3. **그라데이션 색상** 막대에서 시작점(왼쪽, 0%)과 끝점(오른쪽, 100%)을 정합니다. **흰→검**, **검→흰**으로 방향을 고르고, **색 반전**으로 키 순서를 뒤집습니다.
4. **적용 결과 보기**로 확인합니다.
5. **저장·적용 → 마스크 출력**에서 저장합니다.

**기준 본 (선택)**을 고르면 시작점과 끝점이 그 본을 따라 움직입니다(포즈 추종). 본을 찾지 못하면 월드 위치로 굽습니다.

## 다른 방법과 함께 쓰기

이미 내용이 있는 마스크에 그라데이션을 더하면 기본으로 **범위 제한**을 씁니다. 예를 들어 [브릿지](/tabs/bridge-mask)로 고른 가닥 안에만 그라데이션을 남길 수 있습니다. **흰 영역 추가**와 **이것만 사용**도 고를 수 있습니다.

→ [레이어와 마스크 출력](/concepts/layer-stack)

## 칠하기로 다듬기

생성 결과 위에서 [칠하기](/tabs/paint)를 하면 칠한 부분만 보정으로 남습니다. 칠하지 않은 부분은 그라데이션 설정을 바꾸면 따라 바뀝니다.

## 저장

출력 파일은 흑백이며 sRGB를 끈 상태로 임포트됩니다.

→ [sRGB와 임포트 설정](/concepts/srgb-and-import-settings)

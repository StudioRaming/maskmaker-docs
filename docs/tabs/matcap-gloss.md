# MatCap 광택

**이 문서를 읽으면** 맷캡 광택을 흑백 UV 마스크로 굽는 법과, 씬 뷰 각도와 무관하게 메쉬 오목한 부분만으로 AO 마스크를 굽는 법을 알 수 있습니다.

**만드는 것:** 흑백 마스크 텍스처 (셰이더의 광택·이펙트 마스크 입력용)

<!-- SCREENSHOT: MatCap 광택 탭 전체 — 광택/AO 토글, 맷캡 슬롯, 슬라이더 -->

## 절차

1. Hierarchy에서 헤어(또는 대상) 오브젝트 선택 → **Load**
2. **Preview** ON → 씬 뷰 카메라를 돌려 광택이 잡힐 각도를 잡습니다
3. MatCap 텍스처를 고르고 **둥근정도 / 세기 / 대비** 를 조절합니다
4. 씬 뷰 핸들로 위치를 잡습니다
5. **Bake** — 현재 씬 뷰 시점 기준으로 굽고 원본 텍스처 폴더에 자동 저장됩니다

메쉬에 머티리얼이 여러 개면 체크박스 아래 썸네일에서 작업할 슬롯을 먼저 고르세요.
→ [머티리얼 슬롯 피커](/getting-started/first-mask#머티리얼-슬롯-피커)

## 씬 뷰 핸들

| 핸들 | 조작 |
|---|---|
| 주황 구 | 가상 구의 중심 이동 |
| 가장자리 노브 | 반경 |
| 회전 링 | 광택 방향 회전 (카메라는 고정) |

<!-- SCREENSHOT: 씬 뷰의 주황 가상 구 핸들과 회전 링 -->

:::note[Preview가 꺼져 있으면 핸들을 만질 수 없습니다]
프리뷰가 꺼진 상태에서는 핸들이 흐리게 표시되고 편집되지 않습니다. 실수로 값이 바뀌는 것을 막기 위한 것입니다.
:::

## 광택 / AO(캐비티) 서브모드

탭 상단의 토글로 두 가지 마스크를 오갑니다.

| 모드 | 기준 | 씬 뷰 각도 | 프리뷰 방식 |
|---|---|---|---|
| **광택** | 맷캡 + 메쉬 노멀 | 영향 **있음** — 현재 시점 기준으로 구움 | 실시간 |
| **AO(캐비티)** | 메쉬 형태의 오목한 정도 | 영향 **없음** | **프리뷰 베이크** 버튼 |

AO 모드는 카메라를 어디에 두든 결과가 같습니다. 형태 자체를 읽기 때문입니다. 실시간 프리뷰 대신 **프리뷰 베이크** 버튼으로 결과를 미리 확인합니다.

| AO 모드 조정 항목 | 하는 일 |
|---|---|
| 반경 | 얼마나 넓은 범위를 "오목함"으로 볼지 |
| 샘플 수 | 품질. 높을수록 느리고 매끈합니다 |
| 세기 | 어두워지는 정도 |
| 대비 | 밝은 곳과 어두운 곳의 차이 |
| 반전 | 오목한 곳 대신 볼록한 곳을 흰색으로 |

## 프리셋

세팅(글로벌 방향·구 크기 등)을 저장해 두면 다른 메쉬에서 그대로 불러 쓸 수 있습니다. 여러 오브젝트로 나뉜 헤어에 같은 광택을 넣을 때 씁니다.

→ [설정과 프리셋](/reference/settings-and-presets)

## 페인트로 다듬기

베이크 결과 옆의 **페인트로 다듬기** 버튼을 누르면 그 마스크가 [페인트 탭](/tabs/paint)으로 넘어갑니다. 계산으로 나온 광택 위에 손으로 이어 그릴 수 있습니다 — 앞머리 한 가닥만 광택을 지우거나, 계산이 놓친 자리를 채울 때.

## 저장

- 파일명에 **메쉬 구성**이 들어가므로, 같은 구성끼리만 서로 덮어씁니다.
- 같은 이름의 파일이 있으면 덮어쓰기 / 새 이름 / 취소를 묻습니다.
- 탭 하단 **최근 베이크** 목록에서 핑(찾기) · 폴더 열기로 바로 확인합니다.
- Hierarchy 선택이 바뀌면 **"선택이 바뀜 — 다시 로드"** 줄이 뜹니다 (프리뷰 중에는 자동 로드가 꺼집니다).

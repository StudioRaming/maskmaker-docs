# 페인트

**이 문서를 읽으면** 씬 뷰 메쉬 위에 브러시로 직접 그려 마스크·컬러 텍스처를 만드는 법을 알 수 있습니다. 다른 다섯 탭이 계산으로 못 만드는 모양은 전부 여기서 만듭니다.

**만드는 것:** 마스크(그레이스케일) 또는 컬러(RGBA) 텍스처

<!-- SCREENSHOT: 페인트 탭 — 도구 버튼, 브러시 슬라이더, 스텐실 카드 -->

## 절차

1. 대상 오브젝트 선택 → **Load** → 렌더러마다 대상 머티리얼 슬롯을 썸네일에서 고르고 **Preview** ON
2. **새 텍스처**(크기 선택)로 시작하거나 **기존 텍스처 로드**로 이어 그립니다 — 마스크 / 컬러 모드를 고릅니다
3. 씬 뷰에서 **그냥 좌클릭 드래그**하면 칠해집니다. `Ctrl`이 필요 없고 `Alt`는 평소처럼 카메라 회전입니다
4. 도구·반경·강도·폴오프를 조절하며 그립니다
5. **저장** 또는 **다른 이름으로 저장**

## 도구

| 도구 | 하는 일 |
|---|---|
| 그리기 | 현재 색/값으로 칠합니다 |
| 지우기 | 반대 값으로 칠합니다 |
| 부드럽게 | 주변 값을 섞어 경계를 흐립니다 |
| 채우기 | `Ctrl` + 클릭한 **UV 아일랜드 전체**를 한 번에 칠합니다 |

## 브러시 단축키

| 키 | 하는 일 |
|---|---|
| `[` `]` | 반경 |
| `<` `>` 또는 `,` `.` | 강도 (둘 다 같은 기능) |
| `F` + 드래그 | 반경 모달 조절 |
| `Shift+F` + 드래그 | 강도 모달 조절 |
| `S` | 스포이드 — 베이스 텍스처의 색을 추출 |
| `X` | 색/값 교체 |
| `Ctrl` + 클릭 | 채우기 도구 실행 (다른 도구 중이면 임시 채우기) |
| `Ctrl+Z` / `Ctrl+Y` | **스트로크 단위** 실행취소 / 다시실행 |

값은 GUI 슬라이더에 **즉시 반영**됩니다 — 씬 뷰에서 조절한 뒤 패널을 보면 그 값이 들어가 있습니다.

## 칠하는 범위 제한

| 옵션 | 하는 일 |
|---|---|
| **정면 각도 제한** | 카메라를 향한 각도가 큰(비스듬한) 면은 칠하지 않습니다. 실루엣 가장자리가 지저분해지는 것을 막습니다 |
| **차폐** | 카메라에서 가려진 면에는 칠하지 않습니다. **끄면 X-Ray로 관통해서** 앞뒤가 함께 칠해집니다 |
| **대칭** | 좌우 미러 페인트. X/Y/Z 축을 고릅니다 |

## 스텐실 텍스처링 {#스텐실}

스텐실 카드에 이미지를 올리면 **화면에 고정된 오버레이**로 표시됩니다. 그 위를 칠하면 스탬프가 찍힙니다.

| 키 | 하는 일 |
|---|---|
| `T` + 드래그 | 이동 |
| `Shift+T` + 드래그 | 크기 |
| `Ctrl+T` + 드래그 | 회전 |
| `Alt+T` | 화면에 맞춤 |
| 휠 | 크기 조절 |

모서리 핸들로도 직접 조작할 수 있습니다.

<!-- SCREENSHOT: 스텐실 오버레이가 화면에 떠 있고 모서리 핸들이 보이는 씬 뷰 -->

### 내장 스텐실

애니메 헤어 하이라이트 모양 **8종**이 기본 포함되어 바로 쓸 수 있습니다.

| 파일 | 모양 |
|---|---|
| `angel_ring` | 천사링 (헤어 하이라이트) |
| `crescent` | 초승달 |
| `double_ring` | 이중 링 |
| `star4` | 4각 별 |
| `diamond` | 마름모 |
| `wave` | 물결 |
| `zigzag` | 지그재그 |
| `dashes` | 파선 |

전부 StudioRaming이 직접 만든 원본 에셋입니다.
→ [서드파티 고지](/legal/third-party-credits)

## 저장

| 모드 | 저장 형식 |
|---|---|
| 마스크 | **리니어** (sRGB 꺼짐) |
| 컬러 | **sRGB** |

→ [sRGB와 임포트 설정](/concepts/srgb-and-import-settings)

## 자동 저장 복원

프리뷰 중단 · 리컴파일 · 플레이모드 전환 · 씬 전환으로 저장하지 않은 캔버스는 **자동으로 임시 저장**됩니다.

다음 **Load** 시 복원 여부를 물어봅니다 — **복원 / 버리기 / 취소**.

| 항목 | 값 |
|---|---|
| 저장 위치 | `<프로젝트>/Library/MaskMakerAutoSave/` |
| 지워지는 시점 | 실제 저장에 성공하면 임시 파일이 삭제됩니다 |

→ [설정과 프리셋](/reference/settings-and-presets)

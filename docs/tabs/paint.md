# 칠하기

**이 문서를 읽으면** 씬 뷰의 모델 위에 브러시로 직접 그려 마스크를 만드는 법과, 펜 필압과 UV 선택 기능을 알 수 있습니다.

**만드는 것:** 흑백 마스크. 생성 결과 위에 칠하면 칠한 부분만 보정으로 남습니다.

<!-- SCREENSHOT: 칠하기 중인 씬 뷰와 부유 도구 패널 -->

## 절차

1. Hierarchy에서 모델을 고르고 **현재 선택한 대상 사용**을 누릅니다.
2. 오른쪽 패널에서 머티리얼과 마스크를 고릅니다. 빈 칸을 고르면 해상도를 정해 새 마스크를 만듭니다.
3. **칠하기**를 누르고 씬 뷰에서 칠합니다.
4. **적용 결과 보기**로 확인합니다.
5. **저장·적용 → 마스크 출력**에서 저장합니다.

선택된 영역이 없어도 칠하기는 가능합니다. UV 전체에 칠할 수 있으므로, 선택 없음 경고로 막지 않습니다.

## 칠하기 옵션

칠하기 패널의 **차폐** 옵션을 켜면 카메라에서 가려진 면은 칠하지 않습니다. 끄면 가려진 면까지 관통해 칠합니다(X-Ray).

## 키

칠하기 도구와 브러시 크기, 강도, 선택 모드의 키는 [단축키](/reference/hotkeys)에 정리되어 있습니다. 씬 뷰에서는 `1`~`4`로 칠하기 도구를 고르고, UV 캔버스에서는 `1`~`4`가 선택 단위를 고릅니다.

UV 보기의 도구와 적용 버튼은 상단과 좌우의 작은 부유 패널에 있습니다. 슬라이더는 드래그하고, 숫자 칸은 더블클릭한 뒤 입력합니다. 좁은 창에서도 키 힌트와 `Space` / `Esc` 동작을 유지합니다.

## 펜 필압 {#펜-필압}

필압을 두 가지 항목에 각각 적용합니다.

| 항목 | 설정 범위 | 기본값 |
|---|---|---|
| **필압 크기** | 0~100% | 0% |
| **필압 불투명도** | 0~100% | 100% |

- `0%`는 해당 항목의 필압 영향을 끕니다.
- `100%`는 펜 압력을 그대로 반영합니다.
- 크기만, 불투명도만, 둘 다 켤 수 있습니다.
- 마우스는 중립 압력으로 처리됩니다.

펜 압력은 Unity에 값이 전달될 때 사용합니다. Windows 태블릿 드라이버가 압력을 보내야 합니다.

## 지원하지 않는 머티리얼

지원하지 않는 머티리얼은 PNG 출력만 안내합니다. 툴은 머티리얼에 텍스처를 자동으로 넣지 않습니다. PNG를 저장한 뒤 대상 머티리얼의 텍스처 슬롯에 직접 넣으세요.

## 스텐실과 데칼

스텐실 텍스처링과 데칼은 2.0의 마스크 만들기 방법에 없습니다. 기존 데이터는 보존됩니다.

## 칠하기 보정 {#칠하기-보정}

생성 결과 위에서 칠하면 칠한 부분만 보정으로 남습니다. 칠하지 않은 부분은 이후 [그라데이션](/tabs/gradient), [브릿지](/tabs/bridge-mask), [MatCap 광택](/tabs/matcap-gloss)의 설정을 바꾸면 따라 바뀝니다.

다시 칠하기를 누르면 같은 보정 작업으로 돌아갑니다. 생성기와 입력 이미지 파일은 보관됩니다.

→ [레이어와 마스크 출력](/concepts/layer-stack)

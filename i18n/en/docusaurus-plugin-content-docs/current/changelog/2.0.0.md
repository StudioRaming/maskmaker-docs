Version 2.0.0 reorganizes mask creation into five methods: Paint, Image, Gradient, Bridge and MatCap Gloss. You can combine methods as layers and then output the result as a mask. Unity 6 (6000.0, 6000.3 LTS) is supported.

## Check when you upgrade

:::caution[The workflow and some features have changed]
- You can no longer create color grading in Mask Maker. Do color grading in MingPainter. Results from existing color layers are kept.
- Stencil, decal and cavity/AO are no longer among the methods for creating a new mask. Existing data is kept. → [Paint](/tabs/paint)
- A 1.x layer document is converted to the new format the first time you save it in 2.0. The original is backed up under `Library/StudioRaming/MaskMaker/DocumentBackups/`, and a converted document cannot be opened in 1.x. → [Layers and mask output](/concepts/layer-stack)

:::

To update, import the new package over the existing `Assets/StudioRaming/MaskMaker` folder.


## New features

- **Guided / Expert modes** — Guided focuses on the selected mask's effect settings and Scene view editing. Expert gives detailed control over layers, mesh, output and tools. Switching modes keeps your work. → [Make your first mask](/getting-started/first-mask)
- **Five mask methods** — Paint, Image, Gradient, Bridge, MatCap Gloss. → [Paint](/tabs/paint) · [Image](/tabs/image) · [Gradient](/tabs/gradient) · [Bridge](/tabs/bridge-mask) · [MatCap Gloss](/tabs/matcap-gloss)
- **Combining methods** — Adding a method to a mask that has content uses **Limit area** by default. **Add white areas** and **Use only this** are also available. → [Layers and mask output](/concepts/layer-stack#방법-조합)
- **Paint correction** — Painting on a generated result keeps only the painted part as a correction. Other parts follow later changes. → [Paint](/tabs/paint#칠하기-보정)
- **Pen pressure size and pressure opacity** — Each is applied from 0 to 100%. → [Paint](/tabs/paint#펜-필압)
- **Save Layer** — Saves one layer by itself. A drawing that is not connected to a layer is restored without replacing an existing layer. → [Layers and mask output](/concepts/layer-stack#레이어-저장)
- **Mask Output** — From **Save and apply → Mask Output**, set the output size and UV edge bleed. The editable layer document is saved with it. → [Layers and mask output](/concepts/layer-stack#마스크-출력)
- **Three views** — Mask only, Applied result, Original. Mask work is kept in Original view too.
- **Open mask list and search** — Show empty slots is on by default. Search by name, material, shader property or texture.
- **Automatic keep and recovery banner** — Unsaved work is kept on script reload, Play, scene change and when editing stops. After an unexpected quit, choose **Restore** or **Discard**. → [Layers and mask output](/concepts/layer-stack#되돌리기와-자동-보존)
- **Undo steps** — Each apply, selection change and stroke is one step.
- **Open from the MingToon mask slot** — Open the tool straight from a mask slot in the MingToon Inspector. → [MingToon](/shaders/mingtoon)
<!-- CONFIRM: The minimum MingToon version is not in the 2.0 manual (DRAFT_NOTES F4). -->
- **Language switch in the window** — Switch between 한국어, English and 日本語 at the top right of the window. The setting is shared with other StudioRaming tools.
- **Unity 6 support** — 6000.0 and 6000.3 LTS.

## Changes

- New masks can be created with five methods: Paint, Image, Gradient, Bridge and MatCap Gloss.
- During Play, Load, Edit and adding layers are turned off, because changes made during Play are not kept.
- Supported Unity range: 2019.4 to 6000.3.
<!-- CONFIRM: The support range follows the 2.0 manual. 2019.4 has no runtime verification, and 6000.x has only the compile gate (DRAFT_NOTES F1, F2). -->

## Fixes

- Fixed layers disappearing on Play, scene change, reload and window close. They are now kept and restored when you return.
- Fixed creating a new canvas overwriting crash recovery data.
- Fixed saving a mask into a packed texture (for example `_MaskMap` or `_RegionMask`) clearing other channels.
- Fixed bridge layers disappearing when the material changed.
- Fixed MatCap layer outline values not applied in the final output.
<!-- CONFIRM: Confirm whether these are changes from 1.x (DRAFT_NOTES). The cavity outline item was removed because cavity is not in the 2.0 creation list. -->
- Fixed saving failing in projects with long paths.
- Fixed the build breaking on Unity 2019.4.

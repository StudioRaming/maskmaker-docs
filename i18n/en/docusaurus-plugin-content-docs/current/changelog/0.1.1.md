*Release: 0.1.1*

Paint tab added; Isolation tab merged into Bridge tab; tab structure organized into 6.

## Check on upgrade

:::caution[Tab structure reduced from 8 to 6]
**Isolation** tab is now **Manual pick** mode in [Bridge Mask](/tabs/bridge-mask) tab, and **Help** tab moved to header **?** button.

Manual pick mode output filenames keep **`_Isolation` suffix**, so previous masks don't clash names.
:::

## New features

- **Paint tab** — Blender-style texture paint with brush directly on mesh in Scene view to make mask/color textures. Draw/Erase/Smooth/Fill, Normal Limit, Occlusion, Mirror, stencil texturing, 8 built-in stencils, auto-save recovery. → [Docs](/tabs/paint)
- **MatCap Gloss — AO (Cavity) submode** — Bake shadow only from mesh recesses. Ignores Scene view angle; check with **Preview Bake** button. → [Docs](/tabs/matcap-gloss)
- **Refine in Paint** — Hand-paint over MatCap bake result in Paint tab. → [Docs](/tabs/paint)
- **Gradient — Reference Bone** — Start/end follow bone; pose-change pose-switched avatars keep position; preset re-finds same-named bone across avatars. → [Docs](/tabs/gradient#기준-본)
- **Bridge Mask — Edit selection** — Select All / Deselect All / Invert Selection / Grow Selection, **Recent Seeds** log, send to Paint tab. → [Docs](/tabs/bridge-mask)
- **Slot Split — Safeguards** — **Refresh**, **Reset Moves** / **Reset Structure** separate, **Execution Plan** card, **Duplicate materials for new slots** option, auto-preview restart after apply. → [Docs](/tabs/slot-split)
- **Combiner — Auto-optimize** — Auto-scan, thumbnails, drag between groups, **Apply Plan** card, auto-assign materials after bake. → [Docs](/tabs/combiner)
- **Combiner — Shader Profile** — Define/extend scan targets via JSON in `MaskMakerProfiles/` folder. Export Built-ins / Reload. → [Docs](/tabs/combiner#셰이더-프로파일)
- **Material Slot Picker** — Multiple material slots on mesh; pick one from base-map thumbnail per slot to bake/paint/preview. Output filename: `<Mesh>_<Material>`. Slots exceeding submesh count map to last submesh. → [Docs](/getting-started/first-mask#머티리얼-슬롯-피커)
- **Help (header ? button)** — "What is a mask texture?", per-tab purpose table, lilToon/Poiyomi/MingToon/NiloToon property connection tables (click names to copy), 4-step connection, FAQ. → [Docs](/concepts/what-is-a-mask)

## Changes

- **Isolation tab merged into Bridge tab**. Toggle **Random strands / Manual pick** mode at top to switch between behaviors. → [Docs](/tabs/bridge-mask)
- **Help moved from tab to header ? button**. **Close** button returns to tab screen.
- With above two changes, tab structure organized into 6 (**MatCap Gloss · Gradient · Bridge Mask · Slot Split · Combiner · Paint**).

## Improvements

- Scene view selection standardized across tabs: **Ctrl+click / Ctrl+drag paint / Ctrl+Shift+drag box**. → [Docs](/reference/hotkeys)
- Scene view editing now supports **Ctrl+Z / Ctrl+Y** Undo/Redo.
- Save now **confirms overwrite** (Overwrite / New Name / Cancel).
- **Auto re-load on Hierarchy pick** + scene hint display.
- **Recent Bakes** list added to each tab.

## Supported environment

Unity 2019.4 LTS ~ 2022.3 · Built-in RP / URP.

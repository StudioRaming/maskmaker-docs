# MatCap グロス

**このページを読むと** マットキャップグロスを白黒 UV マスクに焼き込む方法と、シーンビュー角度に関係なく、メッシュの凹部分だけで AO マスクを焼き込む方法が分かります。

**作成するもの：** 白黒マスクテクスチャ（シェーダーのグロス・エフェクトマスク入力用）

<!-- SCREENSHOT: MatCap グロス タブ全体 — グロス/AO 切り替え、マットキャップスロット、スライダー -->

## 手順

1. Hierarchy からヘア（またはターゲット）オブジェクトを選択 → **Load**
2. **Preview** ON → シーンビューカメラを回して、グロスが掴まる角度に合わせます
3. MatCap テクスチャを選択して**丸さ / 強度 / コントラスト**を調整します
4. シーンビューハンドルで位置を合わせます
5. **Bake** — 現在のシーンビュー視点を基準に焼き込み、元のテクスチャフォルダに自動保存されます

メッシュにマテリアルが複数ある場合、チェックボックス下のサムネイルで作業対象のスロットを最初に選択してください。
→ [マテリアルスロットピッカー](/getting-started/first-mask#머티리얼-슬롯-피커)

## シーンビューハンドル

| ハンドル | 操作 |
|---|---|
| オレンジ球 | 仮想球の中心を移動 |
| 端のノブ | 半径 |
| 回転リング | グロス方向の回転（カメラは固定） |

<!-- SCREENSHOT: シーンビューのオレンジ仮想球ハンドルと回転リング -->

:::note[Preview がオフの場合、ハンドルに触ることはできません]
プレビューがオフの状態では、ハンドルが薄く表示され、編集できません。値が誤って変更されるのを防ぐためのものです。
:::

## グロス / AO（キャビティ）サブモード

タブ上部のトグルで 2 つのマスクを切り替えます。

| モード | 基準 | シーンビュー角度 | プレビュー方式 |
|---|---|---|---|
| **グロス** | マットキャップ + メッシュノーマル | 影響**あり** — 現在視点を基準に焼き込み | リアルタイム |
| **AO（キャビティ）** | メッシュ形状の凹み具合 | 影響**なし** | **プレビューベイク**ボタン |

AO モードはカメラをどこに置いても結果が同じです。形状そのものを読むためです。リアルタイムプレビューの代わりに、**プレビューベイク**ボタンで結果を事前確認します。

| AO モード調整項目 | 動作 |
|---|---|
| 半径 | どの程度の範囲を「凹み」と見なすか |
| サンプル数 | 品質。高いほど遅く、滑らかに |
| 強度 | 暗くなる程度 |
| コントラスト | 明るい部分と暗い部分の差 |
| 反転 | 凹んだ部分の代わりに、膨らんだ部分を白で表示 |

## プリセット

設定（グローバル方向・球サイズなど）を保存しておくと、別のメッシュで同じものを読み込んで使用できます。複数のオブジェクトに分かれたヘアに同じグロスを入れる場合に使用します。

→ [設定とプリセット](/reference/settings-and-presets)

## ペイントで仕上げる

ベイク結果の隣の**ペイントで仕上げる**ボタンをクリックすると、そのマスクが [ペイントタブ](/tabs/paint) に転送されます。計算で得たグロスの上に手で続け描きできます — 前髪の数本だけグロスを消すか、計算が見落とした場所を埋める場合。

## 保存

- ファイル名に**メッシュ構成**が含まれるため、同じ構成同士のみが互いに上書きされます。
- 同じ名前のファイルがある場合は上書き / 新しい名前 / キャンセルを尋ねます。
- タブ下部の**最近のベイク**リストからピング（検索）・フォルダを開くで即座に確認できます。
- Hierarchy 選択が変わると**「選択が変更されました — 再ロード」**行が表示されます（プレビュー中は自動ロードがオフになります）。

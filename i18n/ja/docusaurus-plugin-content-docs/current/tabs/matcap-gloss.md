# マットキャップ光沢

**このページを読むと** マットキャップのハイライトを白黒のマスクにベイクする方法が分かります。

**作るもの:** マットキャップのハイライトをベイクした白黒のマスク（シェーダーの光沢・エフェクトのマスク入力用）

<!-- SCREENSHOT: マットキャップ光沢の方法: マットキャップの選択と調整項目 -->

## 手順

1. 髪（または対象）のモデルを選び、**現在の選択を使用** を押します。
2. 右側のパネルで、マスクを選ぶか空の欄を開き、方法で **マットキャップ光沢** を選びます。
3. **光沢の形**、**仮想球**、**マスク変換** のカードで、光沢の形を決めます。詳細項目は折りたたまれています。
4. **適用結果を表示** で確認します。
5. **保存・適用 → マスク出力** から保存します。

プリセットの行で、設定を **保存** または **削除** できます。

## 光沢の向き

ベイクするときは、**最後にアクティブだった Scene ビュー** のカメラの向きを使います。希望の角度に Scene ビューを合わせてから、ベイクしてください。

## 描いて仕上げる

マットキャップ光沢の結果の上に [描く](/tabs/paint) で描くと、描いた部分だけが補正として残ります。計算された光沢の上に、手で描き足すこともできます。前髪の 1 本だけから光沢を消したり、計算が漏れた箇所を埋めたりするときに使います。

## ほかの方法と組み合わせる

内容のあるマスクにマットキャップ光沢を足すと、標準では **範囲を絞る** を使います。[ブリッジ](/tabs/bridge-mask)で選んだ毛束の中だけに光沢を残せます。

→ [レイヤーとマスク出力](/concepts/layer-stack)

## 保存

出力ファイルは白黒で、sRGB をオフにした状態でインポートされます。

→ [sRGB とインポート設定](/concepts/srgb-and-import-settings)

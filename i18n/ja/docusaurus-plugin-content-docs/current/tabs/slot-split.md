# スロット分割

**このページを読むと** クリックした束を異なるマテリアルスロットに移した新しいメッシュを作成し、シーン内で交換する方法が分かります。

**作成するもの：** マスクではなく**メッシュアセット**です。完全に異なるシェーダーを適用する部位を分離する場合に使用します。

<!-- SCREENSHOT: スロット分割 タブ — メッシュカードとスロットリスト、シーンビュー凡例 -->

## マスクでできない場合に使用

マスク は**1 つのマテリアル内**でエフェクトの強度を調節します。しかし「この部分だけ透明シェーダー」「この部分だけエミッション専用マテリアル」のように**シェーダー自体が異なる**必要がある場合、マスクでは不可能です。その場合、メッシュをサブメッシュ単位に分割します。

## 手順

1. オブジェクト選択 → **Load** — 即座にスロット別に異なる色が入り、現在の配置が見えます（シーンビュー左上の凡例参考）
2. **ターゲットスロット**をシーンビュー凡例またはメッシュカードの行をクリックして指定
3. シーンビューで移す束を `Ctrl` + クリック — 選択された束がターゲットスロット色で表示されます
4. 誤って移した場合は**移動を初期化**または**構造を初期化**で元に戻します
5. **適用計画**カードでメッシュ別の保存パスとバッジを確認
6. **適用** — 確認ウィンドウ後、新メッシュアセットを保存してシーンの SkinnedMeshRenderer を交換

適用後、プレビューは自動的に再起動します。

## スロット追加と削除

| ボタン | 動作 |
|---|---|
| **+ スロット追加** | 新スロットを作成し、自動的にターゲットスロットに指定 |
| **×** | スロットを削除し、**すぐ上のスロットに統合** |

構造が変わると `[構造変更]` バッジが表示されます。

## 更新

**更新**は Hierarchy 選択と**無関係に**、今ロードされたメッシュのみを再度読み込みます。シーン内で別のオブジェクトをクリックした後も、作業ターゲットは変わりません。

## 2 つの初期化

| ボタン | 戻す範囲 |
|---|---|
| **移動を初期化** | 束の移動のみを取り消す。追加/削除したスロット構成は保持 |
| **構造を初期化** | 追加/削除したスロットまで**Load 時点に**復元 |

## 適用計画 {#적용-계획}

**適用**ボタン上のカードが実行前に何が起こるかを示します。

<!-- SCREENSHOT: 適用計画 カード — メッシュ別バッジと保存パス -->

| バッジ | 意味 |
|---|---|
| 新規作成 | 新しいメッシュアセットファイルを作成 |
| 一意のパス | 同じ名前があるため、異なる名前で作成 |
| 上書き | 以前に Mask Maker が作成した出力を**GUID を保持したまま**更新 |

:::danger[上書きは Mask Maker が作成したファイルのみで発生]
Mask Maker 所有表示と元の GUID/local ID が**両方とも一致する**出力のみ GUID を保持して更新します。外部ファイル · 表示なしのファイル · 元が異なるファイルは**決して上書きしません**。

GUID を保持するため、プリファブ・アニメーションの参照は断絶されません。
:::

キャンセルまたは失敗した場合は**すべてロールバック**されます。一部のみが適用された状態で残りません。

## 新スロットにマテリアルを複製

デフォルトでは、新スロットに**元のスロットと同じマテリアル**が割り当てられます — 適用後に任意のマテリアルに直接変更する必要があります。

**新スロットにマテリアルを複製**をオンにすると、新スロットごとに別個のマテリアル（`_SplitN.mat`）を受け取ります。すぐに値を異なるものにできます。

## 保持されるもの

| データ | 状態 |
|---|---|
| ブレンドシェープ | 保持 |
| ボーンウェイト | 保持 |
| UV（全チャンネル） | 保持 |
| ノーマル · タンジェント | 保持 |
| サブメッシュ割り当て | **これのみ変更** |
| GUID | 所有出力を更新する際に保持 |
| Undo/Redo | 対応 |

## シーンビュー操作

| 操作 | 結果 |
|---|---|
| `Ctrl` + クリック | 束をターゲットスロットに移動 / 取消 |
| `Ctrl` + ドラッグ | 通過した束を切り替え |
| `Ctrl+Shift` + ドラッグ | ボックスで追加選択 |
| `Ctrl+Shift+Alt` + ドラッグ | ボックスで選択解除 |
| クリックのみ | 通常通りシーンオブジェクトを選択 |
| `Ctrl+Z` / `Ctrl+Y` | 元に戻す / やり直す |

内側・反対側の束は**裏面モード**をオンにすると便利です。

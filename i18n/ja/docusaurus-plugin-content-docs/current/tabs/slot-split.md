# スロット分割
**このページを読むと** クリックした束を異なるマテリアルスロットに移した新しいメッシュを作成し、シーン内で交換する方法が分かります。

**作成するもの：** マスクではなく**メッシュアセット**です。完全に異なるシェーダーを適用する部位を分離する場合に使用します。

タブ上部の**分割** / **統合**トグルで 2 つの方向を行き来します。**分割**は束を異なるスロットに移し、**統合**はスロットを複数個から 1 つのサブメッシュに戻します。

<!-- SCREENSHOT: スロット分割 タブ — メッシュカードとスロットリスト、シーンビュー凡例 -->

## マスクでできない場合に使用

マスクは**1 つのマテリアル内**でエフェクトの強度を調節します。しかし「この部分だけ透明シェーダー」「この部分だけエミッション専用マテリアル」のように**シェーダー自体が異なる**必要がある場合、マスクでは不可能です。その場合、メッシュをサブメッシュ単位に分割します。

## 手順

1. オブジェクト選択 → **読み込み** — 即座にスロット別に異なる色が入り、現在の配置が見えます（シーンビュー左上の凡例参考）
2. **ターゲットスロット**をシーンビュー凡例またはメッシュカードの行をクリックして指定
3. シーンビューで移す束を `Ctrl` + クリック — 選択された束がターゲットスロット色で表示されます
4. 誤って移した場合は**移動を初期化**または**構造を初期化**で元に戻します
5. **適用計画**カードでメッシュ別の保存パスとバッジを確認
6. **適用** — 確認ウィンドウ後、新メッシュアセットを保存してシーンの SkinnedMeshRenderer を交換

適用後、プレビューは自動的に再起動します。

## スロット追加と削除

| ボタン | 動作 |
|---|---|
| **+ スロット追加** | 新スロットを作成し、自動的にターゲットスロットに指定 |
| **×** | スロットを削除し、**すぐ上のスロットに統合** |

構造が変わると `[構造変更]` バッジが表示されます。

## 更新

**更新**は Hierarchy 選択と**無関係に**、今ロードされたメッシュのみを再度読み込みます。シーン内で別のオブジェクトをクリックした後も、作業ターゲットは変わりません。

## 2 つの初期化

| ボタン | 戻す範囲 |
|---|---|
| **移動を初期化** | 束の移動のみを取り消す。追加/削除したスロット構成は保持 |
| **構造を初期化** | 追加/削除したスロットまで**読み込み時点に**復元 |

## 適用計画 {#적용-계획}

**適用**ボタン上のカードが実行前に何が起こるかを示します。

<!-- SCREENSHOT: 適用計画 カード — メッシュ別バッジと保存パス -->

| バッジ | 意味 |
|---|---|
| 新規作成 | 新しいメッシュアセットファイルを作成 |
| 一意のパス | 同じ名前があるため、異なる名前で作成 |
| 上書き | 以前に Mask Maker が作成した出力を**GUID を保持したまま**更新 |

:::danger[上書きは Mask Maker が作成したファイルのみで発生]
Mask Maker 所有表示と元の GUID/local ID が**両方とも一致する**出力のみ GUID を保持して更新します。外部ファイル · 表示なしのファイル · 元が異なるファイルは**決して上書きしません**。

GUID を保持するため、プリファブ・アニメーションの参照は断絶されません。
:::

キャンセルまたは失敗した場合は**すべてロールバック**されます。一部のみが適用された状態で残りません。

## 新スロットにマテリアルを複製

デフォルトでは、新スロットに**元のスロットと同じマテリアル**が割り当てられます — 適用後に任意のマテリアルに直接変更する必要があります。

**新スロットにマテリアルを複製**をオンにすると、新スロットごとに別個のマテリアル（`_SplitN.mat`）を受け取ります。すぐに値を異なるものにできます。

## 保持されるもの

| データ | 状態 |
|---|---|
| ブレンドシェープ | 保持 |
| ボーンウェイト | 保持 |
| UV（全チャンネル） | 保持 |
| ノーマル · タンジェント | 保持 |
| サブメッシュ割り当て | **これのみ変更** |
| GUID | 所有出力を更新する際に保持 |
| Undo/Redo | 対応 |

## 統合モード {#합치기-모드}

**分割の逆操作です。** スロット複数個をサブメッシュ 1 つに戻します — 分けたけれどやはり分ける必要がなかった場合、またはドロー呼び出しを減らしたい場合に使用します。

<!-- SCREENSHOT: 統合モード - スロットカード チェックボックスと「残すマテリアル」選択 -->

### 手順

1. タブ上部で**統合**を選択
2. オブジェクト選択 → **読み込み**
3. 統合するスロットを**2 つ以上**選択 — スロットカードの**チェックボックス**（ベースマップサムネイル付き）またはシーンビューの `Ctrl` + クリック
4. **残すマテリアル**を選択。統合されたサブメッシュはこのマテリアルを使い、残りは**レンダラーからのみ削除されます**（マテリアルアセットは削除されません）。デフォルトは最初に選んだスロットです
5. **統合** — 確認ウィンドウのサマリー（`スロット N→M、三角形数`）を見て実行

選択数は `{選択} / {合計} スロット選択（2つ以上必要）` で表示されます。

### 警告は実行を止めません

2 つの場合に警告が表示されますが**実行は止まりません。** 意図的に統合する場合があるからです。

| 警告 | 意味 |
|---|---|
| ベースマップが異なります | 統合すると**残したマテリアルのテクスチャだけ**が使用されます |
| 選択スロットの UV 領域が重なっています | 1 つのテクスチャに統合すると**同じ領域を共有**します |

### 保存される内容と取り消し

| 項目 | 動作 |
|---|---|
| 新メッシュ | 元のアセットの隣に `*_merged.asset` として保存されます（シーン専用メッシュは保存先を直接指定） |
| 元のアセット | **変更されません** |
| レンダラー | 新メッシュに置き換えられ、マテリアル配列から統合されたスロットが削除されます |
| 同じメッシュを使用する別のレンダラー | 一緒にリバインドされます — 片方だけ更新されて画面が変わらない事態がありません |
| `Ctrl+Z` | **メッシュとマテリアル配列が一緒に**元に戻ります |

適用中のキャンセルまたは失敗は分割と同じく**全体がロールバック**されます。

:::caution[分割モードに未適用の変更があるとロックされます]
分割モードで移動した束または追加/削除したスロットをまだ**適用**していない場合、統合は使用できません。先に**適用**するか、**移動を初期化** / **構造を初期化** で整理してください。
:::

### シーンビュー操作（統合モード）

| 操作 | 結果 |
|---|---|
| `Ctrl` + クリック | そのスロットを選択 / 解除 |
| `Ctrl+Z` / `Ctrl+Y` | 取り消し / やり直し |

残すマテリアルはシーンビューではなくパネルで選択します。選択されたスロットカードに**残す**バッジが付きます。

## シーンビュー操作（分割モード）

| 操作 | 結果 |
|---|---|
| `Ctrl` + クリック | 束をターゲットスロットに移動 / 取消 |
| `Ctrl` + ドラッグ | 通過した束を切り替え |
| `Ctrl+Shift` + ドラッグ | ボックスで追加選択 |
| `Ctrl+Shift+Alt` + ドラッグ | ボックスで選択解除 |
| クリックのみ | プレビュー中は**別のオブジェクトが選択されません** |
| `Ctrl+Z` / `Ctrl+Y` | 取り消し / やり直し |

内側・反対側の束は**両面編集**をオンにすると便利です。

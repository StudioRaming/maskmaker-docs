# ブリッジマスク

**このページを読むと** ヘアの束をランダムに選択するか、直接クリックしてマスクを作成する方法と、保存と同時にシェーダースロットに挿入する自動割り当てが分かります。

**作成するもの：** 白黒マスク PNG — NiloToon スタッキングレイヤー / 分離マスク用

<!-- SCREENSHOT: ブリッジマスク タブ — ランダム束/手動選択モード切り替え、比率スライダー、最近のシード チップ -->

## 2 つのモード

タブ上部のトグルで切り替えます。**2 つのモードはクリックで有効・無効にした束を相互に共有します** — ランダムで引き出しておいて、手動で調整してからまたランダムに戻っても、調整内容は残ります。

| モード | 動作 | 主な用途 |
|---|---|---|
| **ランダム束** | 比率・シードで束を自動選択し、クリックで調整 | ブリッジ（ハイライト）染色 — ヘアの一部だけ別の色 |
| **手動選択** | 自動選択なし。クリックした束だけが白い | 特定部位の分離 |

:::note[手動選択モードは旧「分離」タブです]
v0.1.1 で分離タブがブリッジタブに統合されました。動作は同じで、出力ファイル名の `_Isolation` サフィックスも変わらず保持されます — 既存作業ファイルと名前がずれません。
:::

## 手順

1. 上部で**ランダム束** / **手動選択**モードを選択
2. ヘアオブジェクト選択 → **Load** → **Preview** ON
3. （ランダム束）束**比率 / 太さ / サイズフィルタ**を調整し、気に入る間まで**ランダムシード**をクリック
4. シーンビューで束にマウスを重ねてプレビューを確認し、`Ctrl` + クリックで追加・削除
5. パネルボタンで調整
6. **Bake** — 白黒マスク PNG として保存（マテリアルは変更されません）

メッシュにマテリアルが複数ある場合、上部のサムネイルで作業対象の（有効な）スロットを選択してください。
→ [マテリアルスロットピッカー](/getting-started/first-mask#머티리얼-슬롯-피커)

## シーンビュー操作

束にマウスを重ねると、結果が色でプレビュー表示されます。

| ハイライト | 意味 |
|---|---|
| **シアン**（`#33CCFF`） | `Ctrl` + クリックで**選択される** |
| **赤**（`#FF5544`） | `Ctrl` + クリックで**解除される** |

| 操作 | 結果 |
|---|---|
| `Ctrl` + クリック | 束の追加 / 削除 |
| `Ctrl` + ドラッグ | 通過した束をペイントのように切り替え |
| `Ctrl+Shift` + ドラッグ | ボックスで追加選択 |
| `Ctrl+Shift+Alt` + ドラッグ | ボックスで選択解除 |
| クリックのみ | 通常通りシーンオブジェクトを選択 |
| `Ctrl+Z` / `Ctrl+Y` | 元に戻す / やり直す |

前面/背面とミラー束は**自動的に一緒に切り替わり**、ステータスバーに何個が一緒に切り替わったかが表示されます。

## 選択を調整する

| ボタン | 動作 |
|---|---|
| すべて選択 | すべての束を選択 |
| すべて解除 | 選択を空にする |
| 選択を反転 | 選択/非選択を反転 |
| 選択を拡張 | 今選択されている束に隣接する束まで広げる |

| オプション | 動作 |
|---|---|
| **裏面モード** | 前面を隠し、背面のみを表示してカメラを回さずに内側・反対側の束を拾えます。**保存されるマスクに影響しません** |
| **UV 重複束を一緒に選択** | 両面シート・ミラー束を一度に切り替えます |

選択状態は**モードを変更したり、プレビューを切ってオンにしても保持**され、**Load 時に初期化**されます。

## ランダムシードと最近のシード

**ランダムシード**ボタンをクリックするたびに異なる組み合わせが出現します。気に入った組み合わせを見落とした場合、隣の**最近のシード**チップをクリックしてそのシードに戻します。

<!-- SCREENSHOT: ランダムシード ボタンと 最近のシード チップリスト -->

| フィルタ | 動作 |
|---|---|
| 束比率 | 全束の何 % を選択するか |
| 太さフィルタ | 細い/太い束のみを対象に |
| サイズフィルタ | 小さい/大きい束のみを対象に |

## 後処理

| オプション | 動作 |
|---|---|
| グラデーション | 根→先方向にマスク値をぼかす |
| エッジフェード | 束の端を柔らかく（ピクセル単位 + 柔らかさ） |
| ティント色 | **プレビュー専用**です。保存されるマスクは常に白黒です |

## ベイク後に自動割り当て

**ベイク後に自動割り当て**をオンにしておくと、保存と同時に NiloToon スタッキングレイヤースロットに即座に挿入されます。ターゲットプロパティも一緒に選択できます。

これをオンにすると [最初のマスクを作成する](/getting-started/first-mask) の 3～4 ステップを直接行う必要がなくなります。

## ペイントタブへ送る

**ペイントタブへ送る**ボタンで現在の選択マスクを [ペイントタブ](/tabs/paint) に転送して手で続け描きできます。両モードで動作します。

## どこに挿入するか

| シェーダー | スロット |
|---|---|
| NiloToon | `Base Map ▸ Stacking Layer 1..10 ▸ Mask Tex` — 自動割り当てターゲット |
| lilToon | `Main Color ▸ 2nd ▸ Mask` · `Main Color ▸ 3rd ▸ Mask` |
| Poiyomi | `RGBA Color Masking ▸ Masks`（コンバイナーで 4 枚束ねた後） |
| MingToon | `Region ▸ Region Mask`（コンバイナーで 4 部位束ねた後） |

完全な表については → [シェーダー接続](/shaders/nilotoon)

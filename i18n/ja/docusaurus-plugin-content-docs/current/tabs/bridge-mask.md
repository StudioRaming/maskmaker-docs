# ブリッジ

**このページを読むと** 髪の毛束をランダムに、またはクリックで選び、そこから白黒のマスクを作る方法が分かります。

**作るもの:** 選んだ髪の毛束だけが白いマスク

## 手順

1. 髪のモデルを選び、**現在の選択を使用** を押します。
2. 右側のパネルで、マスクを選ぶか空の欄を開き、方法で **ブリッジ** を選びます。
3. **ランダム毛束** モードで毛束を選ぶか、**手動選択** モードで Scene ビューをクリックして選びます。
4. **適用結果を表示** で確認します。
5. **保存・適用 → マスク出力** から保存します。

メッシュの **Read/Write Enabled** がオフのときは、ブリッジがオンにしてよいかを尋ねます。許可すると、オンになります。

## ランダム毛束モードの設定

| 項目 | 意味 |
|---|---|
| **毛束の割合 (%)** | 全体の毛束のうち、ランダムに選ぶ割合。ブリッジの密度を決めます |
| **毛束の太さ (%)** | 毛束の中で使う face の割合。下げると中央の線だけが残ります |
| **サイズフィルター (%)** | 表面積の小さい順に N% の毛束だけを候補にします。大きなシートを外したいときは下げます |
| **前側の毛束のみ** | メッシュの後ろ側（Z 基準）の毛束を候補から外します |
| **シード** / **ランダムシード** | 同じシードなら、いつも同じ結果になります。**最近のシード** から前のシードに戻れます |
| **拡張** | 含めない / 近くの毛束 (5mm) / 頂点を共有。選んだ毛束の隣の毛束も一緒に入れます |
| **範囲** | 選択範囲、またはメッシュ全体 |
| **ぼかし** | face の境界をガウシアンブラーで柔らかくします。0 はオフ、1〜3 を推奨します |
| **エッジのフェード** | 端を少しずつ薄くします（フェードのピクセル数とフェードのカーブ） |
| **ティント（プレビュー）** | プレビューにだけ重ねて見える色です。保存されるマスクは常に白黒です |

**選択を反転** と **選択を拡張** で、選んだ毛束を裏返したり、隣の毛束を追加したりできます。

## Scene ビューでの選択

毛束にマウスを重ねると、結果が色で先に表示されます。

| ハイライト | 意味 |
|---|---|
| **シアン**（`#33E5FF`） | まだ選んでいない毛束。`Ctrl` + クリックで追加されます |
| **赤**（`#FF4033`） | 選択済みの毛束。`Ctrl` + クリックで外れます |

| 操作 | 結果 |
|---|---|
| `Ctrl` + クリック | 毛束を追加または解除します |
| `Ctrl` + ドラッグ | 通った毛束をペイントブラシのようにトグルします |
| `Ctrl+Shift` + ドラッグ | 矩形の中の毛束を範囲選択して追加します |
| `Ctrl+Shift+Alt` + ドラッグ | 矩形の中の毛束を範囲選択して解除します |
| `Ctrl+Z` / `Ctrl+Y` | 取り消し / やり直し |

表と裏の面、UV が重なるミラーの毛束は一緒にトグルされます。キーの一覧は [ショートカット](/reference/hotkeys) にあります。

## ほかの方法と組み合わせる

ブリッジの結果を基準に、[グラデーション](/tabs/gradient)や[マットキャップ光沢](/tabs/matcap-gloss)を **範囲を絞る** で足すと、選んだ毛束の中だけに効果が残ります。

→ [レイヤーとマスク出力](/concepts/layer-stack)

## ベイク後に自動割り当て

**ベイク後に自動割り当て** をオンにすると、保存したマスクをマテリアルの割り当て可能なスロットに自動で接続します。対象は NiloToon、lilToon、Poiyomi のマテリアルだけです。初期設定はオフで、Undo で戻せます。

## 描いて仕上げる

ブリッジの結果の上に [描く](/tabs/paint) で描くと、描いた部分だけが補正として残ります。

## 保存

出力ファイルは白黒で、sRGB をオフにした状態でインポートされます。**手動選択** モードで保存したファイル名は `_Isolation` で終わり、**ランダム毛束** モードのファイル名は `_BridgeMask` で終わります。

→ [sRGB とインポート設定](/concepts/srgb-and-import-settings)

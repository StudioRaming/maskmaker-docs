# 画像

**このページを読むと** 手元の Texture2D をマスクの内容として使う方法が分かります。

**作るもの:** 選んだ Texture2D を内容とする白黒マスク。入力の画像ファイルは元のまま保持されます。

## 手順

1. 右側のパネルで、マスクを選ぶか空のスロットを開きます。
2. 方法で **画像** を選びます。
3. Texture2D を選びます。
4. **適用結果** で確認します。
5. **保存・適用 → マスク出力** から保存します。

アセットファイルからインポートされていない Texture2D（インポーターがないテクスチャ）は、**Read/Write Enabled** がオンである必要があります。オフの場合、ツールはそのテクスチャを拒否します。

## ほかの方法と組み合わせる

内容のあるマスクに画像を追加すると、標準で **範囲を絞る** を使います。**白い範囲を追加** と **これだけ使う** も選べます。

→ [レイヤーとマスク出力](/concepts/layer-stack)

## 保存

出力ファイルは白黒で、sRGB をオフにした状態でインポートされます。

→ [sRGB とインポート設定](/concepts/srgb-and-import-settings)

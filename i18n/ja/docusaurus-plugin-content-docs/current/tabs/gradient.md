# グラデーション

**このページを読むと** ワールド方向グラデーションをカラーテクスチャに焼き込む方法と、ポーズが変わっても位置を保持させるための基準ボーン設定が分かります。

**作成するもの：** カラー UV テクスチャ（sRGB）— オンブレ・フェード染色用

<!-- SCREENSHOT: グラデーション タブ — グラデーション編集器、方向ボタン、ラップオプション -->

## 手順

1. オブジェクト選択 → **Load** → **Preview** ON
2. グラデーション色を編集するか、プリセット（白→黒など）を使用します
3. 方向ボタン（↑ ↓ ← → 前 後）で方向を合わせるか、シーンビューで開始/終了ハンドルを直接ドラッグします（中央ノブ = 全体移動）
4. ラップ（延長 / 繰り返し / ミラー）とプレビュー表示方式を確認します
5. **Bake** — カラーテクスチャ（sRGB）として保存されます

メッシュにマテリアルが複数ある場合、チェックボックス下のサムネイルで作業対象のスロットを選択してください。
→ [マテリアルスロットピッカー](/getting-started/first-mask#머티리얼-슬롯-피커)

## ワールド位置を基準とします

グラデーションは**ワールド座標**を読んで作成されます。カメラをどのように回転させても、結果は同じです。同じ場所に立つアバターであれば、プリセットを適用するだけで同じ方向・範囲が再現されます。

Preview がオフの場合、シーンビューハンドルは薄く表示され、編集できません。

## 基準ボーン {#기준-본}

**ポーズが変わるとワールド座標はずれます。** アバターが腕を上げると、袖のグラデーションが体を基準とした位置にそのまま残ります。

**基準ボーン**を指定すると、開始/終了点がそのボーンに従って動きます。

| 状況 | 基準ボーン なし | 基準ボーン 指定 |
|---|---|---|
| アバターが T ポーズ → A ポーズ | 位置がずれます | 保持 |
| プリセットを別のアバターに適用 | ワールド座標そのまま | **同じ名前のボーンを再度探して**再現 |
| その名前のボーンがないアバター | — | ワールド座標に自動代替 |

<!-- SCREENSHOT: 基準ボーンフィールドと、それに従って動くシーンビューの開始/終了ハンドル -->

:::tip[ヘアには Head、袖には腕ボーン]
動く部位にグラデーションを入れる場合、その部位を実際に動かすボーンを選択してください。そうすればポーズを変えながら確認してもイメージがぶれません。
:::

## ラップ（Wrap）

グラデーション範囲外をどのように埋めるかを定義します。

| 値 | 動作 |
|---|---|
| 延長（Clamp） | 両端の色をそのまま延長 |
| 繰り返し（Repeat） | グラデーションを繰り返す |
| ミラー（Mirror） | 繰り返しますが、方向を交互に反転 |

## 保存

- グラデーションは**カラー**なため、sRGB を**オンのまま**保存されます。マスクとは逆です。
  → [sRGB とインポート設定](/concepts/srgb-and-import-settings)
- 同じ名前のファイルがある場合は上書き / 新しい名前 / キャンセルを尋ねます。
- タブ下部の**最近のベイク**リストからピング · フォルダを開くで確認できます。
- Hierarchy 選択が変わると**「選択が変更されました — 再ロード」**行が表示されます。

## どこに挿入するか

グラデーション結果物はマスクではなく**色**です。マスクスロットではなく、カラーレイヤースロットに入ります。

| シェーダー | 例 |
|---|---|
| lilToon | `Main Color ▸ 2nd ▸ Color Texture` |
| Poiyomi | デカール · 2 番目メインテクスチャ系 |
| NiloToon | `Base Map ▸ Stacking Layer ▸ Color Tex` |

「どの部位にこの色を入れるか」を一緒に指定するには、[ブリッジ+領域マスク](/tabs/bridge-mask)または [ペイント](/tabs/paint) でマスクを別に作成し、同じレイヤーのマスクスロットに挿入します。

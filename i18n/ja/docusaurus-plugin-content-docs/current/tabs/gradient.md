# グラデーション

**このページを読むと** 開始点から終了点へ白黒の値が変わるマスクの作り方が分かります。

**作るもの:** 開始点から終了点へ白黒の値が変わるマスク

## 手順

1. 右側のパネルで、マスクを選ぶか空のスロットを開きます。
2. 方法で **グラデーション** を選びます。
3. **グラデーションカラー** のバーで、開始点（左、0%）と終了点（右、100%）を決めます。**白→黒**、**黒→白** で向きを選び、**色を反転** でキーの順番を逆にします。
4. **適用結果** で確認します。
5. **保存・適用 → マスク出力** から保存します。

**基準ボーン（任意）** を選ぶと、開始点と終了点がそのボーンに追従します（ポーズ追従）。ボーンが見つからない場合は、ワールド位置で焼き付けます。

## ほかの方法と組み合わせる

内容のあるマスクにグラデーションを追加すると、標準で **範囲を絞る** を使います。たとえば、[ブリッジ](/tabs/bridge-mask)で選んだ房の中だけにグラデーションを残せます。**白い範囲を追加** と **これだけ使う** も選べます。

→ [レイヤーとマスク出力](/concepts/layer-stack)

## 描いて補正する

生成結果の上で [描く](/tabs/paint) を使うと、描いた部分だけが補正として残ります。描いていない部分は、グラデーションの設定を変えると、それに従って変わります。

## 保存

出力ファイルは白黒で、sRGB をオフにした状態でインポートされます。

→ [sRGB とインポート設定](/concepts/srgb-and-import-settings)

# 描く

**このページを読むと** シーンビューのモデルの上にブラシで直接描いてマスクを作る方法と、ペン筆圧と UV の選択機能が分かります。

**作るもの:** 白黒のマスク。生成結果の上に描くと、描いた部分だけが補正として残ります。

## 手順

1. Hierarchy でモデルを選び、**現在の選択を使う** を押します。
2. 右側のパネルで、マテリアルとマスクを選びます。空の欄を選ぶと、解像度を決めて新しいマスクを作ります。
3. **描く** を押して、シーンビューで描きます。
4. **適用結果** で確認します。
5. **保存・適用 → マスク出力** から保存します。

選択された領域がなくても描けます。UV 全体に描けるため、「選択なし」の警告では止めません。

## 描画のオプション

描画パネルの **遮蔽** オプションをオンにすると、カメラから隠れている面は描かれません。オフにすると、隠れている面まで突き抜けて描きます（X-Ray）。

## キー

描画ツール、ブラシのサイズと強度、選択モードのキーは [ショートカット](/reference/hotkeys) にまとめてあります。シーンビューでは `1` から `4` で描画ツールを選び、UV キャンバスでは `1` から `4` で選択の単位を選びます。

UV 表示のツールと適用ボタンは、上と左右の小さなフローティングパネルにあります。スライダーはドラッグし、数値欄はダブルクリックしてから入力します。狭いウィンドウでも、キーのヒントと `Space` / `Esc` の動作は保たれます。

## ペン筆圧 {#펜-필압}

筆圧は 2 つの項目にそれぞれ適用します。

| 項目 | 設定範囲 | 初期値 |
|---|---|---|
| **筆圧サイズ** | 0〜100% | 0% |
| **筆圧不透明度** | 0〜100% | 100% |

- `0%` にすると、その項目の筆圧の影響をオフにします。
- `100%` にすると、ペンの圧力をそのまま反映します。
- サイズだけ、不透明度だけ、両方のどれでもオンにできます。
- マウスは中立の圧力として扱われます。

ペンの圧力は、値が Unity に渡されるときに使われます。Windows のタブレットドライバーが圧力を送っている必要があります。

## 対応していないマテリアル

対応していないマテリアルでは、PNG 出力だけを案内します。ツールはマテリアルにテクスチャを自動で入れません。PNG を保存したあと、対象マテリアルのテクスチャスロットに自分で入れてください。

## ステンシルとデカール

ステンシルのテクスチャリングとデカールは、2.0 のマスク作成方法には含まれません。既存のデータは保持されます。

## 描いて補正する {#칠하기-보정}

生成結果の上に描くと、描いた部分だけが補正として残ります。描いていない部分は、あとから [グラデーション](/tabs/gradient)、[ブリッジ](/tabs/bridge-mask)、[マットキャップ光沢](/tabs/matcap-gloss) の設定を変えると、それに合わせて変わります。

もう一度 **描く** を押すと、同じ補正の作業に戻ります。生成器と入力画像のファイルは保管されます。

→ [レイヤーとマスク出力](/concepts/layer-stack)

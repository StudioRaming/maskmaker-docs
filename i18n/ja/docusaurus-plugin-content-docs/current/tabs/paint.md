# ペイント

**このページを読むと** シーンビュー メッシュの上にブラシで直接描いてマスク・カラー テクスチャを作成する方法がわかります。他の5つのタブで計算により作成できない形状はすべてここで作成します。

**作成するもの:** マスク(グレースケール)またはカラー(RGBA)テクスチャ

<!-- SCREENSHOT: ペイントタブ — ツールボタン、ブラシスライダー、ステンシルカード -->

## 手順

1. 対象オブジェクトを選択 → **Load** → レンダラーごとに対象マテリアル スロットをサムネイルから選択して **Preview** ON
2. **新規テクスチャ**(サイズを選択)で開始するか**既存テクスチャを読み込み**で続き描きます — マスク / カラー モードを選択します
3. シーンビューで**そのまま左クリック ドラッグ**すると描画されます。`Ctrl`は不要で、`Alt`は通常通りカメラを回転させます
4. ツール・半径・強度・フォールオフを調整して描きます
5. **保存** または **名前を付けて保存**

## ツール

| ツール | 機能 |
|---|---|
| 描画 | 現在の色/値で塗ります |
| 消しゴム | 反対の値で塗ります |
| なめらか | 周辺の値を混ぜてエッジをぼかします |
| 塗りつぶし | `Ctrl` + クリックした**UV アイランド全体**を一度に塗ります |

## ブラシ ショートカット

| キー | 機能 |
|---|---|
| `[` `]` | 半径 |
| `<` `>` または `,` `.` | 強度(両方とも同じ機能) |
| `F` + ドラッグ | 半径モーダル調整 |
| `Shift+F` + ドラッグ | 強度モーダル調整 |
| `S` | スポイト — ベース テクスチャの色を抽出 |
| `X` | 色/値を交換 |
| `Ctrl` + クリック | 塗りつぶしツールを実行(別のツール使用中は一時的に塗りつぶし) |
| `Ctrl+Z` / `Ctrl+Y` | **ストローク単位**で実行取消 / やり直し |

値は GUI スライダーに**即座に反映**されます — シーンビューで調整した後パネルを見ると、その値が入っています。

## 塗画範囲の制限

| オプション | 機能 |
|---|---|
| **正面角度制限** | カメラに向かう角度が大きい(斜めの)面は塗りません。シルエット端が汚くなるのを防ぎます |
| **オクルード** | カメラから隠れた面には塗りません。**無効にすると X-Ray で貫通して**前後が一緒に塗られます |
| **ミラー** | 左右ミラー描画。X/Y/Z 軸を選択します |

## ステンシルテクスチャリング {#스텐실}

ステンシル カードに画像を置くと**画面に固定されたオーバーレイ**として表示されます。その上を描くとスタンプが押されます。

| キー | 機能 |
|---|---|
| `T` + ドラッグ | 移動 |
| `Shift+T` + ドラッグ | サイズ |
| `Ctrl+T` + ドラッグ | 回転 |
| `Alt+T` | 画面に合わせる |
| ホイール | サイズ調整 |

エッジ ハンドルで直接操作することもできます。

<!-- SCREENSHOT: ステンシル オーバーレイが画面に浮かんでエッジ ハンドルが見える シーンビュー -->

### 内蔵ステンシル

アニメ ヘアハイライト形状**8種**がデフォルト含まれており、すぐに使用できます。

| ファイル | 形状 |
|---|---|
| `angel_ring` | 天使の輪(ヘアハイライト) |
| `crescent` | 三日月 |
| `double_ring` | ダブルリング |
| `star4` | 4角星 |
| `diamond` | ひし形 |
| `wave` | 波 |
| `zigzag` | ジグザグ |
| `dashes` | 破線 |

すべて StudioRaming が直接製作したオリジナル アセットです。
→ [サードパーティ表記](/legal/third-party-credits)

## 保存

| モード | 保存形式 |
|---|---|
| マスク | **リニア**(sRGB オフ) |
| カラー | **sRGB** |

→ [sRGB とインポート設定](/concepts/srgb-and-import-settings)

## 自動保存復元

プレビュー中止・リコンパイル・プレイモード切り替え・シーン切り替えで保存されていないキャンバスは**自動的に一時保存**されます。

次の**Load**時に復元するかどうかを尋ねます — **復元 / 破棄 / キャンセル**。

| 項目 | 値 |
|---|---|
| 保存場所 | `<プロジェクト>/Library/MaskMakerAutoSave/` |
| 削除される時点 | 実際の保存に成功するとテンポラリ ファイルが削除されます |

→ [設定とプリセット](/reference/settings-and-presets)

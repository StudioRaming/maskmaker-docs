# レイヤースタックと最終ベイク

**このページを読むと** タブを移動して作成した結果がどのように 1 つのメッシュ上に重ねて表示されるのか、そしてそれすべてを 1 枚に焼き込む**最終ベイク**が分かります。

## ウィンドウ上部の 2 行は固定です

タブバーのすぐ下に**ターゲット行**（Target · **Load** · **更新** · **Preview**）があり、そのすぐ下に**レイヤー行**があります。どちらの行もスクロール外にあるため、どのタブを見ていても常に同じ場所に留まります。

<!-- SCREENSHOT: タブバー → ターゲット行 → レイヤーチップ行の順序で固定された上部領域 -->

## Load するとすぐにプレビューが開始されます

任意のタブで **Load** をクリックすると、その場所でプレビューが開始されます。

そして**タブを変更しても前のタブのプレビューは消えません。** 各タブの結果は（レンダラー・マテリアルスロット）ごとに 1 つ存在する**レイヤースタック**に積み重ねられ、シーンビューにはそのスタックが合成された結果が表示されます。MatCap グロスをキャッチしておき、ブリッジで束を選択し、ペイントで上塗りすれば、3 つの結果が同じメッシュ上に一緒に表示されます。

**Preview** / **Stop** ボタンは現在、そのタブのレイヤーを**表示 / 非表示**にします。レイヤー自体は残っているため、再度 **Preview** をクリックするとそのまま戻ります。

## レイヤー行

レイヤーごとに 1 行（チップ）が表示されます。

| チップ | どのタブから上がるか |
|---|---|
| マットキャップ光沢 | [MatCap グロス](/tabs/matcap-gloss) — グロスモード |
| キャビティ/AO | [MatCap グロス](/tabs/matcap-gloss) — AO(キャビティ)モード |
| ブリッジ | [ブリッジマスク](/tabs/bridge-mask) — ランダム束・手動選択共通 |
| ペイントマスク | [ペイント](/tabs/paint) — マスクモード |
| グラデーション | [グラデーション](/tabs/gradient) |
| ペイントカラー | [ペイント](/tabs/paint) — カラーモード |

| 項目 | 機能 |
|---|---|
| チェックボックス | このレイヤーをシーンプレビューと最終ベイクに含めるか否か |
| ブレンド | 下のレイヤーと合成する方式 — `Max` · `Add` · `Multiply` · `Subtract` · `Replace` |
| 不透明度 | 0 ~ 100 |

デフォルトブレンドはマスク系レイヤーが `Max`、グラデーションが `Multiply`、ペイントカラーが `Replace` です。

合成順序はレイヤーが上がった順ではなく、**上の表の順序で固定**されます — タブをどの順序で有効化しても結果は同じです。

ターゲット行の右側の**プレビュー色**は、合成されたマスクをシーンでどのような色で覆って表示するかのみを決定します。**保存結果には影響しません。**

:::note[スロット分割プレビューはスタックに入りません]
[スロット分割](/tabs/slot-split)はマスクではなくメッシュを編集するタブなため、スロット色プレビューはレイヤーの上に別途覆われて表示されます。
:::

## 最終ベイク

レイヤー行の下の**最終ベイク**ボタンは、**チェックされたレイヤーをすべて合成して 1 枚に保存**します。

| 保存されるもの | ファイル名 |
|---|---|
| 合成マスク | `<メッシュ>_<マテリアル>_Final.png` |
| カラー（グラデーション・ペイントカラーレイヤーがある場合のみ） | `<メッシュ>_<マテリアル>_FinalColor.png` |

- 保存先は、ボタンの上の**保存先**ラベルに事前に表示されます（ベースマップがあるフォルダ → ないならマテリアルフォルダ → それもなければ `Assets`）。
- 同じ名前のファイルがあれば、上書き / 新しい名前 / キャンセルを尋ねます。
- **シーンビューに見えるそのままが焼き込まれます。** プレビューと最終ベイクが同じ合成式を使うからです。

各タブにある**Bake**は変わらず、**そのレイヤー 1 枚だけ**を焼き込みます。結果 1 つだけが別途必要な場合に使用してください。

## ターゲットが複数の場合

レイヤースタックは（レンダラー・マテリアルスロット）単位です。スタックが 2 つ以上ある場合、レイヤー行の左側に**ターゲットポップアップ**が表示されます。表示と最終ベイクはそこで選択したターゲットに適用されます。

→ [マテリアルスロットピッカー](/getting-started/first-mask#머티리얼-슬롯-피커)

## プレビュー中のシーンクリック

プレビューが有効な間、シーンビューの**通常の左クリックは別のオブジェクトを選択しません。** 作業中のメッシュ横をクリックしてターゲットが変わることを防ぐためです。`Alt` + ドラッグのシーン回転と `Ctrl` クリック/ドラッグの意味は変わりません。

→ [ショートカット](/reference/hotkeys)

## プレビューマテリアルがシーンに残った場合

エディターが強制終了するなどでプレビュー解除が実行されなかった場合、メッシュにプレビュー マテリアルが残り、白く見える可能性があります。

- ウィンドウを再度開くと**自動的に復旧**されます。
- ウィンドウを開かずに戻すには、メニュー**StudioRaming → Mask Maker → Recover Preview Materials** を実行してください。

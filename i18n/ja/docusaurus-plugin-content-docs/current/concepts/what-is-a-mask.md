# マスクテクスチャとは

**このページを読むと** シェーダーがマスクをどう読むか、なぜ白黒なのか、なぜ sRGB をオフにするのかが分かります。ツールの中では、ヘッダーの **?** ボタンから同じ内容を見られます。

## 色ではなく数値を保存する画像

マスクテクスチャは、**色を保存する画像ではなく、数値を保存する画像**です。シェーダーはこの画像の明るさ（0～1）をピクセルごとに読み、**その部分に効果をどれだけかけるか** を決めます。

| マスクの値 | 意味 |
|---|---|
| 黒（0） | 適用しない。元のまま |
| グレー（0.5） | 半分適用 |
| 白（1） | 完全に適用 |

<!-- SCREENSHOT: 黒・グレー・白の 3 マスと、それぞれの結果の比較 -->

そのため、マスクに「きれいな色」は必要ありません。必要なのは **どこがどれだけ明るいか** だけです。

## 1 枚のテクスチャに 4 つのマスク

テクスチャには **R / G / B / A の 4 チャンネル** があり、マスクは通常そのうちの **1 チャンネルだけ** を使います。グレースケールの画像は R=G=B なので、どのチャンネルを読んでも値は同じです。

4 つのマスクをそれぞれ R、G、B、A に入れると、1 枚のファイルに **4 つのマスク** が入ります。この作業を行うのが [マスクコンバイナー](/tabs/combiner) です。
→ [チャンネルとパッキング](/concepts/channels-and-packing)

## 保存するときに必ず確認すること

:::danger[sRGB (Color Texture) は必ずオフにしてください]
マスクは色ではなく数値です。sRGB がオンだと、Unity がガンマ補正をかけ、**数値が変わってしまいます。** 0.5 で焼いたグレーが、シェーダーでは 0.5 として読まれません。

テクスチャを選択 → Inspector で **sRGB (Color Texture) をオフ** → **Apply**。
:::

Mask Maker は **マスク出力** のときに、白黒マスクを sRGB をオフにした状態でインポートします。外部から持ってきたマスクを使うときだけ、自分で確認すれば十分です。
→ [sRGB とインポート設定](/concepts/srgb-and-import-settings)

## 解像度

解像度は出力設定の **テクスチャサイズ (Texture Size)** で選びます。マスクは形の境界だけが重要です。境界が階段状に見える場合は、解像度を上げる前に **アウトライン（px）** の値を確認してください。
→ [トラブルシューティング](/troubleshooting)

## どの方法でどのマスクを作るか

| 方法 | 作るもの | 主な用途 |
|---|---|---|
| [描く](/tabs/paint) | ブラシで描いた白黒マスク | 自動では作れない任意の形 |
| [画像](/tabs/image) | 選んだ Texture2D | 外部で作った画像の再利用 |
| [グラデーション](/tabs/gradient) | 方向や高さに応じて値が変わる白黒マスク | 位置に基づく効果 |
| [ブリッジ](/tabs/bridge-mask) | 選んだ髪の房の白黒マスク | 髪の一部だけに効果 |
| [マットキャップ光沢](/tabs/matcap-gloss) | マットキャップのハイライトを焼いた白黒マスク | 光沢とハイライト |
| [マスクコンバイナー](/tabs/combiner)（詳細作業のツール） | 複数のマスクを R/G/B/A の 1 枚にまとめたもの | ファイル数を減らす |

## シェーダーはどこからマスクを読むか

シェーダーごとに、マスクを受け取るスロット（プロパティ）が違います。同じ「光沢マスク」でも、lilToon は `MatCap ▸ Mask`、NiloToon は `MatCap Additive ▸ Mask Map` から読みます。

→ [lilToon](/shaders/liltoon) · [Poiyomi](/shaders/poiyomi) · [MingToon](/shaders/mingtoon) · [NiloToon](/shaders/nilotoon)

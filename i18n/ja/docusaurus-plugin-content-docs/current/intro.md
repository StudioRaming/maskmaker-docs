# Mask Maker

**アバタースキンのマスクテクスチャを Unity の内部で完成させるエディタツールです。**

マスクはシェーダーのほぼすべての機能が必要とする入力です — どの部位に光沢を入れるのか、どこを別の色で上塗りするのか、アウトラインをどこで薄くするのか。しかしそれを作るには、通常 Unity を終了して外部のペイントツールで UV を展開し、再度インポートして、インポート設定を修正し、マテリアルスロットに挿入して確認し、間違っていたら最初から繰り返す必要があります。

Mask Maker はその往復を排除します。シーンビューで見ながら作成し、その場で焼き込みます。作成したマスクをシェーダースロットに挿入することもできますが、それは選択肢であり、**このツールの本体はマスク作成です**。

メニュー **StudioRaming → Mask Maker** で開きます。

## 何が含まれているか

**6 つのタブが、それぞれ異なる方法で同じ成果物（マスクテクスチャ）を作成します。** マスクによっては計算で作成するのが正確で、マスクによっては手で描くのが高速です。そのため、方法を 1 つに強要しません。

| タブ | 作成するもの | 主な用途 |
|---|---|---|
| [MatCap グロス](/tabs/matcap-gloss) | マットキャップハイライト（グロスモード）またはメッシュの凹部分（AO/キャビティモード）の白黒マスク | グロス・スペキュラー・リムマスク、金属部位の指定、AO |
| [グラデーション](/tabs/gradient) | ワールド方向グラデーションカラーテクスチャ | 高さベース色のティント（オンブレ染色） |
| [ブリッジマスク](/tabs/bridge-mask) | ランダムに選択した束、またはクリックした束だけが白いマスク | ブリッジ（ハイライト）染色レイヤー、特定部位の分離 |
| [スロット分割](/tabs/slot-split) | マスクではなく**メッシュそのもの**を異なるマテリアルスロットに分離 | 完全に異なるシェーダーを適用する部位の分離 |
| [コンバイナー](/tabs/combiner) | 複数のマスクを R/G/B/A 1 枚に合成 · 分離 | テクスチャ数の削減、自動最適化 |
| [ペイント](/tabs/paint) | シーンビューメッシュ上にブラシで直接描画したマスク/カラー | 自動生成ができない任意の形状すべて |

## 他のマスクツールとの違い

**タブ結果が 1 つのメッシュ上に重ねられます。**
タブごとに別々に焼き込み、後で合成する方式ではありません。どのタブでも **Load** をクリックするとすぐにプレビューが有効になり、タブを切り替えても前のタブの結果がシーンに残って重なって表示されます。上部の**最終ベイク**はその重なった画面を**見えるまま** 1 枚のマスクとして保存します。
→ [レイヤースタックと最終ベイク](/concepts/layer-stack)

**挿入するのを手伝いますが、強制しません。**
マスク作成がこのツールの本体で、シェーダースロットへの接続機能は**選択補助**です。ブリッジマスクの**ベイク後にマテリアルへ自動割り当て**はデフォルトで無効になっており、コンバイナーの**合成 + 再割り当て**は実行前に常にプランを表示し、どちらも `Ctrl+Z` 1 回で戻します。
→ [コンバイナー](/tabs/combiner)

**シーンビューが作業画面です。**
リストから選ぶ方式ではありません。束にマウスを重ねるとシアン/赤でプレビューが表示され、Ctrl+クリックで追加・削除します。ドラッグするとペイントのように通過した束が切り替わり、ボックスでも選択できます。内側・裏面の束は裏面モードでカメラを回さずに拾えます。
→ [ショートカット](/reference/hotkeys)

**Undo がすべての領域で動作します。**
シーンビューの束選択、スロット分割の適用、ペイントストロークすべてが `Ctrl+Z` / `Ctrl+Y` で戻ります。

**原本を触りません。**
プレビューはマテリアルを複製して表示し、**Stop** すれば即座に復元されます。ウィンドウをそのまま閉じても復元されます。エディターが強制終了するなどで復元が実行されなかった場合でも、ウィンドウを再度開くと自動的に戻り、メニュー**StudioRaming → Mask Maker → Recover Preview Materials** でも戻せます。保存時に同じ名前のファイルがあれば上書き/新しい名前/キャンセルを尋ねます。

**4 つのシェーダーの接続ポイントを把握しています。**
lilToon · Poiyomi · MingToon · NiloToon のマスクプロパティとインスペクターパスが、ツール内のテーブルに含まれており、コンバイナーはシェーダーごとのプロファイルでスキャンします。リストにないシェーダーは JSON プロファイルで直接追加します。
→ [シェーダー接続](/shaders/liltoon)

**ガイドはツール内に含まれています。**
各タブ上部の**ガイド**コラプスパネルとヘッダーの**?** ボタンが、このドキュメントと同じ内容を含んでいます。このサイトはそれを検索・リンク可能な形式に転換したものです。

## 対応環境

| 項目 | 値 |
|---|---|
| Unity | 2019.4 LTS ~ 2022.3 |
| レンダーパイプライン | Built-in RP · URP |
| 言語 | 日本語 · English · 한국어 (ウィンドウ右上で切り替え) |
| インストール場所 | `Assets/StudioRaming/MaskMaker` 単一フォルダ |

シェーダー接続表は lilToon · Poiyomi 9.x · MingToon · NiloToon を対象としています。その他のシェーダーでもマスクを作成して挿入できますが、自動割り当ては対応していません。

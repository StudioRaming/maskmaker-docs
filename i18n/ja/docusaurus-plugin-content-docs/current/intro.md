# Mask Maker

**アバターのテクスチャマスクを Unity の中で作るエディターツールです。** 2.0 から作業画面は **かんたん開始** と **詳細作業** の 2 つのモードに分かれます。

マスクは、多くのシェーダー機能が入力として使う白黒の画像です。どの部分に光沢を入れるか、どこを別の色で塗り重ねるか、アウトラインをどこで細くするかを決めます。Mask Maker では、シーンビューでモデルの上に直接描いたり、方法を選んでマスクを作ったりして、その場で出力できます。

メニュー **StudioRaming → Mask Maker** で開きます。

## 含まれているもの

マスクを作る方法は 5 つあります。1 つだけ使うことも、複数の方法を組み合わせることもできます。

| 方法 | 作るもの | 主な用途 |
|---|---|---|
| [描く](/tabs/paint) | シーンビューのメッシュ上でブラシを使って描いたマスク | 自動では作りにくい任意の形 |
| [画像](/tabs/image) | 選んだ Texture2D をマスクの内容として使う | 外部で作った画像の再利用 |
| [グラデーション](/tabs/gradient) | 方向や高さに応じて値が変わる白黒マスク | 位置によって変わる効果 |
| [ブリッジ](/tabs/bridge-mask) | 選んだ髪の房から作った白黒マスク | 髪の一部だけに効果を入れる |
| [マットキャップ光沢](/tabs/matcap-gloss) | マットキャップのハイライトを焼き込んだ白黒マスク | 光沢やハイライトの位置 |

カラー調整（カラー調整レイヤー、カーブ、グラデーションマップ、アーティスティック調整）は、Mask Maker ではもう作れません。カラー調整は MingPainter で行います。

## 方法を組み合わせる

内容のあるマスクに方法を追加すると、標準で **範囲を絞る** を使います。たとえば、ブリッジで選んだ房の中だけにグラデーションやマットキャップ光沢を残せます。**白い範囲を追加** と **これだけ使う** も選べます。
→ [レイヤーとマスク出力](/concepts/layer-stack)

## 作業の進め方

- **作業の中心はシーンビューです。** 基本の操作はシーンビューで行います。
- **複数のマスクを行き来できます。** 1 つのマテリアルのマスクを切り替えて編集しても、それぞれの絵とレイヤーが残ります。
- **出力は 1 か所で行います。** **保存・適用 → マスク出力** で、出力サイズと UV の境界のにじみを決めて保存します。編集できるレイヤードキュメントも一緒に保存されます。
- **表示を切り替えられます。** **マスクのみ · 適用結果 · 元の表示** でプレビューを変えられます。

## 対応環境

| 項目 | 値 |
|---|---|
| Unity | 2019.4 ～ Unity 6（6000.0、6000.3 LTS） |
| レンダーパイプライン | Built-in RP · URP |
| 言語 | 한국어 · English · 日本語（ウィンドウ右上で切り替え） |
| インストール先 | `Assets/StudioRaming/MaskMaker` の 1 フォルダー |

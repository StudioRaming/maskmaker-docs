# インストール

**このページを読むと** Mask Maker をプロジェクトに導入し、ウィンドウを開き、正常にインストールされたことを確認する方法が分かります。

## 手順

1. 受け取った `.unitypackage` をプロジェクトにインポートします（`Assets` メニュー → `Import Package` → `Custom Package…`、またはファイルをプロジェクトウィンドウにドラッグ・ドロップ）。
2. インポートリストそのままで **Import** をクリックします。`Assets/StudioRaming/MaskMaker` **単一フォルダのみ** がインストールされます。
3. コンパイルが終了したら、メニュー **StudioRaming → Mask Maker** でウィンドウを開きます。

<!-- SCREENSHOT: Unity メニューバー StudioRaming → Mask Maker -->

:::tip[インポートリストから項目を除外しないでください]
Mask Maker は Editor スクリプトと組み込みステンシル画像が相互に参照します。一部のみをインポートするとコンパイルエラーが発生します。すべて導入し、不要な場合はフォルダ全体を削除してください。
:::

## インストール確認

| 確認項目 | 正常状態 |
|---|---|
| フォルダ | `Assets/StudioRaming/MaskMaker/Editor` が存在 |
| メニュー | **StudioRaming → Mask Maker** アイテムが表示 |
| コンソール | Mask Maker 関連のコンパイルエラーなし |
| ウィンドウヘッダー | 右上に言語選択（日本語/English/한국어）と **?** ボタンが表示 |

<!-- SCREENSHOT: ウィンドウヘッダー — 言語ドロップダウンと ? ボタン -->

## 対応環境

| 項目 | 値 |
|---|---|
| Unity | 2019.4 LTS ~ 2022.3 |
| レンダーパイプライン | Built-in RP · URP |
| プラットフォーム | エディター専用（ビルドに何も含まれません） |

Mask Maker は **Editor 専用ツール** です。作成されたテクスチャとメッシュアセットのみがプロジェクトに残り、ツール自体はビルドに含まれません。作業が完了した後、フォルダを削除しても、既に焼き込まれた成果物は引き続き機能します。

## 言語の変更

ウィンドウ右上のドロップダウンから 日本語 / English / 한국어 を選択します。選択はエディターに保存され、次回の起動時にも保持されます。ツールチップ・ガイド・ヘルプがすべて一緒に切り替わります。

## アップデート

新バージョンは同じ方法でインポートして上書きします。ユーザーが作成した次の 2 つのデータは `Assets` 外に位置するため、アップデートで削除されません。

| データ | 位置 |
|---|---|
| ユーザーシェーダープロファイル | `<プロジェクト>/MaskMakerProfiles/*.json` |
| ペイント自動保存キャンバス | `<プロジェクト>/Library/MaskMakerAutoSave/` |

→ [設定とプリセット](/reference/settings-and-presets)

## 削除

`Assets/StudioRaming/MaskMaker` フォルダを削除すれば完了です。焼き込まれたテクスチャ・メッシュはプロジェクトの他の場所に保存されているため、一緒に削除されません。

# インストール

**このページを読むと** Mask Maker 2.0 をプロジェクトに入れ、ウィンドウを開き、正しく入ったかを確認する方法が分かります。

## 手順

1. 受け取った `MaskMaker_v2.0.0.unitypackage` をプロジェクトにインポートします（`Assets` メニュー → `Import Package` → `Custom Package…`、またはファイルをプロジェクトウィンドウにドラッグします）。
2. インポートの一覧を確認して **Import** を押します。インストールされるのは `Assets/StudioRaming/MaskMaker` の **1 フォルダーだけ** です。
3. コンパイルが終わったら、メニュー **StudioRaming → Mask Maker** でウィンドウを開きます。


<!-- SCREENSHOT: Unity のメニューバー StudioRaming → Mask Maker -->

:::tip[インポートの一覧から項目を外さないでください]
Mask Maker の Editor スクリプトと内部のリソースは互いに参照しています。一部だけインポートするとコンパイルエラーになることがあります。すべて入れて、不要になったらフォルダーごと削除してください。
:::

## インストールの確認

| 確認すること | 正常な状態 |
|---|---|
| フォルダー | `Assets/StudioRaming/MaskMaker/Editor` がある |
| メニュー | **StudioRaming → Mask Maker** が表示される |
| コンソール | Mask Maker に関するコンパイルエラーがない |
| ウィンドウのヘッダー | 右上に **ガイド** ボタンと言語選択（한국어 / English / 日本語）がある。**?** ボタンは作業バーの末尾にある |

<!-- SCREENSHOT: ウィンドウのヘッダー — 言語ドロップダウンと ? ボタン -->

## 対応環境

| 項目 | 値 |
|---|---|
| Unity | 2019.4 ～ Unity 6（6000.0、6000.3 LTS） |
| レンダーパイプライン | Built-in RP · URP |
| プラットフォーム | Editor 専用（ビルドには何も含まれません） |

Mask Maker は **Editor 専用のツール** です。作成されたテクスチャとメッシュのアセットだけがプロジェクトに残り、ツール自体はビルドに入りません。作業が終わったあとにフォルダーを削除しても、出力済みの結果はそのまま動作します。


## 言語の変更

ウィンドウ右上のドロップダウンで 한국어 / English / 日本語 を選びます。選択はエディターに保存され、次に開いたときも維持されます。他の StudioRaming ツールと言語設定を共有します。

## 1.x からの更新 {#update-from-1x}



1. 作業中のプロジェクトをバックアップします。
2. 新しい `.unitypackage` を既存の `Assets/StudioRaming/MaskMaker` フォルダーの上に、そのままインポートします。
3. コンパイルが終わったらウィンドウを開き、既存の作業が表示されるか確認します。

**1.x をお持ちの方は 2.0 に無料でアップデートできます。** 1.x で保存したマスクはそのまま動作し、1.x のファイルや設定もそのまま残ります。

既存のフォルダーの上に重ねてインポートすると、同じ場所のファイルが 2.0 のファイルに置き換わります。古いファイルを先に削除する必要はありません。ただし、Mask Maker をソース（`.cs`）版として入れていたプロジェクトでは、先にソース版を削除してください。DLL 版と一緒に置くと同じクラスが二重に定義され、コンパイルエラーになります。

**編集ドキュメントの変換:** 2.0 はレイヤー編集ドキュメントを新しい形式で保存します。以前の形式のドキュメントは、初めて保存（上書き）するときに元のファイルが `Library/StudioRaming/MaskMaker/DocumentBackups/` にバックアップされます。2.0 形式で保存したドキュメントは 1.x では開けません。

## データの保存場所

| データ | 場所 | 更新したあと |
|---|---|---|
| ユーザーのシェーダープロファイル（詳細作業のマスクコンバイナー） | `<プロジェクト>/MaskMakerProfiles/*.json` | 残る |
| 復旧データとドキュメントのバックアップ | `<プロジェクト>/Library/StudioRaming/MaskMaker/` | 残る（キャッシュフォルダーです） |

→ [設定とプリセット](/reference/settings-and-presets)

## 削除

`Assets/StudioRaming/MaskMaker` フォルダーを削除すれば完了です。出力済みのテクスチャはプロジェクトの別の場所に保存されているため、一緒に消えることはありません。

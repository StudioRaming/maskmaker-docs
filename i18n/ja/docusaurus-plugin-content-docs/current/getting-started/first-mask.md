# 最初のマスクを作成する

**このページを読むと** Load からシェーダースロットまで一度に通過する全体フローが分かります。どのタブを使っても、この 5 つのステップは同じです。

## 全体フロー

**オブジェクト選択 → Load → マテリアルスロット選択 → Preview → シーンビューで調整 → Bake → シェーダーに挿入**

<!-- SCREENSHOT: 上部ターゲットリスト + Load / Preview ボタン -->

## 1. オブジェクトを選択して Load

Hierarchy で作業対象のオブジェクト（通常はヘアまたはボディ）を選択し、ウィンドウの **Load** をクリックします。複数を一度に選択しても構いません。

Load 後に Hierarchy 選択が変わると、シーンビューに**「選択が変更されました — 再ロード」**ヒントが表示されます。プレビュー中でなければ自動的に再ロードされます。

## 2. マテリアルスロットを選択 {#머티리얼-슬롯-피커}

メッシュにマテリアルスロットが複数ある場合、ターゲットリスト下に**スロットごとのベースマップサムネイル**が表示されます。**作業対象のスロットを 1 つ選択する必要があり**、そのサブメッシュのみが焼き込み・ペイント・プレビューされます。

<!-- SCREENSHOT: マテリアルスロットピッカーサムネイルストリップ、1 つのスロットが選択された状態 -->

| 項目 | 動作 |
|---|---|
| 表示されるタブ | MatCap グロス/AO · グラデーション · ブリッジマスク · ペイント |
| 出力ファイル名 | `<メッシュ>_<マテリアル>` |
| サブメッシュよりスロットが多い場合 | 残るスロット（lilToon/Poiyomi のアウトラインスロットなど）は**最後のサブメッシュ**にマッピングされます |

:::note[スロットが 1 つの場合、このステップは表示されません]
ピッカーはスロットが 2 つ以上の場合にのみ表示されます。スロットが 1 つの場合、そのスロットが自動的にターゲットになります。
:::

## 3. Preview

**Preview** をオンにするとシーンビューのメッシュに結果がリアルタイムで適用されます。

- プレビューは**原本マテリアルに影響しません。** 複製本を一時的に被せ、**Stop** すれば即座に復元されます。
- ウィンドウをそのまま閉じても復元されます。リコンパイル・プレイモード切り替えでも復元されます。
- プレビューがオフの場合、シーンビューハンドル（球・グラデーション開始/終了点）は暗く表示され、編集できません。

## 4. シーンビューで調整

タブに応じてハンドルをドラッグするか、束をクリックするか、ブラシで描きます。クリック選択タブ（ブリッジマスク・スロット分割）はすべて同じルールを使用します。

| 操作 | 結果 |
|---|---|
| `Ctrl` + クリック | 束の追加 / 削除 |
| `Ctrl` + ドラッグ | 通過した束をペイントのように切り替え |
| `Ctrl+Shift` + ドラッグ | ボックスで追加選択 |
| `Ctrl+Shift+Alt` + ドラッグ | ボックスで選択解除 |
| クリックのみ | 通常通りシーンオブジェクトを選択 |
| `Ctrl+Z` / `Ctrl+Y` | 元に戻す / やり直す |

全リストについては → [ショートカット](/reference/hotkeys)

## 5. Bake

**Bake** をクリックすると、元のテクスチャフォルダに保存されます。

- 同じ名前のファイルがある場合は**上書き / 新しい名前 / キャンセル**を尋ねます。誤った上書きは防止されます。
- 保存されたファイルはタブ下部の**最近のベイク**リストからピング（検索）またはフォルダを開くで即座に確認できます。

<!-- SCREENSHOT: 最近のベイクリスト — サムネイル + ピング/フォルダを開くボタン -->

## 6. シェーダーに挿入

焼き込みと挿入は別の作業です。4 ステップで完了します。

1. 別のタブでマスクを**焼き込みます**。
2. 保存されたテクスチャを選択 → Inspector で **sRGB (Color Texture) をオフ** → **Apply**。
3. マテリアル Inspector を開き、該当する**プロパティ**スロットにテクスチャをドラッグして挿入します。
4. そのスロットに**チャンネル選択**（R/G/B/A）がある場合、マスクを焼き込む際に使用したチャンネルと一致させます。コンバイナーで合成したマスク以外の場合、通常は **R** です。

シェーダーごとのスロット名と Inspector パスについては → [lilToon](/shaders/liltoon) · [Poiyomi](/shaders/poiyomi) · [MingToon](/shaders/mingtoon) · [NiloToon](/shaders/nilotoon)

:::tip[3～4 ステップをスキップする方法]
ブリッジマスクタブで**ベイク後に自動割り当て**をオンにしておけば、保存と同時に NiloToon スタッキングレイヤースロットに即座に挿入されます。コンバイナーの**パック + 再割り当て**もテクスチャ・チャンネル・有効化切り替え・キーワードまで直接書き込みます。
:::

## どのタブから始めるか分からない場合

| 実現したいこと | タブ |
|---|---|
| ヘアに光沢を入れる場所を指定 | [MatCap グロス](/tabs/matcap-gloss) |
| 凹んだ部分だけを暗くする（AO） | [MatCap グロス](/tabs/matcap-gloss) — AO/キャビティモード |
| 根→先で色が変わる染色 | [グラデーション](/tabs/gradient) |
| ヘアの数本だけ別の色 | [ブリッジマスク](/tabs/bridge-mask) |
| 特定部位だけ別のシェーダーにする | [スロット分割](/tabs/slot-split) |
| テクスチャ数が多すぎる | [コンバイナー](/tabs/combiner) |
| その他の任意の形状すべて | [ペイント](/tabs/paint) |

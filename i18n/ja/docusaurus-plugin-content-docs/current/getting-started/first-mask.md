# 最初のマスクを作る

**このページを読むと** モデルを選び、マスクを作り、出力してシェーダーに接続するまでの流れが分かります。

## 4 つの手順

1. Hierarchy でモデルを選び、**現在の選択を使う** を押します。
2. 右側のパネルで、マテリアルと編集するマスクを選びます。名前やシェーダーのプロパティで検索できます。
3. **描く** を押し、シーンビューのモデルの上に描きます。**画像 · グラデーション · ブリッジ · マットキャップ光沢** でも作れます。
4. **適用結果** で確認してから、**保存・適用** からマスクを出力します。

白は値 1、黒は値 0 です。それぞれの値の効果は、接続したシェーダー機能によって変わります。

## 画面の構成

| 領域 | 内容 |
|---|---|
| ワイドウィンドウ | 左にキャンバスとツール、右にマテリアル選択、レイヤー一覧、開いているマスク |
| 狭いウィンドウ | マテリアル選択、開いているマスク、キャンバスの順に上から並ぶ |
| 開いているマスク | 作業するマスクを切り替え、マテリアルのグループを展開して別のマスクを開く |
| 空のスロットも表示 | 標準でオンなので、オフの効果や空のマスクも見つけやすい |
| かんたん開始 | 選んだマスクの効果の設定とシーンビューでの作業に集中する |
| 詳細作業 | レイヤー、メッシュ、出力、ツールを細かく調整する |
| 最近の作業 | 保存したファイルを Project ウィンドウで探すか、フォルダーを開く |

モードを切り替えても、作業は残ります。

## 表示を変える

**マスクのみ · 適用結果 · 元の表示** のいずれかを選びます。

- **マスクのみ** と **適用結果** は、シーン編集を開始します。
- **元の表示** は、シーン編集を終了します。元の表示でもマスクの作業は保持されます。
- **適用結果** でマスクを明示的に開くと、オフになっていた関連する効果がオンになり、適用結果が表示されます。一覧を見たり検索したりするだけでは効果は変わりません。
- まだ何も描いていないマスクのプレビューは黒く表示され（黒は 0）、「まだ描かれていません。」という案内が 1 行付きます。

## 複数のマスクを編集する

1 つのマテリアルのマスクを行き来して、それぞれに描けます。影のマスクを描いてから輪郭のマスクを編集して戻っても、各マスクの絵とレイヤーはそのまま残ります。R/G/B/A のチャンネルを使うマスクは、チャンネルごとに作業を分けて保持します。インスペクターでチャンネルを変えると、作業も新しいチャンネルへ一緒に移ります。→ [チャンネルとパッキング](/concepts/channels-and-packing#channel-change)

## 出力してシェーダーに接続する

1. **保存・適用 → マスク出力** を開きます。
2. 出力サイズと **アウトライン（px）** を決めます。
3. 保存します。白黒マスクは sRGB をオフにした状態でインポートされます。マテリアルが lilToon、Poiyomi、MingToon、NiloToon のいずれかなら、選んだマテリアルのプロパティに接続されます。ほかのシェーダーは PNG で保存されるので、自分で挿入してください。

標準のファイル名は、マテリアル、マスクのプロパティ、選んだチャンネルを区別します。同じ名前のファイルを上書きする前に、保存先を確認してください。編集できるレイヤードキュメントも出力ファイルと一緒に保存されます。

シェーダーごとのスロット名とインスペクターのパスは → [lilToon](/shaders/liltoon) · [Poiyomi](/shaders/poiyomi) · [MingToon](/shaders/mingtoon) · [NiloToon](/shaders/nilotoon)

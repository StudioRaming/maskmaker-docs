# 最初のマスクを作成する

**このページを読むと** Load からシェーダースロットまで一度に通過する全体フローが分かります。どのタブを使っても、この 5 つのステップは同じです。

## 全体フロー

**オブジェクト選択 → Load（プレビュー自動開始） → マテリアルスロット選択 → シーンビューで調整 → Bake または最終ベイク → シェーダーに挿入**

<!-- SCREENSHOT: タブバー下に固定された対象の行 + レイヤーの行 -->

## 0. ウィンドウ構成

スクロール外の上部 4 行はすべてのタブで同じ場所に固定されています。

| 行 | 内容 |
|---|---|
| ヘッダー | 右側に**Docs**（現在のタブのオンライン説明書） · **?**（内蔵ヘルプ） · 言語 · バージョン（**v0.1.1**、クリックするとそのバージョンのパッチノート） |
| アクションバー | **Load** · **Preview** · **編集メッシュのみ** · **Undo** · **Redo** · **最終ベイク** · **保存** · **名前を付けて** |
| タブ | 6 つのタブ |
| 対象の行・レイヤーの行 | 現在何がロードされているか + このスロットに積み重ねられたレイヤー |

ウィンドウが狭い場合、アクションバーは 2 行に折りたたまれ、現在のタブにない操作のボタンはグレーアウトされます。

**対象の行**は現在の状態を示す表示欄です — `Target: N個のメッシュをロード済み` / `Target: N個選択中（Loadを押してください）` / `Target: （選択なし）`。スロット分割タブには**更新**ボタンも一緒に表示され、Hierarchy 選択に関係なく現在ロードされているメッシュだけを再読み込みします。

<!-- SCREENSHOT: ヘッダー → アクションバー → タブ → 対象の行 → レイヤーチップ行の順序で固定された上部領域 -->

## 1. オブジェクトを選択して Load

Hierarchy で作業対象のオブジェクト（通常はヘアまたはボディ）を選択し、**Load** をクリックします。複数を一度に選択しても構いません。**Load するとプレビューがすぐに開始されます** — 別途 **Preview** をクリックする必要はありません。**編集メッシュのみ**をオンにすると、シーンビューにロード対象だけが残り、遮るものなく作業できます（非破壊、オフにすると元に戻ります）。

Load 後に Hierarchy 選択が変わると、シーンビューに**「選択が変更されました — 再ロード」**ヒントが表示されます。プレビュー中でなければ自動的に再ロードされます。**更新**は Hierarchy 選択と無関係に、現在ロードされているメッシュのみを再度読み込みします。

## 2. マテリアルスロットを選択 {#머티리얼-슬롯-피커}

メッシュにマテリアルスロットが複数ある場合、ターゲットリスト下に**スロットごとのベースマップサムネイル**が表示されます。**作業対象のスロットを 1 つ選択する必要があり**、そのサブメッシュのみが焼き込み・ペイント・プレビューされます。

<!-- SCREENSHOT: マテリアルスロットピッカーサムネイルストリップ、1 つのスロットが選択された状態 -->

| 項目 | 動作 |
|---|---|
| 表示されるタブ | MatCap グロス/AO · グラデーション · ブリッジ+領域マスク · ペイント |
| 出力ファイル名 | `<メッシュ>_<マテリアル>` |
| サブメッシュよりスロットが多い場合 | 残るスロット（lilToon/Poiyomi のアウトラインスロットなど）は**最後のサブメッシュ**にマッピングされます |

:::note[スロットが 1 つの場合、このステップは表示されません]
ピッカーはスロットが 2 つ以上の場合にのみ表示されます。スロットが 1 つの場合、そのスロットが自動的にターゲットになります。
:::

## 3. プレビューとレイヤーの行

結果がシーンビューのメッシュにリアルタイムで適用されます。対象の行のすぐ下の**レイヤーの行**にこのタブの結果が 1 行（チップ）として表示されます。

- **タブを切り替えても前のタブの結果はシーンに残って重なって表示されます。** 各タブの結果が（レンダラー・マテリアルスロット）ごとに 1 つ存在するレイヤースタックに積み重ねられるからです。
- **Preview** / **Stop** は現在、そのタブのレイヤーを**表示 / 非表示**にします。レイヤーは残っているため、再度有効にするとそのまま戻ります。
- プレビューは**原本マテリアルに影響しません。** 複製本を一時的に被せ、**Stop** すれば即座に復元されます。
- ウィンドウをそのまま閉じても復元されます。リコンパイル・プレイモード切り替えでも復元されます。
- プレビューがオフの場合、シーンビューハンドル（球・グラデーション開始/終了点）は暗く表示され、編集できません。

→ [レイヤースタックと最終ベイク](/concepts/layer-stack)

## 4. シーンビューで調整

タブに応じてハンドルをドラッグするか、束をクリックするか、ブラシで描きます。クリック選択タブ（ブリッジ+領域マスク・スロット分割）はすべて同じルールを使用します。

| 操作 | 結果 |
|---|---|
| `Ctrl` + クリック | 束の追加 / 削除 |
| `Ctrl` + ドラッグ | 通過した束をペイントのように切り替え |
| `Ctrl+Shift` + ドラッグ | ボックスで追加選択 |
| `Ctrl+Shift+Alt` + ドラッグ | ボックスで選択解除 |
| クリックのみ | プレビュー中は**別のオブジェクトが選択されません** (`Alt` + ドラッグのシーン回転はそのまま) |
| `Ctrl+Z` / `Ctrl+Y` | 元に戻す / やり直す |

全リストについては → [ショートカット](/reference/hotkeys)

## 5. Bake または最終ベイク

| ボタン | 焼き込むもの | ファイル名 |
|---|---|---|
| タブ内の**Bake** | **そのタブのレイヤー 1 枚だけ** | タブごとのルール（例：手動選択は `_Isolation`） |
| アクションバーの**保存** | 上記と同じですがファイル名と位置を直接指定 | 直接指定 |
| アクションバーの**名前を付けて** | 上記と同じですがファイル名と位置を直接指定 | 直接指定 |
| レイヤーの行下の**最終ベイク** | **チェックされたレイヤーすべてを合成した結果** | `<メッシュ>_<マテリアル>_Final.png`（カラーレイヤーがあれば `_FinalColor.png` 追加） |

**最終ベイクはシーンビューに見えるそのままを保存します** — プレビューと同じ合成式を使うからです。

- 保存先は、ボタンの上の**保存先**ラベルに事前に表示されます。
- 同じ名前のファイルがあれば、**上書き / 新しい名前 / キャンセル**を尋ねます。誤った上書きは防止されます。
- 保存されたファイルはタブ下部の**最近のベイク**リストからピング(検索)またはフォルダを開くで即座に確認できます。

<!-- SCREENSHOT: 最近のベイクリスト — サムネイル + ピング/フォルダを開くボタン -->

## 6. シェーダーに挿入

焼き込みと挿入は別の作業です。4 ステップで完了します。

1. 別のタブでマスクを**焼き込みます**。
2. 保存されたテクスチャを選択 → Inspector で **sRGB (Color Texture) をオフ** → **Apply**。
3. マテリアル Inspector を開き、該当する**プロパティ**スロットにテクスチャをドラッグして挿入します。
4. そのスロットに**チャンネル選択**（R/G/B/A）がある場合、マスクを焼き込む際に使用したチャンネルと一致させます。コンバイナーで合成したマスク以外の場合、通常は **R** です。

シェーダーごとのスロット名と Inspector パスについては → [lilToon](/shaders/liltoon) · [Poiyomi](/shaders/poiyomi) · [MingToon](/shaders/mingtoon) · [NiloToon](/shaders/nilotoon)

:::tip[3～4 ステップをスキップする方法]
ツールに手伝わせたい場合、2 つの補助機能があります。どちらも**選択肢**で `Ctrl+Z` 1 回で戻します。

- ブリッジ+領域マスクタブの**ベイク後にマテリアルへ自動割り当て** — **デフォルトは無効です。** 有効にすると、保存したマスクを選択したスロット（NiloToon スタッキングレイヤーなど）に接続します。
- コンバイナーの**合成 + 再割り当て** — 実行前に**実行計画**カードで何を変更するかを先に表示します。
:::

## どのタブから始めるか分からない場合

| 実現したいこと | タブ |
|---|---|
| ヘアに光沢を入れる場所を指定 | [MatCap グロス](/tabs/matcap-gloss) |
| 凹んだ部分だけを暗くする（AO） | [MatCap グロス](/tabs/matcap-gloss) — AO/キャビティモード |
| 根→先で色が変わる染色 | [グラデーション](/tabs/gradient) |
| ヘアの数本だけ別の色 | [ブリッジ+領域マスク](/tabs/bridge-mask) |
| 特定部位だけ別のシェーダーにする | [スロット分割](/tabs/slot-split) |
| テクスチャ数が多すぎる | [コンバイナー](/tabs/combiner) |
| その他の任意の形状すべて | [ペイント](/tabs/paint) |
| 複数タブの結果を 1 枚に合成する | [レイヤースタックと最終ベイク](/concepts/layer-stack) |

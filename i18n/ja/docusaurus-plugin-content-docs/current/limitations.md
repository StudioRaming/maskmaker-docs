# 既知の制限

**このページを読むと** Mask Maker がしないことと設計上定められた境界を事前に知ることができます。ここに記載されているものはバグではなく意図された動作です。

## 環境

| 項目 | 範囲 |
|---|---|
| Unity | 2019.4 LTS ～ 2022.3。その他のバージョンは検証されていません |
| レンダー パイプライン | Built-in RP · URP。**HDRP はサポート対象ではありません** |
| 実行時点 | エディタのみ。ランタイム API はありません |
| プラットフォーム | エディタが動作する環境(Windows で開発・検証) |

## シェーダー

- 自動割り当てと自動最適化が**知っているシェーダーは NiloToon · Poiyomi 9.x · lilToon 3 種類**です。MingToon は接続表にのみあり、組み込みスキャン プロファイルには含まれていません。
- その他のシェーダーにもマスクを作成して**直接挿すことができます。**自動スキャン・再割り当てはできず、[シェーダー プロファイル JSON](/tabs/combiner#셰이더-프로파일)で追加できます。
- Poiyomi マテリアルが**Locked In**状態の場合、プロパティは更新されません。まず Unlock してください。

## コンバイナー

- 参照マテリアルが**50 個を超えると自動スキャンがオフになります。**スキャン ボタン を直接押す必要があります。
- 既にパック済みのテクスチャ · 非グレースケール テクスチャ · 複数のチャンネルで参照されるテクスチャは**自動的に除外**されます。必要に応じて手動で含めることができます。
- **オリジナル マスク ファイルは削除されません。**結果を確認後、直接整理する必要があります。
- lilToon スロットは R 固定サンプリングなため**1 パックに 1 つだけ**入ります。
- 解像度が混在すると大きい方にリサイズされます。**アスペクト比が混在すると警告のみで進行**します — 結果を目で確認してください。

## スロット分割

- **Mask Maker が作成した出力のみ** GUID を保持して上書きします。外部ファイル · 所有表示のないファイル · オリジナルが異なるファイルは上書きされません。
- 新規スロットにはデフォルトで**元のスロットと同じマテリアル**が割り当てられます。
- 分割は**サブメッシュ割り当てのみ**変更します。メッシュを実際に切り詰めて頂点を分割することはありません。

## ペイント

- 自動保存は `<プロジェクト>/Library/MaskMakerAutoSave/` にあります。**`Library`はキャッシュ フォルダ**なので削除するか、プロジェクトをコピーして移動すると消えます。バックアップではありません。
- ミラー(ミラー)描画は**モデルが左右対称の場合**に意味があります。非対称 UV では反対側がずれます。
- オクルードをオフにすると X-Ray で貫通して描きます。意図した動作ですが、オン/オフを忘れるとバック面が一緒に描かれます。

## MatCap グロス

- **グロス モード**は現在のシーンビュー視点基準でベイクされます。角度を変えると結果が変わります。
- **AO(キャビティ)モード**はシーンビュー角度に無関係ですが、リアルタイム プレビューではなく**プレビューベイク**ボタンで確認します。
- Preview がオフになっていると、ハンドルを編集できません。

## グラデーション

- 結果物はマスクではなく**カラー テクスチャ(sRGB)**です。マスク スロットにそのまま挿すことはできません。
- [基準ボーン](/tabs/gradient#기준-본)を指定しないと、ポーズが変わったアバターで位置がずれます。
- プリセットを別のアバターに適用するときに**同じ名前のボーンがない場合**、ワールド座標で代替されます。

## ブリッジマスク

- 選択状態は**Load 時にリセット**されます。モード切り替えやプレビューのオン/オフでは消えません。
- ティント色は**プレビュー専用**です。保存されるマスクは常に黒白です。
- 手動選択モードの出力ファイル名は**`_Isolation`サフィックス**を保持します(既存作業ファイルとの互換性)。
- 自動割り当ては**NiloToon スタッキング レイヤー**スロットを対象とします。

## 設定

- タブの調整値は `EditorPrefs` に**エディタ グローバル**で保存されます。他のプロジェクトで触った値が移行します。
- ユーザー シェーダー プロファイルは `<プロジェクト>/MaskMakerProfiles/` にあり、プロジェクトを移動すると付いてきます。`EditorPrefs`は付いてこない です。

→ [設定とプリセット](/reference/settings-and-presets)

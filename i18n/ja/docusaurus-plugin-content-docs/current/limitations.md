# 既知の制約

**このページを読むと** Mask Maker が行わないことと、設計上の制限を事前に把握できます。ここに書かれているものはバグではなく、意図された動作です。

## 環境

| 項目 | 範囲 |
|---|---|
| Unity | 2019.4 〜 Unity 6（6000.0、6000.3 LTS） |
| レンダーパイプライン | Built-in RP · URP |
| 実行タイミング | Editor のみ。ランタイム API はありません |
| プラットフォーム | エディターが動く環境（Windows で開発・検証） |


## 再生中

- **再生中は、読み込み・編集・レイヤーの追加が無効になります。** 再生中に変更した内容は保持されないためです。
- 再生を終えると、続けて作業できます。

## メモリの復旧

- 復旧ファイルを書き出せなかった場合、緊急用のコピーはメモリにしか残りません。このコピーは Unity のプロセスが終わるか強制終了されると消えます。
- **保存せずに終了** を選ぶと、メモリにしかなかった作業は消えます。

## シェーダー

- 自動接続は **マスクを差し込む先のシェーダーのプロパティ名** を基準にします。名前が一致しないシェーダーには、自分で差し込む必要があります。

## 詳細作業のツール（コンバイナー、スロット分割）

- マテリアルの数が **50 を超える** と、選択が変わったときの自動再スキャンはオフになります。その場合は **再スキャン** ボタンを自分で押す必要があります。
- すでにパックされていると見えるテクスチャと、マテリアルが **A チャンネル** を参照しているテクスチャは **自動で除外** されます。除外された項目には理由が表示されます。
- **元のマスクファイルは削除されません。** 結果を確認してから、自分で整理してください。
- lilToon のスロットは R 固定でサンプリングするため、1 つのパックに入るのは **1 枚だけ** です。
- スロット分割が変えるのは **サブメッシュの割り当てだけ** です。メッシュを切って頂点を分けることはしません。
- スロット分割の上書きは **Mask Maker が作った出力だけ** が対象です。外部のファイル、所有の目印がないファイル、元のファイルが違うファイルは上書きしません。

## 描画

- ミラー描画が意味を持つのは **モデルが左右対称のとき** だけです。UV が非対称だと、反対側が合いません。
- 対応していないマテリアルでは、PNG を書き出して自分で差し込んでください。ツールはテクスチャを自動では割り当てません。

## グラデーションとブリッジ

- グラデーションの **基準ボーン** を指定すると、開始点と終了点がそのボーンに追従します。ボーンが見つからない場合は、ワールド位置で焼き付けます。
- ブリッジの **ティント（プレビュー）** はプレビューにだけ使われます。保存されるマスクは常に白黒です。

## 設定

- 各タブの調整値と設定は、`EditorPrefs` に **エディター全体で** 保存されます。別のプロジェクトで変えた値が引き継がれます。
- ユーザーのシェーダープロファイルは `<プロジェクト>/MaskMakerProfiles/` に保存されるため、プロジェクトと一緒に移動します。

→ [設定とプリセット](/reference/settings-and-presets)

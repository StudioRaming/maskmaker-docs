# ショートカット

**このページを読むと** シーンビューで使うすべてのキーを 1 画面で見ることができます。

## クリック選択タブ共通

[ブリッジマスク](/tabs/bridge-mask)・[スロット分割](/tabs/slot-split)で同じように動作します。

| 操作 | 結果 |
|---|---|
| `Ctrl` + クリック | 束を追加 / 解除 |
| `Ctrl` + ドラッグ | 通過する束をペイントのようにトグル |
| `Ctrl+Shift` + ドラッグ | ボックスで**追加**選択 |
| `Ctrl+Shift+Alt` + ドラッグ | ボックスで**選択解除** |
| 通常のクリック | 通常通りシーン オブジェクトを選択(Unity デフォルト動作) |
| `Ctrl+Z` / `Ctrl+Y` | 実行取消 / やり直し |

前面/背面とミラー束は自動で一緒にトグルされ、ステータス バーに何個が一緒にトグルされたか表示されます。

## ペイントタブ

シーンビューで**そのまま左クリック ドラッグ**すると描画されます。`Ctrl`は不要で、`Alt`は通常通りカメラを回転させます。

### ブラシ

| キー | 機能 |
|---|---|
| `[` | 半径を小さくする |
| `]` | 半径を大きくする |
| `<` または `,` | 強度を弱くする |
| `>` または `.` | 強度を強くする |
| `F` + ドラッグ | 半径モーダル調整 |
| `Shift+F` + ドラッグ | 強度モーダル調整 |

`<` `>` と `,` `.` は**同じ機能**です。キーボード配列に応じて快適な方を使用してください。値は GUI スライダーに即座に反映されます。

### ツール

| キー | 機能 |
|---|---|
| `S` | スポイト — ベース テクスチャの色を抽出 |
| `X` | 色/値を交換 |
| `Ctrl` + クリック | 塗りつぶしツールを実行(別のツール使用中は一時的に塗りつぶし) |
| `Ctrl+Z` / `Ctrl+Y` | **ストローク単位**で実行取消 / やり直し |

### ステンシル

| キー | 機能 |
|---|---|
| `T` + ドラッグ | 移動 |
| `Shift+T` + ドラッグ | サイズ |
| `Ctrl+T` + ドラッグ | 回転 |
| `Alt+T` | 画面に合わせる |
| ホイール | サイズ調整 |

エッジ ハンドルで直接操作することもできます。
→ [ペイント — ステンシルテクスチャリング](/tabs/paint#스텐실)

## ハンドル操作タブ

[MatCapグロス](/tabs/matcap-gloss)・[グラデーション](/tabs/gradient)はシーンビュー ハンドルをマウスでドラッグします。別途のショートカットはありません。

| タブ | ハンドル |
|---|---|
| MatCap グロス | オレンジ球 = 中心移動 · エッジ ノブ = 半径 · 回転リング = 方向回転 |
| グラデーション | 開始/終了ハンドル = 範囲 · 中央ノブ = 全体移動 |

:::note[Preview がオフになっているとハンドルを触ることができません]
プレビューがオフになっている状態ではハンドルが薄く表示され、編集されません。
:::

## Unity デフォルト動作と重ならないように

Mask Maker は**通常の左クリックを取得しません**(ペイント タブを除く)。シーンビューで通常通りオブジェクトを選択して ギズモを使用できます。`Alt` 回転、`F` フォーカスなど Unity デフォルト操作もそのまま保持されます — ペイント タブの`F`のみがブラシ半径に使用されます。

# ショートカット

**このページを読むと** Mask Maker で使うキーを 1 画面で確認できます。

## 共通

| 操作 | 結果 |
|---|---|
| `Ctrl+Z` / `Ctrl+Y` | 取り消し / やり直し。1 ステップは適用 1 回、選択の変更 1 回、ストローク 1 回です |
| `Space`（押したままドラッグ） | UV キャンバスを動かします |
| `Tab` | 編集のオン・オフを切り替えます（文字入力中は動作しません） |
| `Esc` | 進行中のドラッグやストロークを取り消します |

## シーンビューでの描画

ペイントツールが有効なときに シーンビューで使うキーです。

| キー | 操作 |
|---|---|
| `1` / `2` / `3` / `4` | ペイントツールを選びます: 描画 / 消しゴム / なめらか / 塗りつぶし |
| `X` | ペイントの値を切り替えます（白 1 ↔ 黒 0） |
| `S`（押している間） | スポイト。シーンビューでクリックして色を拾います。キーを離すと解除されます |
| `[` / `]` | ブラシサイズ ×0.9 / ÷0.9 |
| `,` / `.` | ブラシ強度 -0.05 / +0.05 |
| `F` | 半径の調整。押したまま動かすとサイズが変わります |
| `Shift+F` | 強度の調整 |

## UV キャンバス

| 操作 | 結果 |
|---|---|
| `1` / `2` / `3` / `4` | 選択の単位: 頂点 / エッジ / 面 / アイランド。ブラシが有効なときは無視されます |
| `A` / `Alt+A` | すべて選択 / 選択解除（ブラシが無効のとき） |
| `F` | キャンバスをウィンドウに合わせます |
| `X` | ブラシが有効なとき、ブラシの値を 0 と 1 で切り替えます |
| クリック | 選択を置き換えます |
| `Shift` + クリック | 選択に追加します |
| `Ctrl` + クリック・ドラッグ | 選択をトグルするか、選択から外します |

## ブリッジ（シーンビューで毛束を選ぶ）

| 操作 | 結果 |
|---|---|
| `Ctrl` + クリック | 毛束を 1 本追加または解除します |
| `Ctrl` + ドラッグ | 通った毛束をペイントブラシのようにトグルします |
| `Ctrl+Shift` + ドラッグ | 矩形の中の毛束を範囲選択して追加します |
| `Ctrl+Shift+Alt` + ドラッグ | 矩形の中の毛束を範囲選択して解除します |
| `Alt` + ドラッグ（`Ctrl` なし） | シーンビューを回転します（Unity の標準） |

毛束にマウスを重ねると、結果が色で先に表示されます。

| ハイライト | 意味 |
|---|---|
| **シアン**（`#33E5FF`） | まだ選んでいない毛束。`Ctrl` + クリックで追加されます |
| **赤**（`#FF4033`） | 選択済みの毛束。`Ctrl` + クリックで外れます |

表と裏の面、UV が重なるミラーの毛束は一緒にトグルされ、ステータスバーに一緒にトグルされた数が表示されます。

## プレビュー中の Scene クリック

プレビュー中は、シーンビューの通常の左クリックでは別のオブジェクトを選びません。`Alt` の回転と `Ctrl` クリックの意味は変わりません。

## ステンシル

エキスパートツールのステンシルタブで `T` を押したままドラッグすると、ステンシルが動きます。`Ctrl` を押すと回転、`Shift` を押すと拡大縮小します。ステンシルは 2.0 のマスク作成方法には含まれません。

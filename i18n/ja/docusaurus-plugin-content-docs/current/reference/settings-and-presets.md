# 設定とプリセット

**このページを読むと** Mask Maker が何をどこに保存するのか、何がプロジェクトを移動しても付いてきて何が付いてこないかがわかります。

## 保存位置一覧

| データ | 位置 | プロジェクト移動時 | パッケージ更新時 |
|---|---|---|---|
| タブごとの最後の値(スライダー・トグル・モード) | `EditorPrefs`(エディタ グローバル) | 付いてこない | 保持 |
| セッション テンポラリ状態 | `SessionState`(エディタを閉じると消える) | — | — |
| ユーザー シェーダー プロファイル | `<プロジェクト>/MaskMakerProfiles/*.json` | **付いてくる** | **保持** |
| ペイント自動保存キャンバス | `<プロジェクト>/Library/MaskMakerAutoSave/` | 付いてこない(`Library`はキャッシュ) | 保持 |
| ベイク テクスチャ・メッシュ | オリジナル テクスチャ フォルダ(`Assets`内) | **付いてくる** | **保持** |

## EditorPrefs — 値を記憶

各タブの調整項目は**エディタ グローバル**で記憶されます。プロジェクトを変更しても同じ値で開始します。

| 記憶されるもの | 例 |
|---|---|
| MatCap グロス | 強度 · コントラスト · 丸さ · dilate ピクセル · グロス/AO サブモード · キャビティ 半径/サンプル/強度/コントラスト/反転 |
| グラデーション | 軸 · 中心 · 柔らかさ · 塗りつぶし方向 · 終了処理 · プレビュー表示方法 |
| ブリッジ+領域マスク | 比率 · グラデーション/エッジ フェード · 背面モード · ベイク後に自動割り当て · 対象プロパティ |
| スロット分割 | 新規スロットにマテリアルを複製 |
| コンバイナー | lilToon アルファベイク · 保存前に上書き確認 |
| ペイント | ブラシ半径 · 強度 · フォールオフ · 正面角度制限 · ミラー軸 · キャンバス サイズ · マスク/カラー モード |
| 共通 | 言語 · Hierarchy 選択変更時自動ロード |

:::note[値がおかしくなった場合]
`EditorPrefs` は Unity エディタ全体にわたる保存場所です。他のプロジェクトで触った値がそのまま移行します。タブの調整項目を 1 つずつ戻すのが最も速いです。
:::

## プリセット

| タブ | プリセットに含まれるもの |
|---|---|
| MatCap グロス | グローバル方向 · 球サイズ · 強度/コントラスト など全セッティング |
| グラデーション | 色 · 軸 · 範囲 · **基準ボーン名** |

プリセット行はカード上に 1 行あります — **[プリセット ▾]**（現在のプリセット名、ない場合は `-`） **[保存]** **[削除]** **[?]**。一番右の **?** を押すとこのページが開きます。

プリセットを別のメッシュまたは別のアバターに適用すると、同じセッティングがそのまま再現されます。グラデーション プリセットは[基準ボーン](/tabs/gradient#기준-본)を**名前で再検索します** — 同じ名前のボーンがないとワールド座標で代替します。

## シェーダー プロファイル フォルダ

| 項目 | 値 |
|---|---|
| パス | `<プロジェクト>/MaskMakerProfiles/*.json` |
| `Assets`外の理由 | パッケージを更新しても削除されないようにするため |
| 読込時点 | 初回スキャン 1 回または**組み込みを書き出し / 再読み込み**ボタンを押したときのみ |
| 名前の競合 | 組み込みと同じ名前なら**その場所で上書き**(マッチング優先順位を保持)。警告行で通知されます |

スキーマと例は → [コンバイナー — シェーダー プロファイル](/tabs/combiner#셰이더-프로파일)

## ペイント自動保存

| 項目 | 値 |
|---|---|
| パス | `<プロジェクト>/Library/MaskMakerAutoSave/` |
| 保存されるタイミング | プレビュー中止 · リコンパイル · プレイモード切り替え · シーン切り替え時に未保存キャンバスがある場合 |
| 復元 | 次の**Load** 時に**復元 / 破棄 / キャンセル**を確認します |
| 削除 | 実際の保存が成功するとテンポラリファイルが削除されます |

ファイル名はセッション単位の固定 GUID を使用します — 切り替えのたびに新ファイルが作成されないので 4K PNG が蓄積しません。

:::danger[Library はキャッシュフォルダです]
`Library` を削除またはプロジェクトをコピー移動すると、自動保存キャンバスは消えます。**完成した作業は必ず保存してください。** 自動保存は事故復旧用であってバックアップではありません。
:::

## 上書き確認

保存時に同じ名前のファイルがあれば**上書き / 新しい名前 / キャンセル**を尋ねます。うっかり上書きは防止されます。

コンバイナーの手動保存は**保存前に上書き確認**オプションで毎回確認するようにできます。

## 最近のベイク

各ベイクタブ下部に保存したテクスチャリストが残ります。**ピング(検索)**でプロジェクトウィンドウで強調するか、**フォルダを開く**でエクスプローラーを開きます。

## 初期化

| 戻したいもの | 方法 |
|---|---|
| タブの調整値 | 各項目を個別に戻します |
| スロット分割の束の移動 | **移動を初期化** |
| スロット分割のスロット構成 | **構造を初期化** |
| コンバイナースキャン結果 | **再スキャン** |
| シーンビュー編集全般 | `Ctrl+Z` |

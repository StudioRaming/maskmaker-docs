# 設定とプリセット

**このページを読むと** Mask Maker が何をどこに保存するか、どれがプロジェクトを移動したときについてきて、どれがついてこないかが分かります。

## 保存場所の一覧

| データ | 場所 | プロジェクトを移動すると | パッケージを更新すると |
|---|---|---|---|
| 調整値と設定 | `EditorPrefs`（エディター全体） | ついてこない | 保持される |
| セッションの一時状態 | `SessionState`（エディターを閉じると消える） | - | - |
| ユーザーのシェーダープロファイル（コンバイナー） | `<プロジェクト>/MaskMakerProfiles/*.json` | **ついてくる** | **保持される** |
| 復旧データ、ドキュメントのバックアップ、出力の復旧コピー | `<プロジェクト>/Library/StudioRaming/MaskMaker/` | ついてこない（`Library` はキャッシュ） | 保持される |
| 出力したテクスチャとメッシュ | 元のテクスチャフォルダー（`Assets` 内） | **ついてくる** | **保持される** |

## Library の下のフォルダー

| フォルダー | 中身 |
|---|---|
| `Recovery/` | 異常終了後に復元する作業（復旧バナー） |
| `DocumentBackups/` | 古い形式のドキュメントを新しい形式へ変換する前の原本 |
| `OutputRecovery/` | 出力ファイルの書き込み中に作られる復旧コピー |
| `TextureBackups/` | Scene セッションで PNG を上書きする前の原本 |
| `SlotSplitUndo/` | スロット分割の取り消し記録 |

:::danger[Library はキャッシュのフォルダーです]
`Library` を削除したり、プロジェクトをコピーして移したりすると、復旧データは消えます。**完成した作業は必ず保存してください。** 復旧は事故への備えであり、バックアップではありません。
:::

## EditorPrefs

調整値は **エディター全体で** 記憶されます。別のプロジェクトを開いても同じ値から始まります。主な項目は次のとおりです。

| 項目 | 記憶される内容 |
|---|---|
| 描く の **遮蔽** オプション | 描くパネルで最後に設定した値（初期値はオン） |
| ブリッジの **ベイク後に自動割り当て** | 初期値はオフ |
| ブリッジのプリセット一覧 | 保存したブリッジのプリセット（ランダムと手動のモードごと） |
| ヘルプの表示 | ウィンドウにヘルプを表示するかどうか |

:::note[値がおかしくなったら]
`EditorPrefs` は Unity エディター全体で 1 つの保存先です。別のプロジェクトで変えた値がそのまま引き継がれます。調整項目を 1 つずつ戻すのが最も早い方法です。
:::

## シェーダープロファイルのフォルダー（コンバイナー）

| 項目 | 値 |
|---|---|
| パス | `<プロジェクト>/MaskMakerProfiles/*.json` |
| `Assets` の外にある理由 | パッケージを更新しても消えないようにするためです |
| 読み込むタイミング | 最初のスキャン時に 1 回、または **ビルトインを書き出す / 再読み込み** を押したときだけ |
| 名前の衝突 | ビルトインと同じ名前なら、その場で上書きします。警告の行で知らせます |

スキーマと例は → [コンバイナー: シェーダープロファイル](/tabs/combiner#셰이더-프로파일)

## プリセット

**プリセットの行** は、マットキャップ光沢、グラデーション、ブリッジのタブにあります。行のドロップダウンでプリセットを選び、**保存**（上書き）または **削除** できます。`-` を選んだまま保存すると、自動の名前で新しいプリセットが作られます。

- ブリッジは **ランダム毛束** と **手動選択** のモードごとに別の一覧を持ちます。
- プリセット名だけでは区別されません。モードが違えば別のプリセットです。

## 上書きの確認

同じ名前の出力ファイルがあると、**上書き / 新しい名前 / キャンセル** を尋ねます。誤って上書きされることはありません。

## 最近の作業

ヘッダーの **最近の作業** から、このセッションで保存したファイルを探せます。Project ウィンドウで探すか、フォルダーを開けます。

## 1.x の自動保存キャンバス

1.x が `Library/MaskMakerAutoSave/` に保存していた自動保存キャンバスは、**同じプロジェクトに残っている場合** に 2.0 が一度だけ取り込みます。ファイルを描く用の復旧フォルダー（`Library/StudioRaming/MaskMaker/Recovery/Paint/` の下）へ移し、名前の先頭に `legacy_` を付けます。古い EditorPrefs のキーは削除されます。移動できなかった場合は、コンソールに警告が出ます。

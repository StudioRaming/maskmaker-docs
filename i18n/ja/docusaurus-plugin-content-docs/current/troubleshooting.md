# トラブルシューティング

**このページを読むと** 最も頻繁に表示される症状を順番にチェックして原因を絞ることができます。同じ内容がツール ヘッダーの**?**ボタン → FAQ にもあります。

## マスクを挿したのに効果が見えません

順番に確認してください。ほとんどが 1 番です。

1. **sRGB (Color Texture) がオフになっているか**確認します。有効になっているとガンマ補正で値が歪みます。
   → [sRGB とインポート設定](/concepts/srgb-and-import-settings)
2. スロットに**チャンネル選択**(R/G/B/A)があれば、マスク データが**実際に入っているチャンネル**と一致しているか確認します。
3. このプロパティを有効にする**上位トグル**が有効になっているか確認します(lilToon の Rendering Mode、MingToon の`~ Enabled` トグル、NiloToon のスタッキング レイヤー有効化など)。
4. **UV**が本体テクスチャと同じマップを使用しているか確認します。

## 効果が反対に適用されています

シェーダー側の**反転(Invert)**トグルが有効になっているか、マスクを反転して(黒白反対で)ベイクした場合です。

どちらか一方をフリップさせればよいため、**マスクを再度ベイクする前にシェーダーの Invert トグルを最初にオフにしてみてください。** MingToon はほとんどのプロパティにあり、すべてのシェーダーにあるわけではありません。

## マスク境界が段々状に見えます

1. **dilate(アウトライン拡張)**値を増やします。UV 境界外に色を押し出してシーム(seam)が表示されるのを防ぎます。
2. それでもダメなら解像度を上げます(512 → 1024)。
3. それでもダメなら**UV シーム(seam)位置**を疑います。マスク境界がシーム上に配置されると、どの解像度でもきれいにはなりません。

圧縮が原因の可能性もあります — 特に[パック済みパック テクスチャ](/concepts/channels-and-packing)ではチャンネル同士が干渉します。
→ [sRGB とインポート設定](/concepts/srgb-and-import-settings)

## マテリアルが複数あるのにどれに適用されるのですか

各タブは**Load したレンダラーのスロット基準**で動作します。対象リスト下の**マテリアルスロットピッカー**で目的のスロットを選択してください。選択したスロットのサブメッシュのみがベイク・ペイント・プレビューされます。

→ [マテリアルスロットピッカー](/getting-started/first-mask#머티리얼-슬롯-피커)

## ベイクしたばかりのテクスチャがどこに保存されたか分かりません

各ベイク タブ下部の**最近のベイク**リストで**ピン(検索)**またはフォルダを開く**を押してください。

## プレビューがシーンに残っています

**Stop**を押すか、ウィンドウを閉じると自動的に復元されます。リコンパイル・プレイモード切り替えでも復元されます。

プレビューはオリジナル マテリアルを複製して一時的に被せる方式なため、オリジナルが変更されることはありません。

## シーンビューで束が捕捉できません

| 症状 | 確認 |
|---|---|
| クリックしても何も起こらない | `Ctrl`を押してクリックしたか確認してください。通常のクリックはシーン オブジェクト選択です |
| 内側・反対側の束が捕捉できない | **背面モード**を有効にしてください。前面を非表示にして内側を直接掴めます |
| 一度に複数がトグルされる | 正常です。前面/背面と UV が重なるミラー束は自動で一緒にトグルされ、ステータス バーに個数が表示されます |
| Load 後に選択が空 | 選択状態は Load 時にリセットされます。モード切り替えまたはプレビューのオン/オフでは消えません |

→ [ショートカット](/reference/hotkeys)

## コンバイナーがテクスチャを除外しました

自動モードで除外されたテクスチャはリストに**除外理由**が表示されます。理由を確認してから、それでも含める必要があれば**含める**を押してください。

→ [コンバイナー](/tabs/combiner)

## コンバイナーが自動でスキャンしません

参照マテリアルが**50 個を超えると**自動スキャンがオフになります。**スキャン**ボタンを直接押してください。大型アバターで選択するたびに一時停止するのを防ぐための制限です。

## 私のシェーダーがコンバイナー リストにありません

組み込みプロファイルは NiloToon · Poiyomi · lilToon 3 種類です。他のシェーダーは**シェーダー プロファイル JSON**で直接追加してください。**組み込みを書き出し**でテンプレートを取得して編集するのが最速です。

→ [コンバイナー — シェーダー プロファイル](/tabs/combiner#셰이더-프로파일)

## ペイント タブで保存できず、ウィンドウを閉じてしまいました

次の**Load**時に自動保存されたキャンバス復元を提案します — **復元 / 破棄 / キャンセル**。

自動保存は `<プロジェクト>/Library/MaskMakerAutoSave/` にあります。`Library`はキャッシュ フォルダなので、削除すると一緒に消えます。

→ [設定とプリセット](/reference/settings-and-presets)

## スロット分割を適用したのに元に戻したい

`Ctrl+Z`で戻します。適用結果は Undo/Redo をサポートします。

適用中にキャンセルまたは失敗すると、**全体がロールバック**されます。一部だけが適用された状態で残ることはありません。

## スロット分割後、新規スロットが元のスロットと同じマテリアルです

これは デフォルト動作です。適用後、目的のマテリアルに直接変更してください。

新規スロットごとに別のマテリアル(`_SplitN.mat`)を取得したい場合は、適用前に**新規スロットにマテリアルを複製**を有効にしてください。

## それでも解決しない場合

studioraming@gmail.com にお問い合わせください。Unity バージョン、レンダー パイプライン、シェーダー名、どのタブで何をしたのかを一緒に記入していただくと高速です。

# トラブルシューティング

**このページを読むと** よく出る症状を順番に確認して、原因を絞り込めます。

## マスクを差し込んだのに効果が出ません

次の順番で確認してください。ほとんどの場合は 1 番が原因です。

1. **sRGB (Color Texture)** がオフになっているか確認します。オンのままだとガンマ補正で値がずれます。
   → [sRGB とインポート設定](/concepts/srgb-and-import-settings)
2. スロットに **チャンネル選択**（R / G / B / A）がある場合、マスクのデータが **実際に入っているチャンネル** と合っているか確認します。
3. このプロパティを有効にする **親のトグル** がオンになっているか確認します（lilToon の Rendering Mode、MingToon の `~ Enabled` トグル、NiloToon のスタッキングレイヤーの有効化など）。
4. **UV** が本体のテクスチャと同じマップを使っているか確認します。

## 効果が逆になります

シェーダー側の **反転（Invert）** オプションがオンになっているか、マスクを白黒逆に作ってしまった場合です。

どちらか一方を反転すれば十分です。マスクを出力し直す前に、シェーダーの反転オプションをオフにしてみてください。反転オプションがあるシェーダーのスロットでだけ使えます。

## 読み込んだあと、モデルが白く見えます

レイヤーがないとき、または **マスクのみ** がオンのときのプレビューです。元のマテリアルは変わっていません。**編集** をオフにすると元の見た目に戻ります。**元の表示** に切り替えても同じです。

## マスクの境界が階段状に見えます

1. 出力設定の **アウトライン（px）** の値を大きくします。マスクを UV の境界の外まで広げ、継ぎ目（シーム）が見えないようにします。
2. それでも足りなければ、**テクスチャサイズ** を上げます（例: 512 → 1024）。
3. それでも直らなければ、**UV のシーム位置** を疑ってください。マスクの境界がシームの上にあると、どの解像度でもきれいにはなりません。

圧縮が原因のこともあります。特に [パック済みテクスチャ](/concepts/channels-and-packing)では、チャンネルが互いににじみます。
→ [sRGB とインポート設定](/concepts/srgb-and-import-settings)

## ボタンがグレーになっています

ボタンにマウスを重ねると、何をすればオンになるかが表示されます。

## 保存したファイルが見つかりません

ヘッダーの **最近の作業** を押してください。Project ウィンドウで探すか、フォルダーを開けます。

## プレビュー中に別のオブジェクトが選べません

プレビューがオンの間、シーンビューの通常の左クリックでは作業対象から離れません。別のオブジェクトを選ぶには、Hierarchy で選んでください。`Alt` + ドラッグで シーンビューを回転する操作はそのまま使えます。

→ [ショートカット](/reference/hotkeys)

## 異常終了のあと、作業が表示されません

エディターが異常終了すると、ウィンドウの上に **復旧バナー** が表示されます。**復元** を押すと作業が戻り、**破棄** を押すと削除されます。

復旧ファイルを書き出せなかった場合（ディスクの空き容量や権限の問題）は、作業がメモリにしか残っていないことがあります。Unity を強制終了する前に、**作業を開く** を選んで先に保存してください。**保存せずに終了** を選ぶと、メモリにしかなかった作業は消えます。

→ [レイヤーとマスク出力](/concepts/layer-stack)

## 描いたら裏面まで塗れてしまいます

描画パネルの **遮蔽** オプションがオフの場合、隠れた面まで突き抜けて描きます（X-Ray）。カメラから見えない面をスキップするには、**遮蔽** をオンにしてください。

→ [描画のオプション](/tabs/paint)

## 使っているシェーダーがコンバイナーの一覧にありません

ビルトインのプロファイルは NiloToon、Poiyomi、lilToon の 3 種類です。ほかのシェーダーは、**シェーダープロファイル JSON** を自分で追加してください。

→ [コンバイナー: シェーダープロファイル](/tabs/combiner#셰이더-프로파일)

## それでも解決しない場合

studioraming@gmail.com までご連絡ください。Unity のバージョン、レンダーパイプライン、シェーダー名、何をしたかを書いていただくと、早く解決できます。

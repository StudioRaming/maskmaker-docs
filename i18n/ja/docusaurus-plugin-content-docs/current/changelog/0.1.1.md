*リリース: 0.1.1*

レイヤースタック プレビューと**最終ベイク**が追加され、ペイント タブが新たに追加されて、隔離タブがブリッジ タブに統合され、タブ構成が 6 個に整理されたバージョンです。

## アップグレード時に確認すること

:::caution[タブ構成が 8 個から 6 個に削減されました]
**隔離**タブは[ブリッジ+領域マスク](/tabs/bridge-mask)タブの**手動選択**モードになり、**ヘルプ**タブはヘッダーの**?**ボタンに移動しました。

手動選択モードの出力ファイル名は**`_Isolation`サフィックスをそのまま保持**するので、以前に作成したマスクと名前がずれません。
:::

## 新機能

- **レイヤースタック プレビュー / 最終ベイク** — どのタブでも **Load** をクリックするとすぐにプレビューが有効になり、タブを切り替えても前のタブの結果がシーンに残って重なって表示されます。タブバーの下に**対象の行**（Target · Load · 更新 · Preview）と**レイヤーの行**が固定され、レイヤーごとに表示チェックボックス · ブレンド（`Max`/`Add`/`Multiply`/`Subtract`/`Replace`） · 不透明度を調整します。**最終ベイク**は見えるままを `<メッシュ>_<マテリアル>_Final.png`（カラーレイヤーがあれば `_FinalColor.png` 追加）で保存します。タブの **Bake** は「このレイヤーだけ焼き込む」で残ります。→ [ドキュメント](/concepts/layer-stack)
- **元のシェーダーの上に重ねて表示するプレビュー** — シーンビューのプレビューは専用のプレビューシェーダーに差し替えず、**元のシェーダーをそのまま使い、ベースマップの上にマスクを重ねて**表示します。アバターは普段どおりの見た目のまま、マスクだけが乗った状態で確認できます。→ [ドキュメント](/concepts/layer-stack)
- **スロット分割 — 統合モード** — タブ上部の**分割** / **統合**トグルで分割の逆操作を行います。統合するスロットをカードチェックボックス（ベースマップサムネイル）またはシーンビュー `Ctrl` + クリックで 2 つ以上選び、**残すマテリアル**を指定すると、`*_merged.asset` 新メッシュを保存してレンダラーを置き換えます。ベースマップが異なるか UV が重なると警告だけで実行は止まりません。元のアセットは変わらず `Ctrl+Z` でメッシュとマテリアル配列が一緒に戻り、同じメッシュを使う別のレンダラーも一緒にリバインドされます。分割モードに未適用の変更があるとロックされます。→ [ドキュメント](/tabs/slot-split#합치기-모드)
- **アクションバー** — ヘッダーのすぐ下に **Load · Preview · 編集メッシュのみ · Undo · Redo · 最終ベイク · 保存 · 名前を付けて** 1 行が追加されました。よく使う操作がタブごとに異なる場所に散らばっていません。**編集メッシュのみ**はシーンビューにロード対象だけ残す非破壊分離です。→ [ドキュメント](/getting-started/first-mask)
- **ツールからドキュメントへの直リンク** — ヘッダーの**Docs**ボタン（現在のタブページ）、カードタイトル横の小さい**?**ボタン（その機能のページ、マウスを重ねると 1 行説明）、ヘッダーのバージョンラベル **v0.1.1**（このパッチノート）。リンクはツールで選択した言語に従います。
- **シーンクリック ロック** — プレビュー中、シーンビューの通常の左クリックは別のオブジェクトを選択しません(`Alt` + ドラッグのシーン回転、`Ctrl` クリック/ドラッグはそのまま)。→ [ドキュメント](/reference/hotkeys)
- **プレビュー復旧** — プレビューマテリアルがメッシュに残った場合、ウィンドウを再度開くと自動的に復旧し、「?」ヘルプ画面上部の**プレビュー復旧**ボタンでも戻せます。→ [ドキュメント](/troubleshooting)
- **ペイント タブ** — シーンビュー メッシュ上にブラシで直接描いてマスク/カラー テクスチャを作成するブレンダー スタイル テクスチャ ペイント。描画/消しゴム/なめらか/塗りつぶし、正面角度制限、オクルード、ミラー、ステンシルテクスチャリング、内蔵ステンシル 8 種、自動保存復元。→ [ドキュメント](/tabs/paint)
- **MatCap グロス — AO(キャビティ)サブモード** — メッシュの凹んだ部分だけでシェーディング マスクをベイクします。シーンビュー角度に無関係で、**プレビューベイク**ボタンで確認します。→ [ドキュメント](/tabs/matcap-gloss)
- **ペイントで仕上げる** — MatCap ベイク結果をペイント タブに移して手で続き描きします。→ [ドキュメント](/tabs/paint)
- **グラデーション — 基準ボーン** — 開始/終了点がボーンに従い、ポーズが変わったアバターでも位置を保持し、プリセットが別のアバターでも同じ名前のボーンを再検索します。→ [ドキュメント](/tabs/gradient#기준-본)
- **ブリッジ+領域マスク — 選択編集** — すべて選択 / すべて解除 / 選択を反転 / 選択を拡張、**最近のシード**記録、ペイント タブへ送る。→ [ドキュメント](/tabs/bridge-mask)
- **スロット分割 — セーフティ** — **更新**、**移動を初期化**/**構造を初期化**分離、**適用計画**カード、**新規スロットにマテリアルを複製**オプション、適用後自動プレビュー再開。→ [ドキュメント](/tabs/slot-split)
- **コンバイナー — 自動最適化** — 自動スキャン、サムネイル、グループ間ドラッグ移動、**実行計画**カード、ベイク後自動マテリアル割り当て。→ [ドキュメント](/tabs/combiner)
- **コンバイナー — シェーダー プロファイル** — `MaskMakerProfiles/` フォルダの JSON でスキャン対象スロットを直接定義・拡張します。組み込みを書き出し / 再読み込み。→ [ドキュメント](/tabs/combiner#셰이더-프로파일)
- **マテリアルスロットピッカー** — メッシュにマテリアル スロットが複数ある場合、スロット別ベースマップ サムネイルから 1 つを選択してベイク/ペイント/プレビューします。出力ファイル名は `<メッシュ>_<マテリアル>`。サブメッシュ数より多いスロットは最後のサブメッシュにマッピングされます。→ [ドキュメント](/getting-started/first-mask#머티리얼-슬롯-피커)
- **ヘルプ(ヘッダー ? ボタン)** — 「マスク テクスチャとは?」、タブ別用途表、lilToon/Poiyomi/MingToon/NiloToon シェーダー別プロパティ接続表(名前クリックでコピー)、接続 4 ステップ、FAQ。→ [ドキュメント](/concepts/what-is-a-mask)

## 変更

- **隔離タブがブリッジ タブに統合**されました。タブ上部の**ランダム束 / 手動選択**モード トグルで両方の動作を切り替えます。→ [ドキュメント](/tabs/bridge-mask)
- **ヘルプがタブからヘッダー ? ボタンに移動**しました。**閉じる**ボタンでタブ画面に戻ります。
- **ブリッジ+領域マスク タブ名がブリッジ+領域マスクに変更されました。** ランダム束と手動選択（領域）の 2 つの用途を名前に反映させました。動作と出力ファイル名は変わりません。→ [ドキュメント](/tabs/bridge-mask)
- 上の 3 つの変更により、タブ構成が 6 個(**MatCapグロス · グラデーション · ブリッジ+領域マスク · スロット分割 · コンバイナー · ペイント**)に整理されました。
- **対象の行がタブバーのすぐ下に移動**して固定されました。スクロール外なので、どのタブでも同じ場所です。
- **Preview / Stop ボタンの意味が「そのタブ レイヤーの表示 / 非表示」に変わりました。** 切っても レイヤーは残っているため、再度有効にするとそのまま戻ります。
- **マテリアル接続機能の位置を明確にしました。** このツールの本体はマスク作成で、ブリッジ+領域マスクの**ベイク後にマテリアルへ自動割り当て**（デフォルト無効）とコンバイナーの**合成 + 再割り当て**（実行前にプラン表示）はオプション補助機能であり、どちらも `Ctrl+Z` 1 回で戻ります。

## 改善

- シーンビュー選択が**Ctrl+クリック / Ctrl+ドラッグペイント / Ctrl+Shift+ドラッグ ボックス選択**に全タブ標準化。→ [ドキュメント](/reference/hotkeys)
- シーンビュー編集に**Ctrl+Z / Ctrl+Y**実行取消/やり直し を適用。
- 保存時に**上書き確認**(上書き / 新しい名前 / キャンセル)。
- Hierarchy 選択変更時**自動再ロード** + シーン ヒント表示。
- 各タブに**最近のベイク**リストを追加。

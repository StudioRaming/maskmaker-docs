*リリース: 0.1.1*

ペイント タブが新たに追加されて、隔離タブがブリッジ タブに統合され、タブ構成が 6 個に整理されたバージョンです。

## アップグレード時に確認すること

:::caution[タブ構成が 8 個から 6 個に削減されました]
**隔離**タブは[ブリッジマスク](/tabs/bridge-mask)タブの**手動選択**モードになり、**ヘルプ**タブはヘッダーの**?**ボタンに移動しました。

手動選択モードの出力ファイル名は**`_Isolation`サフィックスをそのまま保持**するので、以前に作成したマスクと名前がずれません。
:::

## 新機能

- **ペイント タブ** — シーンビュー メッシュ上にブラシで直接描いてマスク/カラー テクスチャを作成するブレンダー スタイル テクスチャ ペイント。描画/消しゴム/なめらか/塗りつぶし、正面角度制限、オクルード、ミラー、ステンシルテクスチャリング、内蔵ステンシル 8 種、自動保存復元。→ [ドキュメント](/tabs/paint)
- **MatCap グロス — AO(キャビティ)サブモード** — メッシュの凹んだ部分だけでシェーディング マスクをベイクします。シーンビュー角度に無関係で、**プレビューベイク**ボタンで確認します。→ [ドキュメント](/tabs/matcap-gloss)
- **ペイントで仕上げる** — MatCap ベイク結果をペイント タブに移して手で続き描きします。→ [ドキュメント](/tabs/paint)
- **グラデーション — 基準ボーン** — 開始/終了点がボーンに従い、ポーズが変わったアバターでも位置を保持し、プリセットが別のアバターでも同じ名前のボーンを再検索します。→ [ドキュメント](/tabs/gradient#기준-본)
- **ブリッジマスク — 選択編集** — すべて選択 / すべて解除 / 選択を反転 / 選択を拡張、**最近のシード**記録、ペイント タブへ送る。→ [ドキュメント](/tabs/bridge-mask)
- **スロット分割 — セーフティ** — **更新**、**移動を初期化**/**構造を初期化**分離、**適用計画**カード、**新規スロットにマテリアルを複製**オプション、適用後自動プレビュー再開。→ [ドキュメント](/tabs/slot-split)
- **コンバイナー — 自動最適化** — 自動スキャン、サムネイル、グループ間ドラッグ移動、**実行計画**カード、ベイク後自動マテリアル割り当て。→ [ドキュメント](/tabs/combiner)
- **コンバイナー — シェーダー プロファイル** — `MaskMakerProfiles/` フォルダの JSON でスキャン対象スロットを直接定義・拡張します。組み込みを書き出し / 再読み込み。→ [ドキュメント](/tabs/combiner#셰이더-프로파일)
- **マテリアルスロットピッカー** — メッシュにマテリアル スロットが複数ある場合、スロット別ベースマップ サムネイルから 1 つを選択してベイク/ペイント/プレビューします。出力ファイル名は `<メッシュ>_<マテリアル>`。サブメッシュ数より多いスロットは最後のサブメッシュにマッピングされます。→ [ドキュメント](/getting-started/first-mask#머티리얼-슬롯-피커)
- **ヘルプ(ヘッダー ? ボタン)** — 「マスク テクスチャとは?」、タブ別用途表、lilToon/Poiyomi/MingToon/NiloToon シェーダー別プロパティ接続表(名前クリックでコピー)、接続 4 ステップ、FAQ。→ [ドキュメント](/concepts/what-is-a-mask)

## 変更

- **隔離タブがブリッジ タブに統合**されました。タブ上部の**ランダム束 / 手動選択**モード トグルで両方の動作を切り替えます。→ [ドキュメント](/tabs/bridge-mask)
- **ヘルプがタブからヘッダー ? ボタンに移動**しました。**閉じる**ボタンでタブ画面に戻ります。
- 上の 2 つの変更により、タブ構成が 6 個(**MatCapグロス · グラデーション · ブリッジマスク · スロット分割 · コンバイナー · ペイント**)に整理されました。

## 改善

- シーンビュー選択が**Ctrl+クリック / Ctrl+ドラッグペイント / Ctrl+Shift+ドラッグ ボックス選択**に全タブ標準化。→ [ドキュメント](/reference/hotkeys)
- シーンビュー編集に**Ctrl+Z / Ctrl+Y**実行取消/やり直し を適用。
- 保存時に**上書き確認**(上書き / 新しい名前 / キャンセル)。
- Hierarchy 選択変更時**自動再ロード** + シーン ヒント表示。
- 各タブに**最近のベイク**リストを追加。

## サポート環境

Unity 2019.4 LTS ～ 2022.3 · Built-in RP / URP。

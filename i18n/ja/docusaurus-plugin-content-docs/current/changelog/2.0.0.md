*リリース: 2.0.0*


マスクの作成方法を、描く、画像、グラデーション、ブリッジ、マットキャップ光沢の 5 つに整理しました。複数の方法をレイヤーとして組み合わせ、マスクとして出力する流れに変えたバージョンです。Unity 6（6000.0、6000.3 LTS）への対応を含みます。

## アップグレード時に確認すること

:::caution[作業の流れと一部の機能が変わりました]
- カラー調整は Mask Maker ではもう作れません。カラー調整は MingPainter で行ってください。以前のカラーレイヤーの結果はそのまま残ります。
- ステンシル、デカール、キャビティ/AO は、新しいマスクの作成方法から外れました。既存のデータは保持されます。→ [描く](/tabs/paint)
- 1.x のレイヤー編集ドキュメントは、2.0 で初めて保存するときに新しい形式に変換されます。変換前の元のファイルは `Library/StudioRaming/MaskMaker/DocumentBackups/` にバックアップされます。変換後のドキュメントは 1.x では開けません。→ [レイヤーとマスク出力](/concepts/layer-stack)

:::

アップデートは、既存の `Assets/StudioRaming/MaskMaker` フォルダーの上に、新しいパッケージをそのままインポートしてください。


## 新機能

- **かんたん開始 / 詳細作業のモード** — かんたん開始は、選んだマスクの効果の設定とシーンビューでの編集に集中します。詳細作業は、レイヤー、メッシュ、出力、ツールを細かく調整します。モードを切り替えても作業は残ります。→ [最初のマスクを作る](/getting-started/first-mask)
- **マスク作成の 5 つの方法** — 描く、画像、グラデーション、ブリッジ、マットキャップ光沢。→ [描く](/tabs/paint) · [画像](/tabs/image) · [グラデーション](/tabs/gradient) · [ブリッジ](/tabs/bridge-mask) · [マットキャップ光沢](/tabs/matcap-gloss)
- **方法の組み合わせ** — 内容のあるマスクに方法を追加すると、標準で **範囲を絞る** を使います。**白い範囲を追加** と **これだけ使う** もあります。→ [レイヤーとマスク出力](/concepts/layer-stack#방법-조합)
- **描いて補正** — 生成結果の上に描くと、描いた部分だけが補正として残り、残りの部分は設定の変更に従います。→ [描く](/tabs/paint#칠하기-보정)
- **ペン筆圧サイズと不透明度** — それぞれ 0～100% で適用します。→ [描く](/tabs/paint#펜-필압)
- **レイヤー保存** — レイヤーを 1 枚だけ別に保存します。レイヤーに接続されていない絵は、既存のレイヤーを置き換えずに復元します。→ [レイヤーとマスク出力](/concepts/layer-stack#레이어-저장)
- **マスク出力** — **保存・適用 → マスク出力** で、出力サイズと UV の境界のにじみを決めます。編集できるレイヤードキュメントも一緒に保存されます。→ [レイヤーとマスク出力](/concepts/layer-stack#마스크-출력)
- **3 つの表示** — マスクのみ、適用結果、元の表示。元の表示でもマスクの作業は保持されます。
- **開いているマスクの一覧と検索** — 空のスロットも表示がオンで始まります。名前、マテリアル、シェーダーのプロパティ、テクスチャで検索できます。
- **自動保持と復旧バナー** — 保存していない作業は、スクリプトのリロード、Play、シーンの切り替え、編集の終了のときに保持されます。異常終了のあとは **復元** か **破棄** を選びます。→ [レイヤーとマスク出力](/concepts/layer-stack#되돌리기와-자동-보존)
- **元に戻す単位** — 適用 1 回、選択の変更 1 回、ストローク 1 本がそれぞれ 1 ステップです。
- **インスペクターでチャンネルを変えると作業も一緒に移る** — 描いた作業が新しいチャンネルへ移り、新しいチャンネルにすでに作業がある場合は **移す** / **追従のみ** を確認します。→ [チャンネルとパッキング](/concepts/channels-and-packing#channel-change)
- **空のマスクの案内** — まだ何も描いていないマスクのプレビューに「まだ描かれていません。」という案内が 1 行付きます。
- **MingToon のマスクスロットから開く** — MingToon のインスペクターのマスクスロットから直接開けます。この連携には最新の MingToon が必要です。→ [MingToon](/shaders/mingtoon)
- **ウィンドウでの言語切り替え** — ウィンドウ右上で、한국어、English、日本語を切り替えられます。他の StudioRaming ツールと言語設定を共有します。
- **Unity 6（6000.0、6000.3 LTS）対応を含む**

## 変更

- 新しいマスクを作るときの方法は、描く、画像、グラデーション、ブリッジ、マットキャップ光沢の 5 つです。
- 再生中は、読み込み、編集、レイヤーの追加が無効になります。再生中に変更した内容は保持されないためです。
- 対応 Unity は 2019.4 ～ Unity 6（6000.0、6000.3 LTS）、Built-in RP と URP です。

## 修正

- Play、シーンの切り替え、リロード、ウィンドウを閉じたときに、レイヤーが消えていた問題を直しました。保持して、戻ったときに復元します。
- 新しいキャンバスを作ると、クラッシュ復旧データが上書きされていた問題を直しました。
- チャンネルをまとめたテクスチャ（例: `_MaskMap`、`_RegionMask`）へ保存すると、ほかのチャンネルが消えていた問題を直しました。
- マテリアルを切り替えるとブリッジレイヤーが抜けていた問題を直しました。
- 最終出力で、マットキャップレイヤーの輪郭の値が適用されていなかった問題を直しました。
